# 에이전트별 규칙 파일 자동 로드 규격

종류: 리서치 · 작성: 2026-09-18 claude · 웹 사실은 URL과 확인 날짜 기준. 결론은 `../../AgentCollaboration_Plan.md` 1절.

## 주제
세 코딩 에이전트(Claude Code, OpenAI Codex, Gemini CLI/Antigravity)가 세션 시작 시 자동으로 읽는 파일의 공식 규격 확인 — CLAUDE.md/AGENTS.md/GEMINI.md 탐색 순서, @import 문법, SessionStart 훅, 메모리, 스킬(SKILL.md), AGENTS.md·Agent Skills 개방 표준. 목표: 루트 AGENTS.md 한 파일을 세 에이전트가 모두 자동으로 읽게 만드는 최소 변경 도출.

## 권장하지 않는 것
- **Windows에서 CLAUDE.md → AGENTS.md 심볼릭 링크(ln -s / mklink)** — Claude 공식 문서가 Windows는 관리자 권한 또는 개발자 모드가 필요하니 '@AGENTS.md' 임포트를 쓰라고 명시. 임포트는 Claude 전용 절을 덧붙일 수도 있어 상위 호환.
- **Claude Code /import 또는 /init 으로 AGENTS.md를 CLAUDE.md에 복사** — 1회 복사라 두 파일이 표류함. 임포트는 항상 원본을 읽는다.
- **Gemini context.fileName 을 "AGENTS.md" 단일 문자열로 설정** — 현재 GEMINI.md(MCP 서버 경로·에디터 세션 절차)가 더 이상 읽히지 않음. 배열 ["AGENTS.md","GEMINI.md"] 로 둘 다 유지.
- **전역 ~/.codex/AGENTS.md, ~/.gemini/GEMINI.md 에 '프로젝트 AGENTS.md를 읽어라' 문장을 추가하는 방식으로 해결** — 두 도구 모두 전역 파일을 이미 프로젝트 파일 앞에 결합하므로 문장 추가는 불필요하고, 필요한 것은 부정 줄 삭제뿐. 부정 줄을 남긴 채 긍정 줄을 더하면 상충만 커짐.
- **SessionStart 훅으로 AGENTS.md 내용을 cat 해서 주입** — 세 도구 모두 정적 지침 파일을 이미 로드하므로 같은 내용이 두 번 들어가 토큰만 낭비. Claude 가이드가 명시적으로 CLAUDE.md 사용을 권고.
- **AGENTS.md를 Antigravity .agents/rules/ 규칙 파일로 복제** — 루트 AGENTS.md가 이미 시작 시 파싱되고, 규칙 파일은 12,000자 제한이 있어 확장 여지가 작음. 글롭 범위 규칙이 실제로 필요할 때만 별도 파일로.
- **Codex 스킬을 .codex/skills 또는 $CODEX_HOME/skills 에 두기** — 현행 공식 문서의 탐색 경로는 .agents/skills(저장소), ~/.agents/skills, /etc/codex/skills, 시스템뿐. 하위 호환 언급은 커뮤니티 글에만 있어 미확인.
- **Claude autoMemoryDirectory 를 저장소 안으로 돌려 공유 메모리로 사용** — 프런트매터·MEMORY.md 색인 등 Claude 전용 형식이고 Codex·Gemini는 쓰지 않으므로 공유가 아니라 Claude 메모리를 git에 넣는 것에 그침. 공유 기록은 일반 마크다운으로 별도 운영.
- **하위 폴더별 AGENTS.md(Tools/, Source/ 등) 도입** — Codex만 하위 AGENTS.md를 읽고, Claude는 하위 CLAUDE.md, Gemini는 설정한 이름의 하위 파일을 필요 시점에만 읽어 세 도구의 로딩 시점·파일명이 제각각. 루트 한 파일 + 스킬로 유지하는 것이 관리 규칙에 맞음.

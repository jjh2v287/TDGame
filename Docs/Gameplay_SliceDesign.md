# GP-01 한 판 설계 한 장

상태: 확정(2026-11-18, 사용자 "권장대로 진행"으로 권장안 적용, claude 기록 — 초안 Sonnet, 검토 claude). 레벨 상한만 단계 2 명세 때 확인. 대장 `Docs/Gameplay_Tasks.md`, 계획 `Docs/GameplayFoundation_Plan.md`.

## 1. 핵심 판타지
마을에서 걸어 나가 공터마다 적을 쓰러뜨려 강해지고, 다리 너머 산룡의 둥지에서 용을 쓰러뜨리는 칼잡이가 된다.

## 2. 코어 루프
걸어가서 싸운다 → 이긴다 → 경험치·보상을 받는다 → 강해진다(레벨·주문·물약) → 더 센 싸움으로 간다
- 싸움은 클릭 공격·구르기·밀치기·막기로 예고를 읽고 피한 뒤 반격하는 것이 중심이다.
- 이기면 경험치가 오르고, 첫 승리로 첫 주문이 열린다. 물약은 언제 마실지 고르게 한다.
- 성소는 부활·물약 충전·자동 저장을 한곳에 묶어, 죽어도 멀리 되돌아가지 않게 한다.

## 3. 목표 플레이 시간과 한 판 범위
- 한 판은 30분(20~40분). 싱글 전용, 복제·RPC 없음. 본편은 6~8시간, 반복 포함 10시간 이상(뒷 단계).
- 범위: 마을 → 공터 3곳 → 고원 보스 길(켄타우로스 사냥꾼 다리) → 산룡 둥지(고원 메사).
- 시작 맵은 LV_DarkFantasy_OpenWorld. 지역은 걸어서 이어지고 로딩 화면·순간이동은 없다. 던전은 한 판에서 제외한다.
- 조우는 아레나 열린 모드 하나로 통일한다. 사망 시 손실 없음(성소에서 부활).

## 4. 성장
- 레벨(상한은 임시 10, 단계 2 명세 때 확인) + 주문 해금(시작 0칸, 첫 승리로 첫 주문, 이후 승리마다 해금) + 충전식 물약.
- 장비·전리품은 한 판 이후(단계 6)로 미룬다. 체력을 부풀리는 난이도 조절은 하지 않는다.

## 6. 단계 0~3 관문 (분석서 7절 + 기반 계획 5절)
- 단계 0 (1~2일): GP-01 승인, 결정 묶음, 기준선 준비. 관문: 한 판 명세 승인.
- 단계 1 걸어가서 싸운다 (1.5~2주): 마을 시작, 공터 3곳 조우, Esc 일시정지, 기록기, 구르기·공격 중 주문 결함, 전역 난수 제거. 관문: 마을에서 걸어가 공터 3곳을 손으로 완료, 기록 생성, 난수 검사 초록, 변경 전 기준선.
- 단계 2 강해진다 (1.5~2주): 경험치·레벨, 주문 해금, 물약, 성소, 목표 줄, 스태미나, 상호작용 입구(F). 관문: 싸움 → 경험치·주문 → 강해짐이 닫힘, 성소 부활, 체력 100 치트 없음.
- 단계 3 보스와 저장 (2~3주): 고원 보스 길, 저장·이어하기, 실제 체력 난이도, 예고·구르기·빙결 결함. 관문: 20~40분 완주·종료·이어하기, 사람 2회 + 외부 3명, 방황 ≤90초.

## 7. 하지 말 것
- 한 판에 던전·성소 간 순간이동·로딩 화면·미니맵·NPC 대화·동료·새 종을 넣지 않는다.
- 체력 부풀리기, 공격 스태미나, 경험치 손실 사망, 무작위 수치 접사를 쓰지 않는다.
- 게임 연결 전 유체 효과 범위 확장, 한 판 전 결정론 시뮬레이터 본체 착수를 하지 않는다.
- 블루프린트 그래프 로직, 몽타주·AnimBP·StateTree, 동기 로드, 전투 코드의 전역 난수를 쓰지 않는다.
- 성장 반영에 전체 회복 인수(SetStats 기본값)를 쓰거나 회복을 음수 피해로 만들지 않는다.

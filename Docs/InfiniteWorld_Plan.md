# 무한 샌드박스 세계 가능성 검토 (인덱스)

- 사용자 질문(2026-10-23): "탑다운 게임이지만 무한한 샌드박스형 세계 구현에 대해서 가능성 검토 된다면 어떻게?"
- 결론 정본: [01-feasibility.md](InfiniteWorld/01-feasibility.md) — 맨 앞 '질문에 대한 답'과 0절 한 장 결론부터 읽는다.
- 상태: 가능성 검토 완료, 착수 전 사용자 결정 대기(`Docs/Tasks/decisions.md` D-63, 문서 6절 IWQ-01~20). 로드맵 ID `IW-01~25`·관문 `G0~G5`는 제안이며 아직 대장 항목이 아니다.
- 영역: 월드·던전·PCG(AGENTS.md 12절). 교훈 코드 worldgen·build·repo.

## 한 줄 결론

조건부 가능하다. 허브(월드 파티션 + 랜드스케이프)는 두고 그 바깥을 월드 파티션 밖 C++ 64 m 청크 스트리머로 끝없이 생성한다. 수준 A(무한 생성)·B(설치·건물, 구획 한정)·C(2.5차원 높이 편집)는 조건부이고 완전 복셀은 비권장이다. 엔진보다 콘텐츠 양·단조로움·기존 결정(D-05 보류, GQ-22 미결)이 병목이다.

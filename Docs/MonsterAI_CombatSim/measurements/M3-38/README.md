## 원인 판정
- 래그돌 중 메시를 움직이는 계층(UAF·Mover·루트모션·캡슐): 아님 — 컴포넌트·액터 위치 표본상 캡슐 고정, UAF는 `HoldPoseForDeath`로 비활성, 고주파(프레임 간) RMS는 기준선부터 0.1cm 이하.
- 표현층 오프셋(M3-37 워블·히트스톱 진동): 아님 — `SetPresentationOffset`이 `IsRagdolling`에서 0으로 막힘.
- 물리 에셋: 원인 — 바디 `AngularDamping` 0(12종 중 10종), StoneGolem 손·발 큰 상자 겹침·Paragon `*_Extents`(회전 자유 관절, 경계용)로 시작 튐(말단 1300~2700cm/s).
- 프로젝트 물리 설정: 엔진 기본(잠들기 문턱 선 1cm/s·각 0.05rad/s, 섬 단위)이 엄격해 잔여 움직임이 섬 전체를 깨움 → Config 변경 대신 래그돌 전용 정착 단계로 해결(전역 설정은 다른 물리에 영향).
- 시작 속도·탈침투 150: 평균 속도는 처치 속도(약 350~400cm/s)와 일치, 튐은 말단에서만 → 물리 에셋 쪽 원인.
- 시간 늘이기·히트스톱: 측정 중 전역 시간 배율 최소 1.0(일반 처치), 정착 타이머는 게임 시간 기준이라 슬로모에서 실시간으로 늘어날 뿐 동작 동일(정적 검토).
- 지면 충돌: 바닥 관통 없음(가라앉기 전), 자기 충돌만 끄는 실험은 엔진 한계로 무효(`exp5`, L-editor-37).

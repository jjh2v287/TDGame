# M3-39 래그돌 정착 — M3-38 미측정 경우 (2026-10-19 claude)

도구: `Tools/MonsterAI/pie_measure_ragdoll_jitter.py --task M3-39`(+`editor_ragdoll_jitter_sampler.py`). 맵은 `LV_TDMegaMagicArena`이고 지표 정의는 [M3-38](../M3-38/README.md)과 같다. 새 지표는 다음과 같다.
- 잠들 때마다 재우는 순간 최대 바디 속도(깨어 있던 마지막 프레임, 시료기 프레임 차이로 ±20cm/s 오차)
- 다시 깨어 정착 초
- 슬로모 중 시작(래그돌 1초 안 전역 시간 배율 1 미만)
- 다른 시체 정착

목표(표 마지막 열)는 첫 잠들기 3초 이하(0.1초 점검 간격 때문에 0.05초 허용), 재우는 순간 30cm/s 이하, 다시 깨면 3초 안 재정착이다.

## 시나리오
| 경우 | 방법 | 비고 |

## 판정
1. **빙결:** 결함이 아니다(③). Swordsman의 실패는 빙결과 무관한 종 문제다(지상 대조군도 같음).
2. **슬로모 중 시작(④):** 내부 바디 속도가 1/dt로 커진다. 시작 순간 최대 속도는 GriffonAlpha 팩 에셋 2100~2400 대 700~780, 생성 에셋 1330~1600 대 611cm/s다. 질량 중심 속도는 처치 속도(410·160) 그대로였다. 팩 에셋 GriffonAlpha는 루트 바디가 +265~390cm 튀고, 2/3회는 꼬리·허벅지가 230~420cm/s로 떨며 평균 26cm/s로 기어가 끝내 잠들지 않았다(L-anim-22).
   - 효과 없음: 첫 0.4초 매 프레임 질량 중심 대비 상대 속도 600cm/s 제한 흉내(`emu-flight`), 바디 최대 각속도 720도/초(`emu-angcap-flight`). 튐이 물리 단계 안에서 생기기 때문이다.
   - 진입 시점 문제라 M3-40(사망 시작 경로)에 넘겼다.
3. **3초 상한 경로:** M3-38 규칙(3초 뒤 100cm/s 이하면 재우기)이 35~130cm/s로 움직이는 바디를 멈춰 세운다. 해당 사례는 비행 6/6, 빙결 Swordsman, 더미 StoneGolem·다른 시체 62~69, M3-38 지상 3/26이다.
4. **순차 더미:** 맞은 시체는 0.07~0.15초 안에 13cm/s 이하로 다시 잠든다. 재우기·깨우기가 4~5회 반복되지만 바디 속도가 낮아 보이지 않는다(수정 불필요).

## 수정
- **물리 에셋:** 메시에서 생성한 에셋을 종 `RagdollPhysicsAsset`으로 채택했다(`editor_make_ragdoll_physics_assets.py`, 팩 원본 유지).
  - `PA_TD_Griffon_Ragdoll`(70바디, Griffon·GriffonAlpha 공용), `PA_TD_MountainDragon_Ragdoll`(92), `PA_TD_Swordsman_Ragdoll`(14), `PA_TD_Kwang_Ragdoll`(23)
  - 메모리 실험(`gen-*`) 결과: 시작 튐이 그리폰 지상 950~1950 → 430~550, 산룡 비행 670~1342 → 590~610cm/s로 줄었고, 비행 처치 끝없는 떨림이 사라졌다.
- **정착 C++** `ATDCombatCharacter::UpdateRagdollSettle`:
  - 2.4초부터 감쇠 12(선·각)
  - 3초 뒤 상한 문턱 100 → 30cm/s
  - 4초 뒤 질량 가중 평균 속도 15cm/s 이하면 재우기(제자리 떨림 정지)
  - 흉내 실험 `emu-ground`·`emu-pile3`에서 상한 직전 최대 속도가 최대 128 → 35cm/s 이하로 줄었다.
- **Kwang:** 물리 에셋만 붙였다. 종 표 `ragdoll_after_death`는 False로 둬서 지금은 사망 클립만 재생한다. 사망 즉시 래그돌(M3-40)이 들어오면 이 에셋을 쓴다. 강제 측정 2/2 목표, RMS 0~0.5cm.

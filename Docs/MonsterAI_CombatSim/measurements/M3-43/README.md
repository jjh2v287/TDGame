# M3-43 몬스터 논리 회전(캡슐) 가감속 — 판정선·결과

사용자 선택(2026-11-20, 07#MD-63 (b) "캡슐도 부드럽게"): M3-42 의 보이는 몸 오프셋 대신 캡슐(액터 요·Mover 방향) 자체가 가속·감속하며 돌고, 메시는 캡슐의 자식으로 그대로 따라 돈다.

## 1. 바꾸는 것과 방향에 기대는 로직

- 바꿈: `ATDMonsterCharacter::ProduceInput_Implementation` 이 Mover 에 넘기는 방향 의도(OrientationIntent)를 `FTDTurnSmoother`(임계 감쇠 0.06초, 최대 = TurningRate 540도/초 그대로, 가속 한도 8000도/초², 1/240초 하위 단계)로 다듬는다. 의도가 없으면 되돌아감 없이 멈춘다(정지 목표 = 현재 요 + 각속도×0.03초). 다른 코드가 즉시 돌리면(차이 1도 초과) 그 요에서 각속도 0으로 다시 맞춘다. 공격 시작 `FaceRotationImmediately` 는 `SetDesiredFacingDirection(조준)` 으로 바꿔 시전 준비 동안 돈다. 끄기 `TD.Monster.SmoothTurn 0` = 이전 논리(등속 540도/초 + 공격 시작 즉시 회전). 보이는 몸 층(`TD.Monster.VisualTurn`, 메시 오프셋, 틱 그룹 변경)은 걷어낸다.
- 방향에 기대는 로직(조사 `Saved/AgentOps/20261120/turn-popping/logic-facing-research.md`): FacingTarget 입력(Goblin_Melee·Swordsman·Wukong·Kwang·Griffon·Greystone 의 공격 점수에 곱함, 커널 Body.Yaw = 액터 요)만 결과를 바꾼다. 피해 엔티티는 Origin→Target 으로 정해지고 시전자에 붙지 않으며, 막기·뒤치기·시야 원뿔은 없다.
- 밸런스 시뮬레이터(M1-06~12)는 미구현이다. 그래서 고정 스텝(1/64초) 헤드리스 결투를 끔·켬으로 돌려 비교한다(시험 `TDGame.MonsterAI.TurnSmoothing.DuelComparison`).

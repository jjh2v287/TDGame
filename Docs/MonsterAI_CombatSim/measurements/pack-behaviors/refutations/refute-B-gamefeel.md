## 주요

### B-1 사기: 손실 기억이 '창'이 아니라 '사슬'이라 모든 무리가 사상자 1/3 지점에서 반드시 무너진다
- 근거: 명세 2.4-1 `RecentLossCount = (Now - LastLossStep <= 512) ? +1 : 1` — 직전 손실에서 8초 안이면 계속 누적한다. 전투 중 처치 간격은 거의 항상 8초 미만이라 사실상 전투 전체 누적이다. 판정 2k >= 1 + (N-k-1) 은 3k >= N (k >= 2)과 같다. 대기 고리 350/550(TDCombatTactics.h:149-152)이라 무리 지름 <= 1,100 < 목격 반경 1,200 → 전원이 모든 사망을 목격한다.
- 장면: 고블린 3·5·8·12·20 → 각각 2·2·3·4·7마리째 처치에서 생존 1·3·5·8·13마리 전원 공황. 명세 5절 S2의 세 처치 모형(범위 1초 3 / 꾸준 1.5초 1 / 느림 4초 1)이 모두 같은 사상률에서 터지고 시점만 다르다(느림 4초 < 8초라 사슬 유지).
- 체감: 공황이 '큰 한 방의 보상'이 아니라 매 전투의 고정 박자(1/3 지점 흩어짐 → 1~2초 화면 밖 → 복귀)가 된다. 무리 수십 개를 도는 핵앤슬래시에서 같은 연출 반복 = 맥 빠짐·청소 속도 세금. 고블린 3의 마지막 1마리 공황(Pressure 4 >= Support 1)은 '혼자 남은 놈이 도망' 패턴이다.
- 수정안:
  1) 손실을 고정 창으로: `LossWindowSteps = 192`(3초) 안의 사망만 센다(목격자별 최근 사망 스텝 링 4칸, 정수). D2 Fallen "근처에서 누가 죽이면 1~2초"(문헌 §3.4)·Halo 사건 반응(§3.5)에 맞다. Days Gone의 긴 감쇠(§3.6)는 무리 평균 사기용이지 개체 공포 트리거용이 아니다. 효과: 느림 처치 공황 0, 꾸준 처치는 잔당 4~6 이하일 때만, 범위 처치(고블린 12: 2초 뒤 L=6, A=5 → 12 >= 6)는 붕괴 → 공황이 폭발 처치의 보상이 된다.
  2) 홀로 남은 개체 제외: 우두머리 충격이 아니면 `Support >= 2`(비공황 아군 1 이상) 필요. 혼자 남은 저체력 개체는 MD-43 Flee가 맡는다.
  3) 결속을 교전당 1회로: `RallyImmuneUntilStep`을 귀환(BeginReturn)까지 유지. 지금은 시작 후 12초(128+640스텝)에 면역이 풀려 30초 넘는 큰 무리 전투에서 재공황한다.
  4) S2에 합격선 추가 [추론]: 꾸준 처치에서 공황 발생 무리 비율 <= 1/3, 느림 0, 범위 처치 >= 2/3. 현재 S2는 측정만 하고 합격선이 없다.

### B-2 MD-43 Flee: '저체력'이 아니라 체력 77%(혼자)·91%(베기 쿨다운 중)에서도 1.5초 후퇴를 반복한다
- 근거: `Content/MonsterAI/Definitions/Goblin_Melee.json` Flee = 3.0 x (1-h^2) x (1 - 아군/4) x 거리 Logistic(m -12, c 0.35). 대상 140cm에서 거리항 약 0.94, 베기 = 2.0 x Logistic(-12, 0.14) 약 1.14, 베기 쿨다운 중 접근 약 0.40. Flee > 베기 ⇔ (1-h^2)(1-n/4) > 0.40 → 아군 0: h < 0.77, 아군 1: h < 0.68, 아군 2: h < 0.44. 베기 쿨다운(1.2초) 중엔 아군 0: h < 0.91. 명세 2.6은 체력 곡선을 그대로 둔다.
- 장면: 고블린 5 중 2 처치 → 남은 셋 B-1 공황 1~2초 → 복귀 → 체력 60~80% 개체가 혼자·둘이면 6초마다 1.5초(462 x 1.5 = 약 690cm) 물러났다 약 1.65초 걸어 돌아온다. 6초 중 공격 가능 약 2.85초(48%). 결속 면역은 Flee(효용 행동)를 막지 않아 공황과 겹친다.
- 체감: 소규모 전투 막판이 '깔짝 후퇴' 반복으로 늘어진다. 명세 2.6 효과 목표("저체력 고블린이 1.5초 물러섰다 4.5초 이상 싸운다")가 실제로는 다친 고블린 대부분에 적용되고, 4.5초 중 1.65초는 복귀 보행이다.
- 수정안: 같은 데이터 편집에서 체력 고려를 `{ "input": "SelfHealthRatio", "curve": "Logistic", "m": -20, "c": 0.3 }`로 교체(30% 0.5, 35% 0.27, 50% 0.02) → 혼자일 때 Flee는 체력 약 32% 미만(베기 쿨다운 중 약 38% 미만)에서만. 쿨다운 6은 유지 가능. B6 합격선을 "30초 중 MoveAway 시간 <= 30%, 베기 시전 >= 8"로 강화(현재 '시전 >= 1'은 루프가 있어도 통과).

### B-3 하이에나 돌진자: 4~6마리 무리의 공격 빈도가 절반이 되고, 대기 중 하이에나는 맞아도 반격하지 않는다
- 근거: 기본 토큰 `clamp(max((N+1)/3, min(N,2)), 1, cap)`(TDCombatTactics.cpp:87) → N = 4·5·6에서 근접 2. 명세 3.2 돌진자 상한 1 → 하이에나만 있는 무리는 2 → 1. 감독 예산(ComputePoolTokens, cpp:97-105)이 이미 1인 구간 밖에서는 항상 절반. 명세 3.2 "보복 가로채기: 상한에 걸린 후보 제외".
- 장면: 하이에나 6 포위. 한 마리만 물고(공격력 6, 쿨 2.0) 다섯은 반경 약 335 대기 고리(150+150+몸통, 하한 320, cpp:180)에서 선회. 플레이어가 고리의 하이에나를 근접으로 때려도 보복 토큰을 못 받아 계속 선회한다.
- 체감: 하이에나 위협은 '수'인데(Diablo IV swarmer, 문헌 §3.3) 6마리 = 1마리 공격 속도 x 6배 체력이 된다. 선회하는 다섯은 반격 없는 샌드백 → 무료 타격 악용. 문헌의 돌진 1(§4-1, §6 순위 3: Amalur 돌진 6/용량 10)은 '돌진 계열 공격'의 무게 제한이지 종 전체 동시 공격 1이 아니며, 하이에나에는 별도 돌진 능력이 없다.
- 수정안: (a) 이번 작업은 Hyena `Melee` 유지, 돌진자 규칙은 역할 리터럴 시험(C1)으로만 검증하고 Hyena 지정은 S4 결과로 MD-48에서 결정. 합격선 [추론]: 하이에나 4·6 무리의 초당 공격 시작이 기존의 0.75배 이상. (b) 지정한다면 보복은 상한 예외(RetaliationSteps 64 동안 상한 +1) 또는 Reserved(미시전) 보유자에게서 빼앗기(Amalur 28.6.1 '빼앗기 허용·공격 중 잠금', 문헌 §4-3·§5).

### B-4 경보 파문·공황이 기본 카메라에서 화면 밖에서 일어나 '보이지' 않는다
- 근거: 발견 반경 1,500(TDMonsterThinkSubsystem.h:56)과 1·2단 기상 개체(발견자에서 +900·+1,800)는 위 카메라 가정에서 전부 화면 밖. 공황: 고리 350에서 1~2초 x 420 → 770~1,190cm로 북·좌우 경계를 넘고, 남쪽은 이미 경계(약 390) 근처. 명세는 연출 진입점(GetMonsterAlarmRole·IsMonsterPanicking)과 디버그 문자열만 둔다. 공황 속도 1.0은 고블린 Flee 1.1보다 느려 평범한 후퇴·Backpedal과 같은 모습이다.
- 장면: 플레이어가 무리에 다가가면 화면 밖에서 8~16스텝 간격 기상이 일어나고, 화면에는 거리 순 도착만 보인다(거리 300cm 차 = 0.71초 차 > 홉 지연 0.125~0.25초). 공황 무리는 화면 가장자리 밖으로 사라졌다가 돌아온다.
- 체감: 문헌 §6 순위 2의 체감 근거("파문이 보임")와 §4-6("사기·공포는 과장해야 읽힌다", Halo는 과장 애니메이션 전엔 아무도 몰랐다 §3.5)를 충족하지 못한다.
- 수정안: (범위 안) `FearSpeedScale` 1.0 → 1.2(고블린 504 < 플레이어 600이라 추격 시 막힘 규칙으로 여전히 끝남). 공황 후퇴는 대상 거리 `PanicHoldDistanceCm` 700 도달 시 이동을 멈추고 남은 공포 스텝 동안 제자리 대기(정체 판정 대신 시간 제한 유지) → 화면 안 '움츠림'. 홉 지연 8~16은 화면 밖이라 유지 가능, S1에 '화면 안 첫 도착 간격' 지표 추가. (후속) Caller 3D 외침 소리(화면 밖 전달 수단은 소리뿐, 무리당 1)·공황 시작 외침/움찔. MD-48에 "연출 연결 전 Tactics 켜짐 출하 금지" 조건 기록 권장.

### B-5 한 방에 죽은 Home 몬스터는 발견자도 목격자도 되지 않는다(조용한 저격·풀링)
- 근거: OnDamaged → `NotifyMonsterDamaged`가 `PendingAlertSlots.AddUnique`·Engage(TDMonsterThinkSubsystem.cpp:368-372) → 같은 `ReceiveDamage` 안 OnDeath(TDCombatComponent.cpp:373→389) → `StopMonsterBrain`(TDMonsterCharacter.cpp:181) → `UnregisterMonster`가 `PendingAlertSlots.Remove`(cpp:347). 다음 스텝 UpdateEngagement에 발견자가 없다. 명세 2.4-1 목격자는 Engaged만이라 Home 동료는 사망도 무시. 명세 1.2 "피격으로 Home→Engaged가 된 몬스터"는 치명 피격을 다루지 않는다.
- 장면: 발견 반경 1,500 밖(화면 밖)으로 날아간 투사체·메테오가 Home 고블린을 한 방에 죽임 → 900 안 동료는 Home 그대로, 경보·사기 모두 없음 → 무리를 한 마리씩 지운다.
- 체감: 새 경보 연쇄가 '들킴'을 강화하는 기능인데 가장 큰 신호(동료의 죽음)를 무시한다. 사거리 1,500 초과 공격이 있을 때만 성립(플레이어 주문 사거리 미확인).
- 수정안: `UnregisterMonster`에서 사망 + 전술 활성 + PendingAlertSlots 포함(이번 스텝 피격)이면 `{위치, 공격 대상}`을 사망 경보 발견자로 남겨 ②단계에서 그 위치 기준 1단 예약(호출자 판정 동일). 시험 A4 "Home 고블린 한 방 처치 → 900 안 동료 16스텝 안 교전" 추가.

### B-6 큰 피격(최대 체력 12%) 경직이 공황을 즉시 끝내, 범위·근접 빌드에는 공황이 거의 안 보인다
- 근거: Damage >= MaxHealth x 0.12면 `EnterStagger`(TDMonsterThinkSubsystem.cpp:374-380, h:64) → State = Stagger로 후퇴를 덮어쓰고 0.35초 뒤 Idle·강제 사고(TDMonsterActionExecutor.cpp:117-142, h:31). 고블린 120 → 14.4 이상 한 대면 경직. 명세 2.5는 공황 중 경직을 정하지 않는다(2.4-4 '비경직'은 시작 조건만).
- 장면: 범위 공격이 1/3을 죽이고 나머지를 경직 → 0.35초 뒤 공황 시작 → 다음 범위 공격(0.5~1초)의 경직으로 공황 종료 → RecentLossCount 0·결속 12초라 재공황 없음.
- 체감: 공황 가시 시간 약 '다음 큰 피격까지'. 원거리 단일 대상 빌드만 공황을 본다. 작은 피격(<12%)은 후퇴를 안 끊어 도망치는 적을 공짜로 때린다(D2 방식이라 허용 가능).
- 수정안: 의도를 명세에 적는다. 권장: 공황 중 경직은 남은 공포 스텝을 보존하고 경직 끝에 남은 스텝 >= 16이면 후퇴 재개(경직 반응과 공황 둘 다 보임). 아니면 '피격 시 공황 해제'를 명시하고 S2에 '공황 가시 시간' 지표를 넣는다.

## 경미

### m-1 전염 가중이 Days Gone보다 크다(공황 1마리 = 3점 이동)
- 근거: 명세 2.4-2 Pressure에 공황 아군 x2 + Support에서 빠짐 = 3점. Days Gone은 공황 개체 힘을 '적 편에 더함'(문헌 §3.6) = 2점.
- 장면: 고블린 12, 3마리 동시 사망(L=3, A=8): 6 < 9로 버팀 → 가장자리 1마리가 공황하면 다음 스텝 8 >= 8로 손실 2+ 목격자 전원 공황(이분법적 붕괴).
- 수정안: Pressure = 2 x RecentLoss + 공황 아군(가중 1). 같은 장면에서 연쇄에 2마리 필요.

### m-2 정예를 종 표식으로 두면 브루트 여러 마리 무리에서 우두머리 충격이 반복된다
- 근거: 명세 2.2 `elite` = 종 JSON 키, 우두머리 사망 = 1,600 안 비면역 전원 공황(비율 무시), MD-48 제안 BookHead_Brute elite. 출하 7종 모두 team 2라 종 무관 전파.
- 장면: 브루트 2 + 캐스터 3에서 첫 브루트 사망 → 살아 있는 브루트(지지 2배)가 있는데도 전원 공황.
- 수정안: 우두머리 충격은 목격자 1,600 안에 다른 생존 면역 개체가 없을 때만.

### m-3 우두머리 사망 공포 1~2초는 '움찔'로 읽힌다
- 근거: Halo(§3.5)·무쌍 지휘관(§3.9)은 우두머리 사망을 큰 사건으로 다룬다. 명세는 일반 공황과 같은 64~128스텝.
- 수정안: 우두머리 충격만 128~192스텝(명세 5절 민감도 범위 안). 무리당 1회라 반복 피로가 낮다.

### m-4 2단 도달 1,800cm가 이웃 무리를 연쇄로 깨울 수 있다 [미검증]
- 근거: 1단 900 + 2단 900, 끈 3,000(명세 1.2). 무리 간격은 월드 생성 값이라 확인 못 함. 깨어난 B 무리 가장자리가 직접 발견하면 새 0단이 되어 다시 2단 전파.
- 수정안: S1에 실제 스폰 간격 배치를 넣어 '다른 무리 기상 비율'과 '늦게 도착하는 낙오(도착 간격 > 3초) 수'를 측정.

### m-5 호출자 1명 규칙이 서로 다른 종의 두 무리를 하나로 묶는다
- 근거: 명세 1.2 조건(같은 대상·1,800·3초)에 종 조건이 없다.
- 장면: 고블린 무리와 하이에나 무리가 1,800 안에서 함께 발견 → 고블린 외침 하나로 하이에나까지 깨어남(연출 연결 시 소리 불일치).
- 수정안: 조건에 '같은 DefinitionId 또는 같은 extends 뿌리' 추가, 또는 연출 단계(후속)에서 처리.

### m-6 원거리 띠 간격 150이 궁수 몸통을 빼지 않고, 띠를 화면 밖으로 민다
- 근거: 대기 고리 = 사거리 + 150 + 근접 몸통(TDCombatTactics.cpp:180), 바닥 = 고리 + 150 → 궁수 몸통 반경을 빼면 실제 틈 약 70~80cm(근접 메시가 캡슐보다 크면 더 작음). 바닥 640~800은 남쪽(약 390)·좌우(약 800) 화면 경계 밖.
- 수정안: 간격 = 150 + 원거리 몸통 반경, 바닥 상한 `min(MaxReach - 100, 700)`(좌우 800 - 여유 100) [추론]. 사거리 밖으로 밀리지는 않음은 확인(상한 MaxReach - 100 → 띠 최대 900 = 사격 900).

### m-7 하이에나 Flee 거리 기준 450cm가 대기 고리(약 335) 안이라 선회 중 저체력 개체가 빠졌다 들어온다
- 근거: 명세 2.6 Hyena Logistic c 0.3 x 1,500 = 450, 대기 고리 하한 320.
- 장면: 아군 0~1인 저체력 하이에나가 물기도 안 했는데 고리에서 840cm 달아났다 복귀 → 치고 빠지기(물고 Circle 230~360)와 다른 큰 이탈로 보인다.
- 수정안: c 0.15(225cm, 물기 접근 거리)로 낮춰 물러남을 '물고 난 직후'로 한정.

### m-8 지원(Support) 역할이 공황 면역이 아니다
- 근거: 문헌 §3.4 "주술사는 도망 안 감", §6 순위 4 "지원 역할 면역". 명세 2.2 면역 = boss·elite만.
- 수정안: 지원 종이 생길 때(후속) `bIsImmune |= Role == Support` 검토. 이번은 MD-48에 메모만.

## 확인한 비문제
- 도망치는 적 쫓기: 플레이어 600 > 공황 420·Flee 462·하이에나 560이라 추격하면 거리가 30cm 넘게 늘지 않아 24스텝(0.375초) 뒤 막힘 규칙으로 맞서 싸운다. 쫓기 짜증은 작다(정지한 원거리 플레이어만 1~2초 대기).
- 공황으로 끈 이탈: 집–대상 <= 3,000 + 고리 350 + 후퇴 최대 1,008(1.2배 가정) < MaxChaseDistanceFromHome 4,500(h:60) → 공황발 귀환 없음.
- 풀링 난이도: 기상 범위 900 → 1,800으로 어려워짐(B-5 구멍 제외). 지연 동안 플레이어가 예약을 취소할 수단 없음(검증 조건은 몬스터 상태·끈, 600cm/s로 0.25초 안에 끈 3,000을 벗어날 수 없음). 깨어나면 Engage가 강제 사고(cpp:1181)라 사고 주기 지터 없음.
- 선회 대 대기 고리: 하이에나 고리 약 335, Circle 띠 230~360 — 같은 반경대라 '고리를 도는 무리'로 일관되게 보인다.
- 시전 중 공황 대기(명세 2.4-4)는 공격 확정 뒤 취소를 막아 공정하다.

## 2. 시험별 지적(시험·줄 → 놓치는 것 → 보강안)

- **A1 822-825**: 창 [8,16]이 넓어 거리 무시 상수 지연(8 또는 16)과 원점 대신 대상 거리로 계산하는 변형이 통과한다. 700cm면 8+8×700/900 = 14 → `DelayAB`·`DelayBC` ∈ [13,15]로 좁힌다.
- **A2**: 판별력 충분. 선택 사항: 디버그 문자열 대신 공개 `GetMonsterAlarmRole`로도 같은 결론을 단언한다.
- **A3**: 판별력 충분. CVar는 Scenario보다 먼저 선언한 ON_SCOPE_EXIT로 원복된다(월드 파괴 뒤 복원, 정상).
- **A4 935-937**: 하한이 없어 사망 경보 지연 0(즉시 교전)이 통과한다. 기대 TicksAfterKill = 14(600cm → 13 + 표본 보정 1) → `≥ 9`를 추가한다.
- **B1 969-972**: 공포 길이 미확인이라, 우두머리 충격에 일반 공포(64~128)를 쓰는 변형과 `BeginRetreat`가 Steps를 무시하는 변형이 통과한다. `IsMeasuredRetreat`(498-501)의 `DistanceGain > 0`은 너무 느슨하다(서 있는 개체도 회피 밀림으로 +수 cm). 보강: 공황 개체마다 최장 런 ∈ [126,194], DistanceGain ≥ 150, 공황 표본의 대상 거리 최대 ≤ 760(움츠림 700 + 1스텝 7.9cm + 회피 여유)을 단언한다.
- **B2 1005-1008**: 상한 147(=128+19)만 있고 하한이 없다. 런 ∈ [62,130]과 위와 같은 거리 상한 ≤ 760을 단언하면 움츠림 무시가 확정적으로 잡힌다. 첫 처치와 둘째 처치 사이 공황 0도 확인하지 않는다(993은 교전 여부만 본다).
- **B3 1043·1047 / B3b 1078·1082**: `CountPackPanicSamples`(471)가 `panic`만 센다. 공포에 들어갔지만 시간 제한 후퇴가 아닌 상태(fear 표시)로 실제 도주하는 변형이 "공황 0"을 통과한다 → `Morale != "steady"` 표본 0으로 바꾼다. B3b 간격 4초(1071)는 창 80과 거리가 멀어, 명세 S2의 "꾸준 처치(1.5초당 1)"인 96스텝 간격으로 바꿔야 창 192 회귀가 잡힌다.
- **신규 B7(놓침 2건)**: (i) 고블린 3, 16스텝 간격 2마리 처치 → 혼자 남은 개체 morale이 끝까지 steady. (ii) 고블린 6 링 470, 2마리 처치 → 공황 → 회복(rallied) 확인 뒤 같은 교전에서 2마리 더 처치(남은 2: Support 2, Loss 2 → 결속이 없으면 공황) → 새 panic 런 0.
- **B4 1103**: 표본 {10,5}cm는 진행 문턱 30을 0으로 바꾼 변형을 못 잡는다. 1cm/스텝 표본을 추가해 24~26에 Idle이어야 함을 단언한다(30cm 진행 전에 정체 24 도달).
- **B5**: 판별력 충분.
- **B6**: 판별력 충분(빨강 Returning 712·연속 578).
- **C1·C2 675-721**: (i) 단일 역할이라 break 변형을 못 잡는다 → 혼합 장면 추가: 돌진자 2(반경 550, 정렬 앞) + Melee 2(650)에서 "돌진자 보유 1인 스텝 중 ≥ 50%에 Melee 보유 ≥ 1" + Melee 둘 다 시전 ≥ 1. (ii) 피격이 없어 보복을 못 잡는다 → 비보유 돌진자에게 `PackProbeHitDamage`를 주고 64스텝 안에 보유 2를 허용·관측(== 2), 그 밖의 스텝은 ≤ 1. (iii) C2는 빨강에서도 동시 시전이 1이라 718은 판별력이 없다(보유 717만 유효). `MaxHolderCount == 1` 양성 대조도 추가한다.
- **C3 80-82·1246**: 하한 620은 관측 641·명세 바닥 670보다 느슨해, 자기 몸 반경을 뺀 바닥(630)도 통과할 수 있다. 상한 무시는 단언이 없다 → `FTDCombatTactics::ComputeRangedBandFloor` 단위 단언: (650,40,900) == 700, (650,40,750) == 650, (0,40,900) == 0.
- **C4 1257**: elite 값 저장을 확인하지 않는다 → `Definition->bIsElite`, `FTDPackMorale::MakeFragment(...)`의 bIsLeader·bIsImmune(elite: 둘 다 참, Support: 면역 참·우두머리 거짓)을 추가한다.
- **G1 723-748·1286**: 해시가 같다는 것만 보고, 그 장면에서 공황·hop2·돌진자 보유가 실제로 일어났는지 단언하지 않는다. 추정으로는 A·B가 합류해 Support가 4~5라 공황이 경계적이다 → 공황 경로의 결정론이 검증되지 않을 수 있다. 보강: morale ∈ {fear,panic} 표본 ≥ 1, alarm=hop2 ≥ 1, 돌진자 보유 ≥ 1.
- **G2 750-778**: 각 목록이 원소 ≤ 1개(피격 1, 사망 1)이다. `NewlyEngaged`가 OrderedSlots 순회로 쌓이므로(cpp 648) 정렬 제거 변형도 못 잡는다 → 같은 프레임에 비치명 2 + 치명 2를 역순으로 주는 표본으로 바꾼다.

# 명세 v2.1 변경분(spec-v2.md 위에 덮어씀)

근거: 파이썬 결정론 시뮬 v2 재검증(`Tools/scratch/20261018_claude_m314_tactics/v2_report.md`, 조합 B: 정지 최장 굶음 21.0초, 이동 27.3초, 30초 안 전원 공격, 만료 43회).

1. 후보 조건의 사거리 여유: "사거리 ≥ (현재 거리 − 300)" → "사거리 ≥ (현재 거리 − 500)". (둘째 대기 고리 몬스터가 영구히 후보가 못 되던 결함)
2. 예약 만료: ReservationExpirySteps 160 → 256. 만료 회수 벌점은 RegrantReadyStep = StepIndex + 48 만 적용하고 LastAttackEndStep 은 바꾸지 않는다(대기 나이 유지). 거리 초과·MoveAway 회수도 같다.
3. WaitRingMargin 200 → 150(고블린 대기 반경 160 + 150 + 40 = 350, 둘째 고리 550).
4. MaxTokensPerTarget 8 → 5(근접+원거리 합 상한, 근접 상한도 5). 동시 시전은 시작 간격 때문에 실제 약 4가 상한이라 초과 토큰은 만료만 만든다. 기본 토큰 표: 근접 N 1 → 1, 2~7 → 2, 8~10 → 3, 11~13 → 4, 14 이상 → 5.
5. 원거리 막힘 감지: 거리 대신 각도 기준. 원거리 칸에서 각도 오차 > 반폭 이고 64스텝 동안 오차가 2° 넘게 줄지 않으면 막힘. 대기 칸은 거리 기준 유지.
6. 남쪽 원거리 칸: SouthBandRadius(340) 규칙 삭제(띠 최소 500보다 작아 도달 불가). 남쪽 가산(+90°)만 유지.
7. 보스 차선: 보스는 졸개를 기다리지 않는다(보스 허가 = 보스 자신의 능력 쿨다운뿐, 시작 간격 없음). 졸개는 보스 시작 뒤 BossSpacingSteps(24) 동안 시작 금지. 보스 시작은 LastBossStartStep 만 갱신한다(LastAttackStartStep 은 졸개 시작만).
8. 큰 피해 기준: 64스텝 미끄럼 창 ≥ 200‰ → ≥ 160‰.
9. 시험 기대 갱신: `BudgetFormula` 표는 위 4번, `BossLaneNotStarved` 보스 시전 간격 ≤ 쿨다운 + 64스텝(정지 대상).

## 0. 한 화면 요약

- **가능 여부**: 가능하다. 루트 캡슐을 유지하고 길쭉함은 커널 조향 단계(`ApplySeparation()`, `TDMonsterThinkSubsystem.cpp:350·511`)의 순수 함수로만 다루며, 몸 회전 규칙과 충돌 채널 정리를 함께 할 때다.
- **왜**
  1. [측정] 현행(G0) 하이에나 교차(H2) OBB 겹침 17.8%·최대 71.8cm → 직사각형 VO(G1~G5) 0.2~0.7%·4.1~10.2cm(목적지 이동, avg).
  2. [측정] 조향 가중치 9종을 하나씩 ×0.5·×1.5 한 54행 모두에서 G0이 겹침 최하위.
  3. [측정] 캡슐 막힘이 측면 이득을 지운다: 나란히(H1) 측면 중심 간격 G0 86.0 / G1 89.2 / G3 80.3cm(목표 80).
  4. [추론, 벤치 산술] 하이에나 40만 C, 고블린 240 격자 원 분리 = 0.27(성긴)/0.50(밀집)ms/프레임으로 03 근접 처리 두 행 추정 1.06~1.46ms보다 작다. 전원 형상 회피는 1.56~7.03ms [측정]라 불가.
  5. [확인] 회전에는 충돌이 없다. OBB 발자국은 충돌 형상이 아니고(세로 캡슐 + Pawn을 무시하는 `CharacterMesh`, `TDCombatCharacter.cpp:83·99`), 이동 입력은 단위 방향이라 저속에서도 몸이 540°/s로 돈다(`:407-414`).
- **권장 구조**
  1. 루트 캡슐 유지, 길쭉함은 조향 순수 함수(`TDShapeAvoidance`)만.
  2. 종 JSON `body.avoidance` 3등급: `circle`(현행) / `box`(하이에나, C) / `box_rotating`(대형, D_esc).
  3. 몸 자세: 정지 의도는 VO 생략, 반발만 있는 명령은 몸을 돌리지 않음, 큰 회전(정지 바라보기·시전 시작·물기 후 후퇴) 전 목표 yaw OBB 검사.
  4. 물리: 목표 G3(형상 종끼리 캡슐 무시 + 엔진 프로필 응답 명시), 결정 전 G1.
  5. 결정론: 스텝 시작 스냅샷만 읽고 자기 슬롯에만 쓰는 순수 함수, (보수 충돌 시간, SimulationId) 정렬, 골든은 에디터 타깃.
- **첫 단계**: M3-18(보완 측정 + 프로토·벤치를 `Tools/MonsterAI/`로 승격). Source·Config·Content 무변경.
- **사용자 결정**: MD-25~MD-39, 07#MD-09·07#MD-10 재개 때 선택지 추가(6절).

가능하다. 조건: ① 루트 캡슐 유지(4.1) ② 종별 3등급(4.3, 전원 형상 회피는 1.56~7.03ms/프레임 [측정]) ③ 하이에나끼리 캡슐 막힘 해제(G3)가 목표, 새 채널은 엔진 프로필 응답 명시와 한 묶음(4.1-2) ④ 큰 yaw 변경 전 목표 yaw OBB 검사(4.2-4, 4.5) ⑤ 정지 거리 150cm(현행 115는 코가 플레이어를 37.6cm 파고듦 [측정]) ⑥ 장애물 속도는 측정 구성인 32스텝 평균이 기본(4.3 C-2) ⑦ 결정론 규약(4.7) ⑧ 예산은 03 두 행 1.06~1.46ms 기준, 판정은 게임 몸 PIE 카운터(4.8, 카운터는 M3-19가 4.6 #19로 만든다).

**게임 두뇌가 프로토 S8과 다른 점** [확인]
- 동시 시전 토큰은 대상당 3(`TDMonsterThinkSubsystem.h:62`), Cast 상태만 센다(`.cpp:581-605`). 토큰이 없거나 재사용 대기(2초, `Hyena.json:4`) 중이면 `AbilityReady` = 0(`.cpp:710-716`)이라 Circle(`MoveToBand` 230~360cm)을 고른다.

- 그래서 S8(6마리가 정지 거리까지 몰림)은 과장된 스트레스 지표이고, '물기 후 후퇴 반전'이 가장 잦은 큰 회전이다. 수용 지표는 '대상당 10초 물기 수'와 '반전 중 새 OBB 겹침'.

## 3. HZD 방식 요약과 탑다운에서 달라지는 점

### 3.1 HZD 방식(`Saved/AgentOps/20261014/hzd_ch09.txt` 줄)
- 형상(10-18): 원은 길쭉한 로봇 사이를 너무 벌린다 → 직사각형 VO. 회전(29-46): 현재 자세(처음 방향)의 회전 직사각형 두 개로 민코프스키 합 VO를 만들고, 회피 속도를 고른 뒤 몸이 도는 방향 변화는 VO에 반영하지 않고 장애물 근처 회전 벌점으로 줄인다(출시판도 '아주 가끔' 관통).
- 장애물(55-112): 보수 충돌 시간(식 1~3, 분모 = 내 최대 속력 + 장애물 속도의 나를 향한 성분) 순 ≤5, 뒤쪽 120°·낮은 우선순위·목적지 너머 제외. 우선순위(98-105): 높은 등급은 낮은 등급을 무시, 정지한 낮은 등급은 위험 구역에서 비킴.
- VO(138-184): 직사각형 민코프스키 합 접선 원뿔을 장애물 속도만큼 이동, 시간 절단 없음. 점수(188-287): 결합 VO 경계 꼭짓점·교점·최근접점·속력 원 교점, 식 4 = (1−g_r)(400α_s+50β_s+70γ) + 0.5(1−g_t)(400α_a+50β_a)(저자는 그대로 쓰기보다 참고만 하고 자기 식을 쓰라고 함).
- 해제(295-298): 유효 후보가 없으면 정지, 잠시 뒤 희망 속도. 장애물 속도(303-306): 0.5초 평균. 기타(325-334): 360° 고리 감지 후 정지, 원·직사각형 혼합 시 원을 직사각형으로.
- 정적 지형(335-350): 오픈 월드라 무시, 좁은 게임은 내비 모서리 선분 VO 권장. 비용(352-354): PS4 밀집 약 60µs/개체. 경고(371-375): 차량 같은 움직임, 애니메이션 우선 경로 추종과 충돌.

4. **조기 종료**: 희망 속도가 모든 원뿔 밖이면 그대로.
5. **줄서기**(`:169-197`): 선택 장애물 중 희망 방향 앞(측면 ≤ 반폭 합 + 20cm)의 가장 가까운 몸이 반대로 오지 않고(진행 성분 ≥ −20cm/s), 정지(<20cm/s)면 인내 1.5초[가정] 안에서 v = 방향 × clip(앞 몸 진행 속력 + 2 × 틈, 0, 희망 속력). 원뿔 밖이면 채택.
6. **경계 후보**: 결합 VO 꼭짓점, 각 변과 '희망 방향 × 최대 속력' 교점, 희망 속도 최근접점, 속력 원(희망·최소·최대) 교점. 최대 속력 초과·원뿔 안은 버린다.
7. **점수**(HZD 식 4 변형, `horizon_cost_weighted` `:132-150`)
   - 비용 = (1 − d)·[(1 − k)(2α_s + 1β_s) + k(2α_c + 0.5β_c + 2γ) + 0.5α_s] + d·(2α_s + 1β_s)
   - α_s = |후보 각 − 희망 각|/π, β_s = |후보 속력 − 희망 속력|/최대 속력, α_c = |후보 각 − 몸 yaw|/π, β_c = |후보 속력 − 현재 속력|/최대 속력, γ = |ω| > 0.2rad/s이고 후보가 각속도 반대로 돌면 α_c, 아니면 0.
   - k = max(정지 근접, 동적 근접). 정지 근접 = 정지 장애물(<20cm/s)에 clamp(1 − (희망 방향 광선 진입 거리 / 희망 속력)/2), 동적 근접 = clamp(1 − SAT 최대 간격/100cm)(`avoid_sim.py:676-683`). d = clamp(1 − 목표 거리/300cm, 0, 1).
   - 끝의 0.5α_s는 측면 편향이 아니라 희망 각 편차를 한 번 더 더하는 항. 동률은 후보 번호. 가중치는 ±50%에서 가족 안 순위가 바뀌므로 과적합하지 않는다.
8. **포화(유효 후보 0)**: 줄서기가 켜져 있으면 따라오기 v를 **원뿔 검사 없이** 반환(S12q 1.1%에 기여), 아니면 0. 32스텝(0.5초)을 넘으면 유효 후보가 생길 때까지 **매 스텝 희망 속도**(`:218-233`)라 G3에서는 반발(≤150cm/s)만으로 관통을 못 막는다(H4 해제 G1 24·G2 17·G3 16회 [측정]). 마주 보고 정지한 두 몸의 '다가섬 → 인내 1.5초 → 포화 → 관통' 순환도 가능하다 [추론]. → 해제 제한('OBB 침투를 늘리지 않는 성분만' 또는 '지속 상한 N스텝')을 M3-18 (e)에서 재고, 해제 횟수·해제 중 침투를 수용 지표에 넣는다.
9. **VO 생략**: 희망 속력 0(정지·시전·경직·강제 이동)인 몸은 장애물로만 보인다(측정 구성, `avoid_sim_game.py:1016`, `idle_vo` 기본 꺼짐). '정지 몸이 VO를 돌리면 겹침이 생긴다'는 결과 파일이 없어 [미검증].
10. **외부 장애물**: 추적 대상이 아닌 플레이어·동료(r42)와 원형 종은 정사각형으로(HZD 330-334). 선택·미측정(M3-18 (e)): 통과 방향 고정·점수 관성, 360° 고리 감지(HZD 325-328).

### 4.5 특수 상황

1. **플레이어**: 추적 대상이면 VO에서 뺀다(빼지 않으면 접근 불가). 아니면 정사각형 장애물.
2. **물기 후 후퇴 반전**(1절): 이동 중 약 180° 회전이라 지금 규칙으로는 게이트 밖이다. M3-18 (h)에서 대책 셋: (1) 이동 중 큰 yaw 변화 게이트 (2) 후퇴 때 대상을 바라본 채 뒷걸음(`MoveToBand` 후퇴에 바라보기 유지 + `FacingDirection`) (3) 하이에나 M_arc. 지표는 반전 중 새 OBB 겹침과 대상당 10초 물기 수.
3. **정지 거리 150cm**(MD-29) = 앞 반길이 88.5 + 대상 반경 42 + 틈 약 20(측정은 표 2-3).
   - 효용 [추론]: 효용 = 가중치 × 고려사항 곱(`TDUtilityScorer.cpp:3-14`), 로지스틱 K/(1+e^{−M(X−C)})(`TDResponseCurve.cpp:34-35`). 중심 150cm(X = 0.1)에서 물기 2.5×1×0.5 = 1.25, 접근 1/(1+e^{0.28}) ≈ 0.43, 재사용 대기 중 Circle 1.3×1×0.96 ≈ 1.25. 접근→물기 전환은 전환 비율 1.15 포함 약 190cm. 사고 주기 round(64/12) = 5스텝 = 12.8Hz(`TDMonsterDefinitionLibrary.cpp:382`)라 약 44cm 늦을 수 있다. 150cm 정지는 물기 선택을 막지 않는다.
   - `range` 150은 시전 게이트가 아니라 피해 원점 배치용이다(`TDMonsterCharacter.cpp:541-567`; 게이트는 토큰·재사용 대기, `TDMonsterActionExecutor.cpp:224-233`). `DA_TDHyenaBite` 반경의 150cm 명중은 [미검증].
4. **시전 시작 회전**(M3-22): 현행 `FaceRotationImmediately` 즉시 회전(`TDMonsterCharacter.cpp:349-351`, 평균 1~9°).
   - 서브시스템이 스냅샷으로 목표 yaw OBB 겹침을 검사해 `FTDMonsterStepContext`에 결과를 넣는다(Context엔 이웃 뷰가 없고 `StartCast`는 Brain·Context만 받음, `TDMonsterActionExecutor.h:9-17`·`.cpp:224-233`). 겹치지 않으면 지금처럼 즉시 돈다.
   - 겹치면 **Cast 상태의 선행 하위 단계**(새 FSM 상태 없음, 00#D1 유지). Cast로 세므로 토큰 집계(`TDMonsterThinkSubsystem.cpp:343-348·581-592`)에 자동 포함되어 대상당 3을 넘지 않는다. `BeginBodyAbility`(`:248`)·재사용 대기는 미루고, 선회율로 돌되 겹침 각은 보류한다. 15° 정렬 또는 64스텝 뒤 대상 생존·동일을 재검사해 `BeginBodyAbility`, 아니면 Cast 해제 → Idle. 선딜(00#D19 `ActivationDelay`)은 정렬 뒤부터 센다. Cast 중 `CanThink`는 false(`TDMonsterBrainSlot.h:66-69`).
   - 측정(S9, 즉시 회전 → 선회율 + 겹침 검사, 동시 시전 상한 3; 정지 규칙은 G0만 c115, G0f·G3·G5는 foot, `run_game_experiments.py:30-32`) [측정]: 시전당 새 겹침 G3 0.13→0.06, G5 0.06→0.03, 조준 실패 G3 0/31·G5 1/39, 시전 수 G3 34→31. 캡슐 막힘 + 원 분리인 G0f(foot)는 보류율 16.1%·조준 실패 1/74로 정상 동작하지만 새 겹침이 줄지 않는다(0.21→0.21, 상한 8은 0.25→0.24).

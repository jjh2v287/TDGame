# 교전 해제·귀환 요요 분석과 수정 (M3-25)

작성: 2026-10-14 claude. 대장 [07 M3-25](../07-roadmap-and-tasks.md). 작업 산출물 `Saved/AgentOps/20261014/m3-25-*`, 시뮬 `Tools/scratch/20261014_claude_m325_engagement/`.

## 1. 결론

- **원인은 AI 프레임워크(유틸리티 선택 + 실행 FSM, D1)가 아니라 그 바깥의 교전 계층 로직이다.** 교전 계층은 수직 슬라이스 때 결정 없이 덧붙은 `bool bIsEngaged` 하나였다(07 M1-05 기록 '추가'). 유틸리티 점수기는 교전 중일 때만 돌고, 교전 진입·해제·귀환은 서브시스템이 거리 두 개(1500/3500)로 직접 정했다.
- 같은 조건식을 비헤이비어 트리·StateTree·HTN·GOAP로 옮겨도 요요는 그대로 생긴다(4절). **프레임워크 교체는 필요 없다.** 고칠 것은 상태 설계(무엇을 기억하고, 어떤 변수로 판정하느냐)다.
- 수정: 교전 계층을 `Home → Engaged → Returning → Home` 3상태로 만들고, 해제 기준을 '집 기준 영역'으로 바꾸고, 귀환을 도착까지 지키는 커밋 상태로 만들었다(5절).

## 2. 증상과 재현 수치

사용자 보고: 플레이어가 도망가면 몬스터가 제자리로 가다가, 플레이어가 쫓아가면 다시 다가오는 것을 반복한다.

- 속도: 플레이어 600cm/s, 몬스터 230(Golem)~560(Hyena) — 전 종이 플레이어보다 느리다. 귀환은 0.7배속이었다.
- 2D 결정론 시뮬(추적 카이터, 120초): 구 규칙은 귀환 도중 재교전 Goblin 5회·Golem 10회, 주기 11.5~19.7초(Hyena 63초). 재교전이 귀환 도중 일어나 몬스터가 집에 끝내 못 닿고 주기마다 집에서 멀어진다(래칫): 최대 집 거리 Goblin 20,678cm, Hyena 56,378cm. 원거리 견제(3초마다 피격)는 피격 잠금 6초가 계속 갱신돼 7종 모두 27,589~67,128cm까지 끌려갔다.
- 체력이 깎인 Goblin·Hyena는 플레이어가 가만히 있어도 도망(Flee)→3500 해제→플레이어 쪽 귀환→1500 재교전→도망을 반복했다.

## 3. 원인 사슬 (수정 전 코드)

1. 해제 기준이 몬스터-플레이어 거리(> 3500)였다. 집에서 얼마나 멀어졌는지는 어떤 판정에도 없었다(`HomeLocation`은 귀환 목적지로만 쓰임).
2. 귀환이 상태가 아니라 '비교전'이었다. 귀환 중에도 매 스텝 '몬스터 현재 위치-대상 ≤ 1500'이면 재교전했고, 피격·경보도 귀환을 즉시 끊었다.
3. 대상이 살아서 멀어지면 재교전 차단이 0이었다(대상이 죽었을 때만 6초).
4. 1500/3500 히스테리시스는 폭보다 작은 흔들림만 거른다. 플레이어는 입력(거리)을 폭보다 크게 의도적으로 움직이는 적대적 입력원이라, 히스테리시스는 빠른 떨림을 느린 고리로 바꿀 뿐 고리 자체를 막지 못한다.

## 4. 프레임워크 판정

| 대안 | 같은 조건식을 옮기면 | 근거 |
|---|---|---|
| 비헤이비어 트리 | '대상 ≤ 1500' 데코레이터 + Observer Aborts가 귀환 분기를 즉시 중단 → 같은 요요 | UE 데코레이터 레퍼런스(Observer Aborts) |
| StateTree | OnTick 전이가 매 틱 '거리 ≤ 1500'을 시도 → 같은 고리 | `EStateTreeTransitionTrigger::OnTick` 문서 |
| HTN | 근접 센서가 바뀌면 재계획 → 공격 메서드 재선택 | Humphreys, Game AI Pro 1 12장 |
| GOAP | 같은 거리 센서로 목표 관련도를 매기면 교대 선택. F.E.A.R.의 해법은 계획기가 아니라 작업 기억 | Orkin, GDC 2006 |

상용 사례도 leash(교전 이탈 한계)는 프레임워크가 아니라 소수 규칙으로 푼다: WoW 서버 구현(TrinityCore)은 '대상-몬스터 집 거리'로 판정하고 귀환(evade) 중에는 공격·동료 지원을 거부한다. ESO·시티 오브 히어로즈는 귀환 중 재교전 불가, 리그 오브 레전드 정글 몬스터는 캠프 기준 반경 + 인내 시간 + 소프트/하드 리셋이다.

**같은 부류 문제를 막는 원리**(어느 프레임워크에서도 같다):
- 판정 변수는 플레이어가 싸게 조작할 수 없는 것으로(집에서의 거리·경과 시간). 몬스터-플레이어 거리처럼 플레이어가 자유롭게 움직이는 값으로 모드를 바꾸지 않는다.
- 여러 초짜리 결정은 '상태'로 기억하고 끝날 때까지 지킨다(커밋). 유틸리티 관성(0.3~0.4초 유지, 교체 비율 1.15)은 고빈도 떨림 대책이라 수 초 주기의 저주파 요요를 막지도, 지표(교체율 < 5회/초)로 잡지도 못한다.
- 히스테리시스는 잡음 대책이다. 적대적 입력에는 커밋과 시간 조건이 필요하다.
- 회귀 지표: '귀환 도중 재교전 0', '집 최대 이탈 ≤ 상한', '해제 수 ≤ 도착 수 + 1'.

**프레임워크를 바꿀(정확히는 추가할) 신호** — 이번 요요는 어디에도 해당하지 않는다:
1. 모드 계층을 명시 FSM과 시험으로 정리한 뒤에도 같은 부류 결함이 다른 축에서 반복되고, 최상위 모드가 8~10개를 넘어 전이가 흩어질 때 → 자체 계층형 FSM(StateTree는 01의 S1~S7 충족 시에만).
2. 상황 따라 순서가 바뀌는 길이 2 이상의 다단계 계획(3페이즈 이상 보스 안무)이 필요할 때 → HTN(01의 H1).
3. 무리 역할 배정이 자리 토큰으로 표현되지 않을 때 → HTN(H2).
4. 종 하나를 JSON 표로 표현하지 못하거나 10분 저작 루프(D37)가 반복 실패할 때.
5. 사고 비용·결정론 게이트가 프레임워크 때문에 깨질 때(현재 사고 추정 0.10ms).

## 5. 수정 설계 (구현: `MonsterAI/TDMonsterThinkSubsystem.*`, `TDMonsterBrainSlot.h`)

| 상태 | 의미 | 나가는 조건 |
|---|---|---|
| Home | 비교전, 집에 있음 | 근접: 몬스터-대상 ≤ 1500 ∧ 집-대상 ≤ 3000(LeashRadius) ∧ 차단 0 / 피격 / 경보 → Engaged |
| Engaged | 현행 교전(유틸리티 + FSM) | 대상 사망 → Returning(재교전 차단 6초) / 몬스터-집 > 4500 → Returning(잠금 무시) / '닿지 않음'(집-대상 > 3000 ∨ 몬스터-대상 > 3500)이 2초 연속 ∧ 피격 잠금 0 → Returning |
| Returning | 포기 후 귀환 커밋(1.0배속) | 집 120 안 도착 → Home(근접·경보 1초 안정) / 1초 진척 없음(막힘) → 그 자리를 임시 집으로 정착 → Home(다음 포기 때 집을 원래 스폰 지점으로 되돌림) / 공격자가 집 2500 안에서 때림 → Engaged |

- 근접·경보는 Returning을 끊지 못한다. 경보는 경보자가 Engaged이고, 받는 동료가 Home이며, 대상이 그 동료의 영역 안일 때만 전파된다.
- 귀환 시작 때 활동 중단·대상 해제·피격 잠금 0. 스텝당 최대 1전이(switch), SimulationId 순, 난수 없음.
- 수치는 시뮬 민감도(Leash 2500/3000/3500 × 포기 1/2/3초 × 상한 4000/4500/5000, 27조합 × 3정책 × 7종에서 불변식 통과)를 보고 정했다. Leash·포기 시간은 왕복 빈도와 진폭을 맞바꾼다: (2500, 1초) 분당 10회·최대 1,811 → (3000, 2초) 6.4회·2,835 → (3500, 3초) 4.5회·3,868.

## 6. 검증

- 시뮬(같은 2D 모델, 6정책 × 7종): 신 규칙은 귀환 도중 근접 재교전 0회, 최대 집 거리 4,580 이하, 포기 1.98초(원거리 견제만 피격 잠금 때문에 8~19초), 불변식 3개 모두 통과. 구 규칙은 추적 카이터에서 Hyena를 뺀 6종이 셋 다 실패했다.

## 7. 남은 한계 (의도된 동작 포함)

- **집 도착 뒤 재교전은 의도된 동작이다.** 플레이어가 영역 안 1500 안에 다시 들어오면 몬스터는 영역을 지키러 다시 나온다. 전 종이 플레이어보다 느리므로 플레이어가 반복해서 끌어낼 수 있다(시뮬 추적 카이터: 교전 진입 분당 약 6회, 진폭은 집 기준 1,230~2,888로 묶임). 1초 도착 안정 시간이 급반전만 줄인다. 근본적으로 줄이려면 종 속도 설계(MD-44)가 필요하다.
- 귀환 중 영역 밖 공격자의 타격은 교전을 일으키지 않지만 체력은 깎인다(무적·회복 없음 → MD-41).
- 막힘 정착: 직선 귀환이라 장애물에 막히면 그 자리가 임시 집이 된다. 포기할 때마다 원래 스폰 지점으로 다시 귀환을 시도하므로 집이 누적해서 끌려가지는 않지만, 같은 장애물에 다시 막히면 그 자리에 머문다. 경로 탐색 귀환은 후속.
- Flee(MoveAway)에 끝 조건이 없어 체력 낮은 Goblin·Hyena는 '도망 → 포기 → 귀가 → 재교전'을 약 20초 주기로 반복한다(데이터 문제 → MD-43).
- 보스도 같은 전역 leash를 쓴다. 귀환 시작이 시전·시퀀스를 취소하므로 위험 패턴을 피하는 데 쓸 수 있다(→ MD-42).
- 교전 반경·시간은 아직 C++ 전역 상수다(종별 JSON화 → MD-40).
- 결정론 상태 해시(M1-11)를 만들 때 `Engagement`·두 카운터·`ClosestReturnDistance`·`HomeLocation`을 해시 대상에 넣어야 한다. 문서 03의 LOD 'L0 교전'(최근 피격·공격 192스텝)은 이 교전 계층과 다른 개념이므로 M3-03 구현 때 이름을 분리한다.
- 형상 회피(다른 세션 research/project-elongated-monster-avoidance.md)가 들어와 회피 대기·탈출 기동을 하면 1초 막힘 판정이 오탐할 수 있다 → 그 스텝은 막힘으로 세지 않는 훅이 필요하다.

## 알려진 한계 / 후속
- 조명·색보정은 1차 기준값(태양 7lux, 수동 노출 10.4). 게임 카메라에서 추가 튠 필요.
- 던전 입구는 절벽 메시 아치 + 어두운 상자 조합의 임시 형태. 실제 입구 액터(P1-03 `ATDDungeonEntrance`)로 교체 예정. 현재는 `TargetPoint` 마커(태그 `TDDungeonEntrance`, `TDPoi`)만 둠.
- 재생성 시 손으로 다듬은 액터는 보존되지 않음(P3-06 잠금 기능 필요).
- 나무 HISM은 조감(700m)에서는 컬링되어 보이지 않음(게임 카메라 거리에서는 정상).
- 팩 머티리얼 4개(`M_Bark`, `M_LightBeam`, `MI_Dreadplants`, `MI_Red`)가 인스턴스 메시 사용 플래그 자동 갱신으로 저장됨.

# 검증 기록의 적용 범위

이 디렉터리의 이미지와 JSON은 GAS 전환 전, 공식 Unreal MCP를 사용한 실제 PIE 검사 기록이다.

- 파이어볼: 표적 체력 300 → 253 → 246, 장판 생성과 반복 피해 확인.
- 블리자드: 낙하, 피해 누적, 빙결 표시 및 시간 배율 0 → 1 복원 확인.
- 지뢰: 준비 중 체력 300 유지, 발동 후 240.
- 쇼크웨이브: 중심 표적 300 유지, 외부 표적 265.
- 운석: 직접 적중과 폭발 후 체력 185.

당시 원래 템플릿 블루프린트가 C++ 전투 클래스를 상속하지 않는 문제를 찾아 설정 전용 전투 블루프린트 3개와 기본 게임 모드 연결을 추가했다.

이후 사용자가 GAS 전환과 에디터 테스트 보류를 요청했다. 따라서 이 자료를 현재 GAS 구현의 실행 검증으로 사용하지 않는다. 지연 호밍의 최종 PIE 상태 관측도 후속 에디터 검증에 남아 있다.

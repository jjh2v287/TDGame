# 탑다운 2D 안개 개선 1차(물체와 안개) — 통과 기준, 측정 전 등록 (v1)

등록: 2026-11-12 claude, 촬영을 시작하기 전에 씀. 결과를 본 뒤에는 고치지 않는다. 결함이 드러나면 그대로 적고 새 판은 새 측정 전에 등록한다.

## 무엇을 고치나

조사 결과(2026-11-12): 지금 2D 안개(FogMist·FogMistStir·FogTileSim)는 물체를 전혀 장애물로 받지 않는다. 장애물을 받게 켜면 이번에는 높이와 상관없이 기둥 전체를 막는다. 1차 개선은 "높은 물체는 흐름을 막고, 안개 층보다 낮은 물체는 막지 않는다"이다.

- 코드: 설정 하나(낮은 장애물 높이 문턱, 기본 0 = 기존과 같은 동작)와 장애물 목록을 만들 때의 높이 비교. 셰이더와 압력 풀이는 건드리지 않는다.
- 정본 값(안개 종류의 기본 설정)은 이번에 바꾸지 않는다. 시험 장면에서만 값을 켜서 비교하고, 기본으로 켤지는 그림을 본 뒤 사용자가 정한다.

## 시험 장면 (저장하지 않는 임시 배치)

- 안개 무대 평지. 휘젓기에 반응하는 안개 1개.
- 물체 2개, 둘 다 장애물로 등록: 낮은 상자(가로·세로 150cm, 높이 30cm), 높은 상자(가로·세로 150cm, 높이 180cm). 서로 8m 이상 떨어뜨린다.
- 같은 방법·같은 속도로 각 물체 옆을 지나가며 물체 쪽으로 안개를 민다. 구도는 탑다운 검증 구도(스프링 암 800cm, 60도 내려봄, 1920×1080), 노출 고정.
- 상태 세 가지: S0 = 장애물 끔(지금 기본), S1 = 장애물 켬·문턱 0(전부 막음), S2 = 장애물 켬·문턱 45cm(낮은 상자는 통과).

## 지표

- 물체 뒤쪽(미는 방향의 반대편) 영역에서 안개가 흐트러진 정도를 잰다. 흐트러짐 = 휘젓기 전 평균 그림과 휘저은 뒤 평균 그림의 화소별 밝기 차의 평균(0~255).
- 흔적비 T = (그 상태의 물체 뒤 흐트러짐) ÷ (S0 의 같은 영역 흐트러짐). 낮은 상자 뒤는 T_low, 높은 상자 뒤는 T_tall.
- 잡음 바닥 = 휘젓지 않고 두 번 찍은 그림의 같은 영역 차.

## 판정

- 가 (낮은 물체는 넘어간다): S2 에서 T_low ≥ 0.6
- 나 (높은 물체는 막는다): S2 에서 T_tall ≤ 0.3 그리고 T_low − T_tall ≥ 0.3
- 다 (정보): S1 에서 T_low 를 적는다. 문턱이 없으면 낮은 상자도 막는다는 것을 보이는 대조값이다.
- 라 (기존 동작 보존): 문턱 0 이면 장애물 목록이 기존과 같다는 단위 시험 통과, 헤드리스 자동화 시험이 기준선(기존 실패 1건 외 전부 통과)과 같음, 관련 검사 도구 통과.
- 판정 불가: S0 의 물체 뒤 흐트러짐이 잡음 바닥의 3배 미만이면 지표 결함으로 적는다.
- 통과 = 가·나·라 모두 통과. 그 뒤 S1 과 S2 의 그림(이름 가림)을 사용자에게 보내 눈 판정을 받는다.

## 이번에 하지 않는 것 (다음 차수 후보)

- 공중 입력(점프·든 칼·날아가는 파편)이 바닥 안개를 덜 휘젓게 하는 높이 규칙: 칼 휘두르기 반응까지 약해질 수 있어 값과 규칙을 따로 정한다.
- 일반 스태틱 메시를 자동으로 장애물로 모으기: 스트리밍·인스턴스 메시 설계가 필요하다.
- 낮은 물체를 서서히 통과시키는 방식(셰이더 변경): 3D 안개와 겹쳐 보류.

표기: 꼴 U=위쪽 한계(이보다 작아야) / L=아래쪽 한계(이보다 커야) / E=같음(비트·0·대칭) / R=다른 실행에 대한 비. s=입력 바람 세기. 근거는 `파일:줄`. 확인=파일에서 직접 봄, 추정=내 해석.

## 0. 먼저 알아 둘 것
1. 섞는 곳은 한 줄이다: `바람 = 바람 + (목표 − 바람) × W × s` (`fog3d_core.py:1281-1284`). 지형판은 `fog3d_terrain.py:268-296`(섞기 :281-286), R5 는 `fog3d_terrain_add2.py:132-163`(섞기 :144-149)에 복사본이 따로 있다. 확인.
2. 1단계 판정선 장면의 입력 세기는 거의 전부 s=1(`SweptSphere` 기본 1.0 `fog3d_core.py:127`, `still_sphere`·`capsule_spheres` 기본 1.0). 가중치 W ≤ 1(`band_weight` 가 (1−(d/r)²)² 꼴)이므로 s·W ≤ 1, 곧 넘침이 없다. 따라서 "s·W ≤ 1 구간에서 지금 식과 같은 후보(예: min(1, s·W))"는 s=1 장면에서 비트까지 같아야 한다(추정). 넘침이 실제로 생기는 판정선은 s>1 인 것뿐이다: 1단계는 1d 걷기 `BODY_WIND=2.0`(`fog3d_gates_v2.py:36`), 2a 는 몸 3.0·칼 2.5(`fog3d_gates_s2a.py:55,65,68`). 확인.
3. 정본 값 몸 3.0·칼 2.5 를 쓰는 판정선은 2a 의 걷기·칼·구 장면뿐이다. 1단계 장면은 s=1, 1d 걷기만 2.0(정본 아님). 확인.
4. dt 는 `Params.dt`(한 걸음의 초, 기본 1/60 = 초당 60걸음). 변형 1/30·1/144(D-G4·D-G6·D-G8·D-G14/15·2A-G6 S60), 1/20(D-G16). 확인.

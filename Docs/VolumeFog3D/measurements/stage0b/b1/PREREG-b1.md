# 0b-1 가 측정 정의 (촬영 전 등록, 2026-11-12)
- 구도: 3인칭, 안개 최대 거리 20m, 격자 8픽셀, 128층, 소광 0.25/m, 노출 바이어스 고정, 장면당 8장 평균(0a 와 같음).
- 장면: N(수식 N), T(텍스처 상수 알파 1), C(수식 C), Np(수식 N 다시), Tp(텍스처 다시), X(상자 둘 다 숨김).
- 영향 영역 M: 8장 평균 밝기(RGB 평균)에서 |N-C| >= 2 (0a 와 같은 정의). D(X,Y) = M 안 화소별 |X-Y| 평균.
- 잡음 바닥 = max(D(N,Np), D(T,Tp)), 단 8비트 양자화 때문에 하한 0.05 를 둔다.
- 읽는다: D(N,T) <= 3 x 잡음 바닥. 못 읽는다: D(T,X) <= 3 x 잡음 바닥 이고 D(N,X) > 3 x 잡음 바닥(화면에 텍스처판 안개가 없음). 그 밖은 '애매'.
- P6: 구도마다 F T T F T F F T 여덟 구간, 구간당 csvprofile 400프레임, 앞 60행 버림, 열 GPU/VolumetricFog. 차 = 텍스처판 중앙값 - 수식판 중앙값(프레임 전체 합친 중앙값). 0.10 ms 이하 통과.

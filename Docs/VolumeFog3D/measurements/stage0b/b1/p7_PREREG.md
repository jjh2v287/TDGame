# 0b-1 나 P7 측정 정의 (촬영 전 등록, 2026-11-12)
- 구도: 3인칭, 최대 거리 20m, 격자 8픽셀·128층, 소광 0.25/m, 노출 바이어스 고정, 60fps 고정(t.OverrideFPS), 수식판 상자(0a 와 같음).
- 전환: 정착 8초 뒤 N, 예약 사건 한 번으로 Packed 25 -> 3025(N -> C) 한 틱에 바꿈. 연속 촬영(HighResShot 1920x1080, 다음 장은 그려진 다음 틱).
- I(t) = 영향 영역 M 안 화소 평균 밝기(RGB 평균). M = 0a 와 같은 정의 |N - C| >= 2 이되, N·C 는 같은 세션에서 정착 뒤 찍은 8장 평균(별도 변형)을 쓴다.
- 최종값 = 전환 후 마지막 8장 I 의 평균, 처음값 = 전환 전 8장 I 의 평균. 진행률 f = (I - 처음값) / (최종값 - 처음값).
- 50%·90% 프레임 수 = f 가 처음으로 0.5·0.9 이상이 되는 전환 뒤 틱 수(선형 보간값도 같이 적음). 이론값 = ln(1-p)/ln(w) 의 w^k 감쇠(w = 시간 섞기): 50% 6.6/3.1/1.9, 90% 21.9/10.3/6.5.
- 촬영 방식 확인(1번): 연속 촬영에서 f 가 여러 틱에 걸쳐 단계적으로 오르면 반영, 한 장 만에 1 이 되면 '측정 불가'.
- 흔들림: 정지 장면 24프레임에서 평균 |I_t - (I_{t-1}+I_{t+1})/2| (영역 평균 밝기 기준, 그리고 화소별 기준 둘 다 적음).
- 촬영 틱과 전환 틱의 대응은 예약 상태 JSON(issued_game_time, 사건 game_time)으로 읽는다. 위상 어긋남 변형으로 틱 해상도를 메운다.

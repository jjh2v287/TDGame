# 0b-1 나 결과: 반응 지연(P7)과 P5 본 측정용 계획 스크립트

작성 2026-11-12 하위 에이전트(Sonnet 5.5). 측정 정의는 촬영 전에 `PREREG-p7.md` 에 적었다. 증거 사본: `Docs/VolumeFog3D/measurements/stage0b/b1/`(`p7_` 접두). 구도 3인칭, 안개 최대 거리 20m, 격자 8픽셀·128층, 소광 0.25/m, 노출 바이어스 고정, 60fps 고정, 수식판 상자(N → C 를 한 틱에 전환).

## 1. 촬영 방식이 엔진의 시간 섞기를 반영하는가: 반영한다 (조건 하나)

- 직접 확인: 전환 뒤 연속 촬영에서 영역 평균 밝기가 한 장 만에 끝나지 않고 여러 장에 걸쳐 단계적으로 최종값에 다가간다. 기본 설정 첫 시험(시간 섞기 0.9)에서 진행률 0.24 → 0.50 → 0.67 → 0.79 → 0.87 → 0.92 …(촬영 한 장마다).
- 조건: 사진 한 장은 엔진 프레임 한 장이 아니다. 엔진 코드(`UnrealClient.cpp:1684-1717`)와 `Docs/Lessons/editor.md` L-editor-46 대로 `HighResShot` 은 가짜 뷰포트로 `r.HighResScreenshotDelay`(기본 4)번 장면을 다시 그리고 월드는 틱하지 않는다. 그래서 사진 한 장 사이에 안개 이력이 여러 번 갱신된다.
- 직접 확인한 근거: 촬영 지연 d = 1, 2, 3 을 바꿔 같은 시간 섞기로 잰 곡선이, 갱신 횟수 n = (d+1)×k + d (k = 전환 사건 틱을 0 으로 센 촬영 순번)로 환산하면 같은 곡선에 겹친다(같은 n 에서 서로 다른 지연의 진행률 차이 최대 0.02, 시간 섞기 0.9·0.8·0.7 모두). 기본 지연 4 의 첫 시험도 n = 5k+4 로 환산하면 지연 1 곡선과 맞는다(n=4,9,14,19 에서 0.24/0.50/0.67/0.79 대 0.27/0.52/0.71/0.81). 이 환산이 아래 프레임 수의 바탕이다.
- 추정(직접 확인 못 함): 사진 한 장 = 지연 d 번 + 평소 프레임 한 번이라는 해석. 곡선 모양으로 맞추면 절편 오차는 약 ±0.5 프레임이다. 엔진 내부 프레임 카운터를 읽어 확인하지 못했다.
- 결론: 촬영 지연을 1~3 으로 낮춘 연속 촬영으로 n 을 환산하면 엔진 시간 섞기를 잴 수 있다. 측정 불가가 아니다. 단 지연 1~3 은 엔진이 그 사진의 시간 누적 앤티앨리어싱(TAA)을 끄므로(엔진 설명), 이 숫자는 그 조건의 값이고 변형끼리는 같은 조건이다.

## 2. P7: 전환 뒤 영역 평균 밝기가 최종값의 50%·90% 에 닿는 엔진 프레임 수 (정보)

영향 영역 M = 같은 세션 정지 N·C 8장 평균의 |N-C| >= 2, 394,934 화소(화면의 19.0%, 0a 3인칭 18.9% 와 같은 수준). I 의 처음값 87.2~87.5, 최종값 79.3~79.7(전환 전 8장·마지막 8장 평균). 변형은 시간 섞기 3 x 촬영 지연 3 = 9개(각 50장). 아래는 세 지연의 표본을 n 으로 합친 곡선에서 보간한 값(표본 n = 1,2,3,5,7,8,9,11,13,…, n+1 이 소수인 4·6·10·12 는 표본 없음).

| 시간 섞기 | 50% 측정(보간) | 50% 처음 닿은 표본 n | 50% 이론 | 비 | 90% 측정(보간) | 90% 처음 닿은 표본 n | 90% 이론 | 비 |
|---|---|---|---|---|---|---|---|---|
| 0.9 | 8.4 | 9 | 6.6 | 1.28 | 25.2 | 26 | 21.9 | 1.15 |
| 0.8 | 4.1 | 5 | 3.1 | 1.32 | 12.3 | 13 | 10.3 | 1.19 |
| 0.7 | 2.5 | 3 | 1.9 | 1.31 | 7.6 | 8 | 6.5 | 1.17 |

- 이론값은 이력 가중 w 의 감쇠 w^n 에서 ln(1-p)/ln(w). 실측이 이론보다 15~30% 늦다. 추정(확인 안 함): 이력에 섞이는 것은 안개 농도이고 우리가 보는 밝기는 투과율(지수 함수)을 거치므로 밝기 진행이 농도 진행보다 뒤처진다. 수식으로는 이 방향과 크기가 맞지만 따로 검증하지 않았다.
- 읽는 법: 시간 섞기 0.9 에서 가림이 바뀐 뒤 눈에 보이는 변화의 절반이 약 8프레임(60fps 에서 0.14초), 90% 가 약 25프레임(0.42초). 0.7 이면 절반 약 2.5프레임(0.04초), 90% 약 7.6프레임(0.13초). 진행률은 앞 몇 프레임이 가장 느리다(0.9 에서 n=1 에 0.08, n=3 에 0.21).
- 정지 장면 흔들림(정지 N 26장 연속, 지연 1 이라 이웃 사진은 엔진 2프레임 간격, 안쪽 24개 값): 영역 평균 밝기 기준 |I_t-(I_(t-1)+I_(t+1))/2| 평균과 화소별 기준(영역 안 화소 평균, 0~255 단위).

| 시간 섞기 | 영역 평균 밝기 흔들림 | 화소별 흔들림 | 평균 I |
|---|---|---|---|
| 0.9 | 0.0167 | 0.135 | 87.21 |
| 0.8 | 0.0331 | 0.153 | 87.42 |
| 0.7 | 0.0465 | 0.169 | 87.50 |

  시간 섞기를 낮출수록 흔들림이 는다(영역 평균 기준 0.9 대비 0.7 이 2.8배, 화소별은 1.25배). 8비트 양자화 바닥은 따로 재지 않았다. 평균 I 가 시간 섞기마다 0.3 쯤 다르다(0.9 가 가장 낮음, 이유 미확인).
- 눈으로 볼 연속 그림: `p7_sheet_w090_w070.png`(960x456, 6열 x 2줄씩, 영향 영역 둘레를 잘라 줄임, 칸마다 촬영 순번 k·엔진 프레임 수 n·I 표시, 위 두 줄 = 0.9, 아래 두 줄 = 0.7). 변화가 부드러워 눈으로는 어두워지는 속도 차이가 보이는 정도다. 수치는 JSON(`p7_series.json`, `p7_still_judge.json`).

# 1c 일괄 보정 숫자 요약 (기준 dry_b)

숫자는 후보를 거르는 데만 쓴다(통과·실패 판정이 아님). Wk·Sk·N·Tx 는 8비트 밝기 단위(0~255), ×기준은 기본값 실행 대비 배수.

| 실행 | 묶음 | 유효 | Wk(12.1) | ×기준 | Wk/N_W | Sk(2.5) | ×기준 | Sk/N_S | Tx | ×기준 | 되차오름 S | 되차오름 W | N_W | N_S | 로그 경고·오류/거부 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| dry_b |  | 예 | 1.28 | 1.00 | 5.5 | 4.58 | 1.00 | 15.9 | 1.72 | 1.00 | 0.39 | 0.50 | 0.23 | 0.29 | 0/0 |
| dry_d |  | 예 | - | - | - | - | - | - | - | - | - | - | - | - | - |
| dry_e |  | 예 | - | - | - | - | - | - | - | - | - | - | - | - | - |

숫자는 뒤 카메라에서만 계산한다(등록본 3절). 눈으로만 보는 실행: dry_d, dry_e

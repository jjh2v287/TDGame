### 독립이 아닌 측정 (식 수준)
R4 는 지형 H 에 1차 함수 L(x, y) = s·x + t·y + c 를 더해도 같은 계산이 된다(벽 문턱과 기울기 문턱에 걸리지 않는 한):
- 표본의 세계 z 는 L(표본)만큼 바뀐다.
- 기둥 기울기(중앙 차)와 그 이중선형 보간 Sc 는 (s, t)만큼 바뀐다.
- 그래서 z̃ = z − Sc·(x − m) 는 L(m) 이라는 입력마다 같은 상수만큼 바뀌고, ã·b̃ 도 같은 상수만큼 바뀐다. 무게는 높이 차만 쓰므로 그대로다.
- 걷기의 세로 속도는 s·Vx + t·Vy 만큼 늘고, 윗면 목표값의 Vx·Sx + Vy·Sy 도 같은 만큼 늘어 상쇄된다.

이 성질에서 나오는 것:
1. **2A-G12 의 15값은 모두 "균일 비탈 = 평지"라는 같은 등식의 사례다.** 걷기 일곱은 상태 해시까지 평지와 같다. S20 오르막과 S30 오르막은 서로도 비트까지 같다.
   - 2A-G7(A 는 평지의 앞뒤 차 3e-7 그대로), 2A-G8(비 1.0), 2A-G10, 2A-G6 의 균일 비탈 (ㄴ)(ㄷ) 여덟(최대 바람 = 평지 대조라 비가 정의상 정확히 1/1.5 = 0.6667)도 같은 등식에서 나온다.
   - 그래서 이 선들은 등식이 비트까지 성립하는 한 따로 떨어질 수 없다. 이 선들이 실제로 따로 가리는 것은 "등식의 구현이 방향 x·y, 기울기 20·30·45·61.7도, 계산 간격 1/30·1/60·1/144초에서 성립하는가" 하나로 줄어든다.
2. **2A-G11 (나)의 넷은 사실상 둘이다.** FOOT30(−x) = FOOT30(x) + tan30·x 이므로, FOOT30 을 −x 로 걷는 것은 같은 지형을 +x 로 걷는 것의 거울상에 1차 함수를 더한 것이다(TOP30 도 같다). 조각에서 FOOT30 오르막·내리막 값은 19.832860 / 19.832858, TOP30 은 21.857777 / 21.857777 로, 차이는 평지 앞뒤 걷기의 차(1e-7 상대) 정도다.
   - 그래서 2A-G11 은 "아래로 꺾인 곳(FOOT30)" 하나, "위로 꺾인 곳(TOP30)" 하나, 굽은 땅 HILL 하나의 독립 측정 셋이다. 방향(오르막·내리막)에 대한 따로 된 정보는 없다.
   - R4 에서는 걷는 방향이 정의상 결과를 바꾸지 않는다. 1차 함수 불변 때문에, 방향 차를 내는 것은 이제 비탈이 아니라 꺾임뿐이다.

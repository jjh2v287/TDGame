# 덧붙임 2 초안(후보 R5) 독립 검토, 2026-11-15

대상: `Docs/VolumeFog3D/stage2/prereg-2a-design-add2.md`(잠금 전 초안). 판정 값(R5 의 판정선 값)은 내지 않았다. 한 것은 기하 계산뿐이다: 잠긴 `TerrainSimR4` 의 기둥 높이·기둥 기울기·틀 기울기(`frame_slope`)·`band_weight` 를 그대로 불러, 등록 장면의 입력 순서(계산 단계는 돌리지 않음)마다 기준 기둥·평면 편차 e 를 D절 식대로 구하고, 두 틀 가운데 어느 하나라도 무게가 0 보다 큰 표본(u·v·w 면과 칸 가운데)만 셌다.
계산 스크립트: `critic_add2_scratch/deviation_geometry.py`(분포), `raw_counts.py`(띠 안 개수), `mixed_where.py`(띠 안 표본의 자리), `rough_tie.py`(경계 위 기준 기둥), `max_e.py`(닿는 범위 안 |e| 최대).

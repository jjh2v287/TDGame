## e. 2A-G6 의 S 와 V′
조각 12개 모두에서 다음이 성립한다.
- 내가 조각의 slope_x·slope_y 로 다시 계산한 변환 크기가 조각의 converted_input_speed 와 같다(차 0).
- V′ = (Vx, Vy, Vz − Vx·Sx − Vy·Sy) 가 flat_control.velocity 와 같다.
- 입력·뒤 걸음 수가 등록과 같다.

S 를 고르는 기둥: 균일 비탈에서는 비탈의 S(S30 0.5774, S45 1.0, S60 1.856), (ㄱ)은 Sy = 0 이라 V′ = V 다. ROUGH (ㄴ)은 Sx 0.6175, Sy 0.052 인 기둥을 골랐다. 코드는 입력 단계마다 칸 가운데 무게 > 0 인 칸이 있는 비벽 기둥 가운데 크기가 최대인 기둥을 고르며(1단계에서 확인), 등록 문장대로다.

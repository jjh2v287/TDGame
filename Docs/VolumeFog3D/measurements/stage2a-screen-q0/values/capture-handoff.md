## 6. 그림에서 눈에 띈 것 (판정 없이)
1. 30도 능선 옆 카메라: 켬에서 판 밑 삼각 그늘이 뿌옇게 보이고 끔에서는 검다. 높은 카메라에서 켬은 비탈 윗면과 꼭대기 평지에 얇게 안개가 얹혀 있고 판 윤곽이 유지된다.
2. 구멍 칸(높은 카메라): 구멍 위 안개가 둘레 평지와 같은 높이 한 층으로 덮여 구멍은 테두리 선만 흐리게 보인다. 옆 카메라(z150)는 안개 층 안이라 구멍이 안 보인다.

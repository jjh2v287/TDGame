# 2b-0 화면 시운전 값 (끔 = 지금 코드)

## 방법
- 조합 WALL/HIGH × T(위)/S(옆), 대조 6회(휘두르기 없이 끝자리에 서 있음) + 결함 3회(휘두르기 1회, `TDPlayMeleeAction` 길이 1.85초, 1.5초에 시작 → 끝 3.35초). 시각표 동일.
- 측정 시각: 끝 + 1.5초 = 4.85초(A), 끝 + 3.0초 = 6.35초(B), 각각 0.1초 간격 8장 평균. 기준 = 7.3초에 계산 끈 뒤 8.3~9.0초 8장 평균.
- 값 = |측정 8장 평균 − 기준 8장 평균| 의 띠 안 평균(8비트 밝기 0~255).
- 띠(먼 띠) = 물체 먼 면(+X)에서 31~120cm, 면 폭에서 양끝 31cm씩 뺌, 바닥에서 0~135cm 상자. 카메라 값으로 화면에 투영해 화소로 만들고 물체가 앞에 찍힌 화소와 폰 몸(반지름 40cm·높이 190cm 원기둥) 화소는 뺌. 가까운 띠는 정보(`near`, pilot.json).
- 폰 자리·바닥 높이는 대조 1회의 상태로 모든 실행에 같이 씀(결함 폰은 z 98.15, 대조 100: 카메라 자리 최대 1.85cm 차이).
- σ̂ = 대조 6회 표본 표준편차(ddof=1), 정보 열 = (결함 평균 − μ) ÷ max(σ̂, 0.1).

# 3D 안개 프리셋 두 벌 — 3인칭(주력)과 탑다운(보류)

작성: 2026-11-14 claude. 사용자 결정(같은 날): 3D 안개는 3인칭 기준으로 계속 진행하고, 탑다운은 지금까지의 기록과 값만 따로 보존해 나중에 언제든 다시 시작할 수 있게 한다.

값 파일은 `Tools/FluidFX/fog3d_presets/` 에 있다. 각 파일의 `overrides` 가 전역 표 `Globals.TDFog3DSettings`(정본 `Content/FluidFX/PresetData/TDFluidPresetTuning.json`)에서 바꿀 필드다. 3인칭(주력) 값은 2026-11-14 에 정본과 코드 기본값(`FTDFog3DSettings`)에 기본값으로 넣었다. 탑다운 값은 기본값에 넣지 않았다.

| 프리셋 | 쓰임 | 상태 | 파일 |
|---|---|---|---|
| 3인칭(주력) | 옅은 무릎 높이 안개. 칼 자국과 걷기 자국이 3인칭에서 보인다 | 기본값으로 넣음(2026-11-14) | `thirdperson_mid.json` |
| 탑다운(보류) | 짙은 안개. 게임 기본 카메라(8m, 60도)에서 칼을 휘두른 자리가 빈 자리로 보인다 | 보류. 값과 기록만 보존 | `topdown_dense.json` |

## 3인칭(주력)

- 값(기본값으로 넣음, 정본 `Globals.TDFog3DSettings` 와 코드 기본값이 같다): 몸의 영향 반지름 발·손 45cm·골반 60cm, 몸 바람 3.0, 칼 반지름 35cm·칼 바람 2.5, 구름 무늬 켬(세기 0.75, 간격 4m), 밀린 것이 돌아오는 빠르기 가로 0.05·높이 0.15.
- 근거: 사용자 눈 판정 "중"(2026-11-14), 구름 무늬는 더 뚜렷하게, 걷기 자국이 발 뒤로 이어지게. 숫자와 그림 `measurements/stage1c/package/`, `measurements/stage1c/round2/cloud_trail.md`.
- 값 맞추기 결과(`prereg-1d-diag.md` 4절 사다리, 직접 잰 값): 새 기본값 기준 조건(얼룩 켬, +X 걷기)에서 걷기 자국 Wk 7.63(8~14 아래), 치우침 +0.084, 칼 자국 Sk2 20.50(경계), 남는 비 0.665. 마지막 확인(얼룩 끔, 같은 출발 네 방향) Wk 평균 6.63(편차 7.3% 이내), 치우침 차 0.075(크기 0.107 이하). 걷기 Wk 는 사다리 끝까지 8 에 못 미쳐 가장 가까운 몸 바람 3.0 을 썼다.
- 시험 무대 `LV_TDFog3DStage` 의 해는 옆빛(높이 35도·방향 100)이다.

## 탑다운(보류)

- 값: 안개 짙기 16배, 높이 150cm·윗면 흐림 120cm, 위와 같은 몸·칼 반응 값, 구름 무늬 0.6 / 4m. 개념 증명에서 가장 잘 보인 구성(T8) 그대로다.
- 잰 값(게임 기본 카메라): 안개가 보이는 정도 59.9, 칼 자국 60.9(되풀이 잡음의 30.5배). 그림 `measurements/stage1c/round2/poc_top_swing.png`.
- 알게 된 것: 안개가 두꺼우면(150cm 까지) 눌린 자리가 묻혀 자국이 약해진다 — 낮고 짙은 쪽이 유리해 보인다. 3인칭에서는 허리까지 차는 융단이 되어 자국이 거의 안 보인다(`poc_back.png`). 위에서 봐도 안개는 무늬 없는 한 장이다.
- 다시 시작할 때 할 일: ① 기본 높이(90cm)에 짙기 8~16배 + 위 반응 값을 먼저 찍어 본다(아직 안 찍은 조합) ② 카메라에 따라 프리셋을 고르는 장치(전역 표에 둘째 항목 + 고르는 설정)를 코드에 넣는다 ③ 탑다운에서 걷기 자국과 안개 무늬를 보강한다 ④ 0단계의 "탑다운에서 높이 구분이 어렵다"는 결과는 그대로이므로, 탑다운은 "빈 자리가 보이는가"를 목표로 삼는다.

## 지금 써 보는 법 (에디터 PIE, 코드·정본 변경 없음)

1. 프리셋의 `overrides` 를 `--set 필드=값` 으로 넘겨 조절 표 사본과 촬영 변형을 만든다:
   `python -B Tools/FluidFX/fog3d_calib_variants.py --name try_top --set BaseDensity=16 --set BaseThicknessCm=150 ... --light side --camera top`
2. `Tools/FluidFX/fog3d_calib_run.py` 로 실행하고 `fog3d_calib_report.py` 로 숫자와 그림을 만든다(사용법은 각 파일 첫머리).

# 0단계 통과 기준 — 0b 부분 개정 (v2, 0b 측정 전 등록)

등록: 2026-11-12 claude. 0b 측정을 시작하기 전에 씀. 0a 부분(v1)은 이미 측정이 끝났으므로 고치지 않는다.

## 왜 고치나

- 0a 결과와 사용자 눈 판정(2026-11-12): 3인칭에서는 높이 차이가 구분되고, 탑다운에서는 구분하기 어렵다. 사용자 결정으로 3D 의 기준 시점이 3인칭이 됐다.
- v1 의 P5 는 "탑다운에서 D(A,B) 가 0a 값의 0.7~1.3배"였다. 탑다운 D(A,B) 는 3.0~3.2 로 작아서 비율 비교가 흔들리기 쉽다. 기준 구도를 3인칭으로 바꾼다.

## 바뀐 기준 (0b 에만 적용)

- P4 (계산 시간): v1 그대로. 256×256×8 칸, 압력 풀이 8회, 전부 계산, 오프스크린 성능 시험 중앙값 1.0 ms 이하 통과 / 1.0~1.5 ms 조건부 / 1.5 ms 초과 실패. 정보 표도 v1 그대로이고, 3인칭용 재료로 격자 256×256×16 과 128×128×32 를 반드시 포함한다.
- P5 (3D 텍스처를 안개 재질에 넣기): 실시간으로 쓴 3D 텍스처에 무늬 N·C·A·B 를 담아 안개 재질에 넣는다. 기준 구도는 0a 의 3인칭·안개 최대 거리 20m·격자 8픽셀·128층(0a 값 D(A,B) = 6.03). 같은 지표로 잰 D(A,B) 가 4.2~7.8(0a 값의 0.7~1.3배)이면 통과. 화면에 아무것도 안 나오면 실패(대체 길: 층들을 2D 그림 한 장에 펼쳐 넣기). 탑다운 값은 정보로만 적는다.
- P6 (재질 비용): v1 그대로. 엔진 볼륨 안개 GPU 시간 중앙값 증가 0.10 ms 이하 통과. 3인칭 구도와 탑다운 구도 둘 다 적는다.
- P7 (반응 지연, 정보): v1 그대로이되 3인칭 구도에서 잰다. 먼저 "촬영 방식이 엔진의 시간 섞기를 실제로 반영하는가"를 확인하고(연속 프레임에서 밝기가 단계적으로 변하는지), 반영하지 않으면 '측정 불가'로 적는다.

## 종합 규칙 (0b)

- P4 통과 또는 조건부, P5 통과 → 3인칭 기준 1단계 설계로 넘어간다(7절 단계 계획을 3인칭 기준으로 다시 짠다).
- P5 실패 → 2D 펼침 대체 길을 추가로 시험한다.
- P4 실패 → 칸 수·반복 수를 줄인 품질 단계 표를 만들어 사용자에게 보인다.

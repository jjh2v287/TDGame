## 0a 두 무늬의 화면 차이 (새 계산 코드 없음)

장면
- 무대 `LV_TDFluidFogStage` 의 평지(저장하지 않음). 시험용 볼륨 재질 상자(가로·세로 6m 이상, 높이 3m). 기본 안개는 땅 위 0~2.4m 에 균일하게 깔린다.
- 무늬 다섯 가지
  - N: 구멍 없음
  - C: 지름 3m 원기둥 안의 안개를 전부(0~2.4m) 지움
  - A: 같은 원기둥 안에서 위 절반(1.2~2.4m)만 지움
  - B: 같은 원기둥 안에서 아래 절반(0~1.2m)만 지움
  - A': A 를 한 번 더 찍은 것(잡음 바닥)
- A 와 B 는 지운 두께가 같다. 둘의 차이는 '어느 높이를 지웠는가'뿐이다.
- 안개 짙기 보정: A·B 를 찍기 전에 N·C 만으로 정한다. 탑다운·안개 최대 거리 60m 에서 D(N,C) 가 20~60 이 되게 한다.
- 구도
  - 탑다운: 스프링 암 800cm, 60도 내려봄, 시야각 90도, 1920×1080, 구멍 중심이 화면 가운데
  - 3인칭: 카메라 높이 1.7m, 구멍 중심(높이 1.0m)까지 수평 5m, 구멍 중심을 바라봄
- 엔진 안개 설정 네 가지: 최대 거리 20m / 60m / 120m (격자 8픽셀·128층), 그리고 최대 거리 20m 에서 격자 16픽셀·64층.
- 노출 고정. 장면마다 8장을 찍어 화소별로 평균한다.

지표
- 밝기 = RGB 평균(0~255).
- 영향 영역 M = |N − C| 가 2 이상인 화소.
- D(X,Y) = M 안에서 화소별 |X − Y| 의 평균.

판정 (구도 × 설정마다)
- 보임: D(A,B) ≥ 3.0 이고 D(A,B) ≥ 3 × D(A,A')
- 안 보임: D(A,B) < 1.0
- 판정 불가: M 이 화면의 0.2% 미만, 또는 D(A,A') > 1.0, 또는 D(A,B) 가 1.0~3.0 사이

관문
- P1 (탑다운): 격자 8픽셀·128층의 세 거리 중 하나 이상에서 '보임'이면 통과. 통과한 가장 먼 거리를 '탑다운 권장 최대 거리 후보'로 적는다. 셋 다 '안 보임'이면 실패. 그 밖은 판정 불가.
- P2 (3인칭, 같이 갈 수 있는지의 재료): 60m 또는 120m 에서 '보임'이면 "3인칭 같이 진행 후보". 20m 에서만 보이면 "먼 곳 처리가 먼저 필요, 탑다운 먼저". 판단 재료이며 단독 관문은 아니다.
- 정보: 격자 16픽셀·64층(20m) 결과는 품질 단계 설계의 재료로 적는다.

## 0b 엔진 안 3D 측정

- P4 (계산 시간): 256×256×8 칸, 압력 풀이 8회, 전부 계산. 오프스크린 성능 시험의 중앙값이 1.0 ms 이하면 통과. 1.0~1.5 ms 면 조건부(칸 수나 반복 수를 줄인 품질 단계로 진행). 1.5 ms 초과면 실패(사다리 아래 칸으로).
  - 정보: 격자 {128×128×8, 192×192×8, 256×256×8, 256×256×16} × 압력 풀이 {4, 8, 12, 16}회의 시간 표, 압력 풀이 뒤 남은 몰림의 비율.
- P5 (3D 텍스처를 안개 재질에 넣기): 실시간으로 쓴 3D 텍스처에 무늬 A·B 를 담아 안개 재질에 넣었을 때, 0a 와 같은 구도·설정(탑다운, 0a 에서 '보임'인 거리 하나)에서 D(A,B) 가 0a 값의 0.7~1.3배면 통과. 화면에 아무것도 안 나오면 실패(대체 길: 층들을 2D 그림 한 장에 펼쳐 넣기).
- P6 (재질 비용): 3D 텍스처를 읽는 재질로 바꿨을 때 엔진 볼륨 안개 GPU 시간의 중앙값 증가가 0.10 ms 이하면 통과.
- P7 (반응 지연, 정보): 구멍을 한 프레임에 켠 뒤 영향 영역의 평균 밝기가 최종값의 50%·90% 에 닿는 프레임 수를 엔진 안개의 시간 섞기 0.9 / 0.8 / 0.7 에서 적는다. 기준 없음(설정 권고의 재료).

## 0단계 종합 규칙

- P1 통과, P4 통과 또는 조건부, P5 통과 → 1a 착수를 권고하고, 사용자 눈 판정용으로 A·B 짝 그림(이름 가림)을 함께 보낸다.
- P1 실패 → 엔진 안개에 얹는 길로는 탑다운에서 층이 안 보인다는 뜻이다. 자체 그리기를 먼저 할지, '높이만 아는 2D'로 물러날지 사용자에게 묻는다.
- P5 실패 → 2D 펼침 대체 길을 0b 에 추가로 시험한다.
- 지표가 통과해도 사용자가 "차이가 안 보인다"고 하면 1a 로 넘어가지 않는다.

## 처음 계획에서 바꾼 것 (측정 전)

- "안개 8장을 동시에 돌려 8층 분량 비용 재기"는 뺐다. 0b 가 엔진 안에서 실제 3D 계산 시간을 직접 재므로 대용 측정이 필요 없다(액터를 늘리면 에디터가 죽는 위험도 피한다).
- 반응 지연 측정은 0a 에서 0b 로 옮겼다. 실시간 3D 텍스처가 있어야 움직이는 구멍을 자연스럽게 만들 수 있다.
- 무늬 A·B 는 '지운 두께가 같은 위 절반·아래 절반'으로 정했다. 두께가 다르면 높이가 아니라 지운 양의 차이를 재게 된다.

## 무늬와 좌표 약속 (0b-1 스크립트와 0b-2 코드가 같이 쓴다)

- 시험 상자는 0a 와 같다: 600×600×300cm, 바닥이 땅. 3D 텍스처 좌표 UVW = (세계 좌표 − 상자 최소) ÷ 상자 크기.
- 원기둥은 상자 가운데, 반지름 150cm(UV 반지름 0.25). 층 경계 높이 120cm(W 0.4), 안개 꼭대기 240cm(W 0.8). W 0.8 위는 농도 0.
- 무늬 번호: 0 = N(구멍 없음), 1 = C(원기둥 전체 지움), 2 = A(위 절반 1.2~2.4m 지움), 3 = B(아래 절반 0~1.2m 지움).
- 텍스처 형식 RGBA16F. 농도는 알파 채널(0~1). 재질의 소광 = 0a 수식판과 같은 값 × 알파.
- 해상도 두 가지: 촘촘(128×128×64, P5 판정용), 계획 격자(40×40×10 = 칸 15cm·층 30cm, 정보용).
- 재질의 3D 텍스처 파라미터 이름: `DensityVolume`.
- 콘솔 명령(출하 빌드가 아닐 때만): `TD.Fog3D.ProbeWrite <볼륨 렌더 타깃 오브젝트 경로> <무늬 0~3>`. 그 렌더 타깃 전체에 위 무늬를 계산 셰이더로 쓴다.

## 0b-2 C++ 범위 (모듈 TDFluidGpu, 새 파일만, 기존 파일 수정 0)

- `Source/TDFluidGpu/Shaders/Private/TDFluidGpuVolFogProbe.usf`
  - 한 번 계산을 이루는 4종(읽는 텍스처와 쓰는 텍스처를 나눈 핑퐁): ① 옮기기 + 입력(바람 3방향과 흐트러짐을 RGBA16F 한 장에 담아 삼선형 샘플 1회, 입력 8개 적용) ② 몰림 계산 ③ 압력 반복 1회 ④ 압력 기울기 빼기. 이웃 6칸의 막힘은 8비트 판 한 장에서 읽는다.
  - 무늬 쓰기 1종(위 약속대로).
- `Source/TDFluidGpu/Private/TDFluidGpuVolFogProbe.h`·`.cpp`: 전역 셰이더 클래스, 한 번 계산의 패스를 더하는 함수(격자 크기·압력 반복 수), 무늬 쓰기 함수(볼륨 렌더 타깃, 무늬 번호), 위 콘솔 명령.
- `Source/TDFluidGpu/Private/Tests/TDFluidGpuVolFogProbeRhiTests.cpp` (자동화 시험 빌드에서만)
  - `TDGame.FluidFXRhi.VolFogProbe.StepTiming`: 격자 {128×128×8, 192×192×8, 256×256×8, 256×256×16, 128×128×32} × 압력 반복 {4, 8, 12, 16}. 기존 성능 시험과 같은 방식(워밍업 60, 측정 120프레임, 중앙값·95백분위). 결과는 `Saved/FluidFX/perf/volfog3d_probe_timing.json`. 압력 반복 뒤 남은 몰림의 비율(반복 전 대비)도 읽어 와 적는다.
  - `TDGame.FluidFXRhi.VolFogProbe.VolumeTargetWrite`: 볼륨 렌더 타깃에 무늬를 쓰고 읽어 와 값이 약속과 맞는지 확인.
- 규칙: 주석 금지, 이름에 TD, 조기 리턴. 쿠킹이 쓰는 낮은 셰이더 단계에서도 컴파일돼야 한다(`Tools/FluidFX/check_fluid_gpu_shaders.py`, CookGlobalShaders). 통합 빌드 이름 충돌 검사 통과.
- 실행 순서는 준비 조사 6절(보류 획득 → 빌드 캐시 파일 삭제 → 검사 → `python Tools/build_and_test.py --filter TDGame.FluidFXRhi.VolFogProbe --label fog3d-0b --rhi offscreen` → 결과 JSON → 쿠킹 셰이더 확인 → 보류 해제).

## 0b-1 이 만드는 것 (재설정 전)

- 텍스처판 시험 재질: 0a 수식판과 같은 상자에서 `DensityVolume` 을 읽는다. 메모리 안에만 만들고 저장하지 않는다.
- 파이썬으로 볼륨 렌더 타깃 만들기(계산 셰이더가 쓸 수 있는 옵션 켬)와 상수 값으로 지우기.
- P5 예비: 상수 농도 1 의 볼륨 렌더 타깃을 텍스처판 재질에 넣어 3인칭 구도로 찍고, 수식판 N 과 같은 지표 D 로 비교한다(잡음의 3배 이내면 "읽는다").
- P6: 수식판 재질과 텍스처판 재질에서 엔진 볼륨 안개 GPU 시간의 중앙값 차(3인칭·탑다운).
- P7: 수식판의 무늬를 한 프레임에 N → C 로 바꾸고 연속 프레임을 찍어, 영향 영역 평균 밝기가 최종값의 50%·90% 에 닿는 프레임 수를 시간 섞기 0.9 / 0.8 / 0.7 에서 잰다. 먼저 촬영 방식이 시간 섞기를 반영하는지 확인하고, 반영하지 않으면 '측정 불가'로 적는다.
- P5 본 측정용 촬영 계획 스크립트(콘솔 명령으로 무늬 전환). 실행은 0b-3.

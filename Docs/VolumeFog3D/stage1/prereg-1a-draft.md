# 1a 통과 기준 — GPU 계산 핵심 (초안 3판)

상태: **초안 3판**(2026-11-13, 반박 V3·V4·V5·V6·V7·V8 반영). 규칙의 꼴은 여기서 정했다. 【기준값】 칸은 작업 1a-0 이 올린 기준 모의(명세 v1 의 최종 구성)로 뽑아 채운다. 채운 뒤 GPU 를 한 번도 재기 전에 `prereg-1a.md` 로 등록하고 해시로 잠근다. 잠근 뒤에는 고치지 않는다.

## 0. 원칙

1. 1a 가 판정하는 것은 "GPU 구현이 기준 모의(파이썬 참조 계산)와 같은 계산을 하는가"이다. 설계가 좋은지는 설계 판정선이 기준 모의로 이미 판정했다.
2. 설계 판정선(높이 구분 등)은 GPU 값으로 다시 재서 정보로 적는다. 다만 설계 여유가 10% 미만인 높이 구분 비(기준 모의 2.100, 기준 2)가 GPU 에서 2 를 못 넘으면, 1b 를 시작하기 전에 감독이 원인을 본다.
3. 구조상 늘 맞을 수밖에 없는 확인은 "자명한 확인"으로 따로 적고 통과 근거로 세지 않는다.
4. 사용자 지시(2026-10-25)대로 칸마다 빌드·회귀·결정론·오프스크린만 본다. 시간은 정보다.
5. 잠그기 전에 GPU 로 재는 것은 없다. 쌓이는 값이 모두 32비트라 저장 반올림을 흉내 낼 필요가 없다.

## 1. 공통

- 시험 이름 `TDGame.FluidFXRhi.Fog3D.*`. 실행 `python Tools/build_and_test.py --filter FluidFXRhi.Fog3D --label fog3d --rhi offscreen`.
- 구성: 명세 v1 의 최종 구성과 기본 데이터 값. 기준 모의와 GPU 는 풀이 방식·색 순서·훑기 횟수·계산 순서·자리 약속(u = +x 면, v = +y 면, w = 윗면)이 같아야 한다.
- 장면은 기준 모의가 내보낸 "장면 재생 파일"(계산마다의 시간 간격, 따라갈 점, 쓸린 구 목록, 물체 목록, 시험용 손잡이, 코드 지문)을 C++ 시험이 그대로 재생한다. 장면을 손으로 옮겨 적지 않는다. 입력 위치는 창 기준 값 그대로 주고, 원점은 정수 칸 번호로만 옮긴다.
- 기준 모의는 64비트로 계산하고 32비트로 저장한다. 길 따라가기의 경계 비교는 32비트로 한다. GPU 는 32비트로 계산하고 저장한다.
- 대조·해시는 유체 칸만 본다(막힌 칸의 그리기용 값은 기준 모의에 없다).
- 상태 해시 = 바람 u·v·w, 밀린 거리 3성분, 채움의 32비트 값을 창 순서(지역 x 가 가장 바깥, 높이가 가장 안쪽)로 늘어놓은 것의 sha256. 막힌 칸은 0 으로 놓고, −0 은 +0 으로 바꾼 뒤 계산한다.
- "값이 0" = +0 또는 −0.
- "차이값" = 그려지는 농도와 평소 농도의 차 = max(0, 1 + g) × B(칸 가운데 − d 의 높이) − B(칸 가운데의 높이)(`prereg-design-2b.md` 2절).
- 장 차이 = (두 장의 차)의 제곱합 제곱근 ÷ (기준 장)의 제곱합 제곱근. 따로 적지 않으면 창 가장자리 띠 8칸은 뺀다. 바람(u·v·w), 밀린 거리(3성분), 채움을 따로 잰다.
- 대조 허용값 X = max(0.2%, 민감도 × 3), 상한 3%. 민감도 = 기준 모의에서 모든 입력 위치를 1e-4cm 흔든 실행과 흔들지 않은 실행 사이의 장 차이(32비트 계산과 64비트 계산의 차, 길 따라가기의 거의 같은 시점 뒤집힘을 대신하는 값). 등록할 때 장면별 X 를 숫자로 적는다.
- 기준 모의와의 대조는 모두 고정 시간 간격으로 한다(따로 적지 않으면 1/60초). 붓·깎기 시험은 창 원점과 칸 모서리의 관계를 기준 모의와 같게 둔다.
- 가로와 세로 이동이 정확히 같은 대칭 바람 시험(A13 의 45° 벽·볼록 모서리·쌓은 벽)은 밀린 거리가 아니라 채움으로만 판정한다(길 따라가기의 순서 규칙이 벽 옆 칸의 밀린 거리를 바꿀 수 있다).

대조 장면(모두 장면 재생 파일로)
- 가 내려찍기(설계 D-V1 입력), 0.5초 시점. 128×128.
- 나 낮게 휘두르기 + 깎기 초당 30(설계 D-V2 낮음 입력), 0.3초 시점. 128×128.
- 다 높은 상자 앞에 멈춘 바람 입력(설계 D-V3 높음), 1초 시점. 128×128.
- 라 달리기: 구 입력이 초속 6m 로 2초(창 이동 4번 이상). 낮은 상자 하나와 얇은 벽 하나를 "처음 창 밖에 있다가 새 띠로 들어오는 자리"에 둔다. 끝 시점. 128×128.
- 마 장면 나를 시간 간격 1/30초로.
- 바 장면 나를 256×256 으로.
- 사 얇은 벽(두께 10cm) 옆에서 벽 쪽으로 휘두르기 + 깎기, 0.3초 시점. 128×128.
- 아 이음매에서 4칸 안쪽 입력(A12 장면), 1초 시점. 이 장면만 가장자리 띠를 넣어서 장 차이를 잰다.

## 3. 자명한 확인과 정보 (통과 근거로 세지 않음)

- 자명한 확인: 다시 차오름 절반 시간 2.31초 ±1%.
- 정보: 격자별·패스별 시간(256×256×8, 128×128×8, 정리 패스가 도는 프레임 포함), 설계 판정선(내려찍기, 높이 구분, 상자)의 GPU 값과 기준 모의 값, 움직이다 멈춘 첫 계산의 남은 몰림 비, 장면별 실제 장 차이.

## 4. 판정

- A1~A16 을 모두 만족하면 1a 통과.
- 실패하면 원인을 고치고 다시 잰다. 기준은 바꾸지 않는다. 기준 자체가 틀렸다고 판단되면 그 사실을 적고 새 판을 다음 측정 전에 등록한다.

## 2. 촬영 절차 고침 (식·영역·문턱은 그대로)

1. mode2_a 의 유효 조건을 게임 시간으로 정한다: 휘두르기 명령의 게임 시각에서 mode2_a 촬영 게임 시각까지가 2.15초 이상 3.0초 이하(동작 1.85초 + 여유). mode2_b 는 mode2_a 뒤 0.3~1.0초. mode0_a 는 모드 0 명령 뒤 0.8초 이상, mode0_b 는 mode0_a 뒤 0.3~1.0초. 결과 파일의 게임 시각으로 확인하고, 벗어난 실행은 절차 고장이므로 판정하지 않고 다시 찍는다(벗어난 실행의 값도 적어 둔다). 변형 파일은 새 이름으로 만들고 지문을 판정 실행 전에 적는다. 정착 시간을 어떻게 맞추는지는 자유다.
2. 대조 실행: 판정 실행과 같은 에디터 프로세스에서, 판정 실행보다 먼저, 3D 안개 구역이 없는 기존 맵에서 PIE 를 열어 같은 칼 휘두르기 명령을 한 번 돌린다. 그 구간의 로그에 같은 ensure 가 나오면 "3D 안개와 무관"으로 본다. 알고 정하는 것: 엔진의 ensure 는 프로세스마다 한 번만 로그를 남기므로, 대조 실행에서 나오면 판정 구간에는 다시 나오지 않는다. (3) 은 등록 문장 그대로(판정 구간의 줄 수 0) 판정하고, 이 사정을 판정 기록에 함께 적는다. 대조 실행에서 ensure 가 나오지 않았는데 판정 구간에서 나오면 (3) 실패이고 3D 안개와 관련된 것으로 보고 조사한다.

## 3. 원인(값) 고침의 규칙 — 후보를 차례로, 처음 통과하는 것

기본값을 아래 후보로 바꾼 조절 사본으로 정보용 진단 촬영을 한다(코드 재빌드 없이 조절 표 다시 읽기). 각 후보마다 2절의 유효 조건을 지킨 여덟 장(또는 반응 쪽 네 장)을 한 번 찍어 등록된 (2) 식을 계산한다.

| 후보 | 바꾸는 값 |
|---|---|
| S0 | 지금 기본값(견주기용, 고르지 않는다) |
| S1 | 몸(손·두 발·골반)의 깎기 초당 4. 칼날 초당 30 그대로 |
| S2 | 얼룩 켬(세기 0.3, 간격 200cm). 몸 깎기 0 |
| S3 | S1 + S2 |
| S4 | 몸 깎기 초당 8 + 얼룩 켬 |

- 고르는 규칙: S1 → S2 → S3 → S4 차례로, 진단 촬영에서 (2) 가 통과(비 ≥ 3 그리고 차 ≥ 1/255)하는 첫 후보를 기본값으로 채택한다. 하나도 통과하지 못하면 채택하지 않고 "기본값 조정만으로는 안 됨"으로 보고한다.
- 채택한 값은 헤더 기본값과 정본 JSON 에 넣고 빌드·시험을 다시 돌린 뒤, 판정 실행을 정확히 한 번 한다(2절의 유효 조건을 어긴 절차 고장은 세지 않는다). 그 한 번의 결과가 이번 회차의 B8 판정이다. 실패하면 더 조정하지 않고 실패로 보고한다.
- 이 값들은 명세 9절의 결정 9("몸 깎기 0, 얼룩 끔")와 달라진다. 명세가 "1c 일괄 보정" 대상으로 적어 둔 값이고, 모양이 좋은지는 여전히 1c 에서 사용자가 눈으로 판정한다. 달라진 사실은 결정 기록에 편차로 적는다.

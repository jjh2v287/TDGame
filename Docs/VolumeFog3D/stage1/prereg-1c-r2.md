# 1c 2회차 — 사용자 눈 판정 뒤의 촬영 목록과 탑다운 개념 증명 (등록본)

등록: 2026-11-14 claude(감독·결정). 정확한 시각은 이 파일의 수정 시각이다. 2회차 화면을 찍기 전에 썼다. 1회차 등록본 `prereg-1c.md` 와 덧붙임 둘의 시각표·영역·식은 그대로 쓴다.

## 0. 사용자 눈 판정 (2026-11-14, 눈 판정 페이지의 답)

중 / 걷기 자국은 그 정도로 / 휘두르기 자국은 그 정도로 / 구름 무늬는 더 뚜렷하게 / 거슬리는 것: 걷기 자국이 한쪽으로 치우침, 안개가 납작한 한 장처럼 보임 / 걷기 자국이 발 뒤로 이어졌으면.
추가 제안: 탑다운에서도 3D 안개가 보이는지 — 바닥은 짙고 위로 갈수록 옅은 안개면 칼을 휘둘렀을 때 바닥 쪽 안개가 밀려 빈 자리가 보이지 않겠는가.

"중"의 값(이 문서에서 "중 값"): FootRadiusCm 45, HandRadiusCm 45, PelvisRadiusCm 60, BodyWindStrength 2, BladeRadiusCm 30, 얼룩 켬 0.6 / 400cm.

## 1. 탑다운 개념 증명

- 카메라 "top" = 게임 기본 카메라(팔 800cm, 내려다보는 각 60도, 방향 0. `TDGameCharacter.cpp` 의 값). 빛은 옆빛, 시각표는 1회차 등록본 그대로.
- 영역 C = 화면 세로 [0.25 H, 0.75 H) × 가로 [0.25 W, 0.75 W).
- 안개 보임 Fv = C 안 |Y(S 기준 장) − Y(구역 숨김 장)| 의 평균. 구역 숨김 장은 같은 카메라·빛으로 구역 액터를 숨기고 한 번 찍는다.
- 반응 세기 Rs = C 안 |Y(S 2.5초 장) − Y(S 기준 장)| 가운데 큰 쪽 2% 화소의 평균. 잡음 Rn = 기준 장 둘로 같은 식. 걷기 Rw = W 12.1초 장과 W 기준 장으로 같은 식.
- 구성(값 바꾸기):

| 이름 | 값 |
|---|---|
| T0 | 기본값 |
| T1 / T2 / T3 | BaseDensity 4 / 8 / 16 |
| T4 | BaseDensity 8 + BaseThicknessCm 150·BaseTopBlurCm 120(바닥 30cm 가 짙고 150cm 까지 서서히 옅어짐) |
| T5 | BaseDensity 16 + 같은 높이·흐림 |
| T6 | T4 + 중 값에서 얼룩을 뺀 것 |
| T7 | T5 + 중 값에서 얼룩을 뺀 것 |
| T8 | T7 + 얼룩 0.6 / 400cm |

- 덧붙여 눈으로만: T4·T7 을 뒤 카메라로 한 번씩(짙은 안개가 3인칭에서 어떻게 보이는가), T7 을 엔진 깊이 칸 2배(`r.VolumetricFog.GridSizeZ` 를 지금 값의 2배로, 끝나면 되돌림)로 한 번.
- 성공 기준(찍기 전에 정함): 어느 한 구성에서 Fv ≥ 10 이고 Rs ≥ 12 이며 Rs ≥ 3 × Rn. 이 숫자는 "위에서도 안개와 칼 자국이 화면에 나온다"만 본다. 빈 자리로 읽히는지와 보기 좋은지는 그림으로 사용자가 판단한다. 어느 구성도 못 미치면 "지금 방식으로는 탑다운에서 안 보인다"로 보고한다.

## 2. 한쪽 치우침 진단 (중 값, 뒤 카메라 — 카메라 방향은 걷는 방향에 맞춘다)

- 좌우 걷기 자국: 1회차의 걷기 영역 RW 를 가로 가운데(0.50 W)에서 둘로 나눠 Wk_L·Wk_R(각각 W 12.1초 장과 W 기준 장의 차 평균). 치우침 = (Wk_L − Wk_R) ÷ (Wk_L + Wk_R).
- 실행: A0 중 값 그대로 +X 로 걷기 / A1 칼의 바람과 깎기를 0 으로(BladeWindStrength 0, BladeErosionPerSec 0) / A2 −X 로 걷기 / A3 +Y 로 걷기 / A4 빛을 반대쪽에서(해 높이 35도, 방향 280).
- 읽는 법(미리 정함): A1 에서 치우침이 절반 아래로 줄면 칼 쪽 입력이 원인. A2·A3 에서 치우침이 폰 기준 같은 쪽(폰의 왼쪽)에 남으면 폰 쪽 원인, 세계 축 기준 같은 쪽에 남으면 계산 격자 쪽 원인. A4 에서 뒤집히면 빛 때문에 그렇게 보이는 것.
- 따로, 기준 모의로 좌우 대칭 입력을 넣어 계산 자체가 치우치는지 본다(촬영 없음).

## 3. 구름 무늬와 걷기 자국의 이어짐 (중 값 위에, 뒤 카메라로 숫자 + top 카메라로 눈)

| 이름 | 더 바꾸는 값 |
|---|---|
| C1 | 얼룩 0.75 / 400cm |
| C2 | 얼룩 0.75 / 600cm |
| C3 | 얼룩 0.85 / 500cm |
| C4 | C1 + BaseThicknessCm 110·BaseTopBlurCm 70 |
| R1 | DisplacementRefillHorizontalPerSec 0.05·VerticalPerSec 0.15 |
| R2 | R1 + WindRefillPerSec 0.5 |

- 고르는 규칙: 구름 무늬는 평소 무늬 Tx2 가 중 값(0.45)보다 크고, 휘두르기 자국 Sk2(2.5) 가 중 값의 0.8배 이상 남는 것 가운데 감독이 그림을 보고 하나를 고른다(얼룩덜룩해 자국을 가리면 탈락). 걷기 자국의 이어짐은 다시 차오름 비 Wk(17.6) ÷ Wk(12.1) 가 0.4 이상이면서 Wk(12.1) 가 8~14 인 것 가운데 고른다. 고른 값은 사용자에게 그림으로 다시 보인다.

# 1단계 마무리 촬영 — 1c 에서 미뤄 둔 목록과 전체 비용 (등록본)

등록: 2026-11-14 claude(감독·결정). 정확한 시각은 이 파일의 수정 시각이다. 촬영 전에 썼다. 사용자 지시 "마무리 촬영부터"(같은 날). 근거: `prereg-1c.md` 8절(2회차로 미룬 목록)과 계획 문서 7절의 1c 줄("+ 전체 비용").

## 0. 성격

보여 주기와 정보 숫자가 목적이다. 값을 맞추지 않고, 코드·기본값·에셋을 바꾸지 않는다. 숫자에는 판정선을 두지 않는다(표시용 문턱 하나만 둔다). 1단계를 닫는 판정은 5절 한 가지다.

## 1. 공통 조건

- 새 기본값 그대로(조절 표 사본을 쓰면 정본과 같은 내용), 무대 `LV_TDFog3DStage` 의 옆빛 그대로, 1280×720, 초당 60장 고정, 따로 적지 않으면 품질 높음(256칸·초당 60번).
- 실행마다 유효성(제출 거부 0, 3D 안개 경고·오류 0)을 확인하고, 에디터를 띄운 뒤 첫 판정 실행 전에 대조 실행을 한다.
- 폰을 다른 자리에 세울 때는 계산을 끈 동안 순간이동한다. 폰은 +X 를 본 채로 둔다(방향끼리 견주는 촬영이 아니다. 견줄 일이 생기면 L-editor-104 를 따른다).

## 2. 찍을 것

A. 물체 옆(0.1초 간격, 뒤 카메라와 물체 면을 모로 보는 카메라)
- A1 낮은 상자(높이 30cm): 상자의 −X 쪽 120cm 앞에 서서 +X 로 휘두르기. 상자 옆 60cm 를 +X 로 걸어 지나가기.
- A2 높은 상자(높이 180cm): 같은 두 가지.
- A3 얇은 벽(두께 10cm): 벽의 −X 쪽 100cm 앞에 서서 벽 쪽으로 휘두르기.
- 숫자(정보): 휘두른 뒤 2.5초 장과 기준 장(계산 끔)의 밝기 차이로, 물체 면에서 20~120cm 띠의 평균을 가까운 쪽과 먼 쪽에서 재어 "먼 쪽 ÷ 가까운 쪽". 기대: 낮은 상자는 넘어가고, 높은 상자와 벽은 막힌다. 다만 칼의 입력 구가 벽 너머에 닿는 것을 막는 일은 2단계 항목이라 벽 너머가 0 이 아닐 수 있다 — 그대로 적는다.

B. 품질 단계와 창
- B1 품질 낮음(128칸·30번)·보통(256칸·30번)·높음(256칸·60번): 등록된 시각표(+X, 뒤 카메라)로 걷기 자국 다섯 시각·휘두르기·좌우 치우침, 그리고 0.1초 간격 그림을 셋 나란히.
- B2 거리: 품질 낮음과 높음에서 카메라 팔 500·1000·2000cm(내려봄 20도)로 가만히 선 장과 휘두른 뒤 장. 볼 것은 창 가장자리(낮음 ±1000cm, 높음 ±2000cm)가 보이는가. 숫자: 가만히 선 장에서 창 가장자리 선의 안쪽 100cm 띠와 바깥쪽 100cm 띠의 평균 밝기 차(8비트). 1.0 이하면 "안 보임"으로 적는다(표시용 문턱).

C. 2D 안개와 나란히
- 2D 무대 `LV_TDFluidFogStage` 와 3D 무대에서 같은 시각표(+X, 뒤 카메라)로 0.1초 간격 촬영 → 왼쪽 2D, 오른쪽 3D 로 나란히 도는 그림(휘두르기, 걷기). 무대의 빛과 바닥이 달라 숫자는 견주지 않는다. 다른 점을 적는다.

D. 반박이 짚었던 볼 것
- A 와 B1 의 0.1초 장을 직접 열어 다음이 있는지 본다: 밀린 곳을 깎은 뒤 드러나는 구멍, 빠른 베기에서 무늬가 접혀 보이는 것, 맨 위 층 근처에서 잘리는 것, 벽·상자 옆의 안개 띠, 깜빡임, 네모난 모양. 있으면 실행·시각·자리를 적는다.
- 내려찍기와 높이가 다른 베기는 공격 동작이 하나뿐이라 찍지 못한다(기록만).

E. 전체 비용(정보)
- 조건 다섯: 구역 숨김(3D 안개 없음) / 계산 끔(그리기만) / 낮음 / 보통 / 높음. 조건마다 폰이 서 있을 때와 걷기·휘두르기를 되풀이할 때.
- 재는 값: GPU 프레임 시간의 중앙값(300프레임 이상), 3D 안개 계산 패스들의 합, 엔진 볼륨 안개 패스. 조건마다 두 번 재어 차이를 적는다. 도구는 있는 것을 쓴다(`Tools/pie_profile.py`, GPU 통계).
- 계획의 3단계 목표(걷기만 0.3ms, 보통 싸움 0.8ms, 최악 1.5ms)와 나란히 적되 판정하지 않는다(줄이는 일은 3단계다). 에디터 안에서 잰 값이라는 점을 적는다.

## 3. 사용자에게 보일 것

물체 옆 그림(A1·A2·A3), 품질 셋 나란히(B1), 창 가장자리 장(B2), 2D 와 3D 나란히(C), 비용 표(E), 찾은 흠 목록(D).

## 4. 지킬 것

코드·기본값·에셋·레벨을 바꾸지 않는다. 촬영 도구에 기능을 더할 수 있다(자체 점검은 통과해야 한다). 숫자를 좋게 보이려고 영역·식을 바꾸지 않는다.

## 5. 1단계를 닫는 판정

목록을 유효한 실행으로 모두 찍었고(내려찍기 제외), 치명적인 결함(안개가 사라짐, 화면이 깨짐, 오류·경고, 제출 거부)이 없으면 1단계를 닫는다. 찾은 흠은 2~4단계의 할 일로 옮겨 적는다. 치명적인 결함이 있으면 닫지 않고 원인을 먼저 본다.

# 1c 눈 판정·일괄 보정 — 촬영 목록과 절차 (등록본, 1회차)

등록: 2026-11-14 00:30 무렵 claude(감독·결정). 정확한 시각은 이 파일의 수정 시각이다. 1c 의 화면을 한 장도 찍기 전에 썼다. 잠근 뒤에는 고치지 않고, 바꿀 것이 생기면 덧붙임을 다음 촬영 전에 따로 쓴다.

## 0. 이 단계에서 정하는 것과 정하는 사람

- 모양이 좋은지는 사용자가 눈으로 정한다. 감독(나)은 후보를 만들고, 숫자로 걸러 내고, 권장안을 낸다.
- 1회차(이 문서): 값을 하나씩 바꿔 보는 탐색 → 후보 세 벌(약·중·강) → 사용자에게 보여 줄 묶음.
- 2회차(사용자가 고른 뒤): 고른 값으로 기본값 확정(코드·데이터·시험), 그리고 남은 촬영 목록(8절).
- 1b 에서 알게 된 출발점: 칼 휘두르기 반응은 보이지만 걷기만으로는 자국이 거의 안 보이고, 평소 안개가 무늬 없는 매끈한 한 장으로 보인다. 위에서 내려다보는 시점은 0단계 결정대로 2D 안개의 몫이라 이번 판정은 3인칭 기준이다.

## 1. 고정 조건

- 무대 `/Game/FluidFX/Maps/LV_TDFog3DStage`, 화면 1280×720, 노출 고정(무대의 후처리 볼륨), 품질 높음(창 256칸, 초당 60번), 게임 시간은 초당 60장 고정(촬영 도구의 예약 촬영).
- 카메라 셋: 뒤(팔 400cm, 내려다보는 각 12도, 방향 0) / 옆(팔 500cm, 20도, 방향 90) / 비스듬히 위(팔 700cm, 35도, 방향 30). 탐색은 "뒤" 하나로 하고, 시운전과 후보 묶음에서 셋을 다 찍는다.
- 빛: 시운전에서 세 가지(원래 = 해 높이 18도 역광 / 옆빛 = 해 높이 35도·방향 100 / 앞빛 = 해 높이 40도·방향 20)를 기본값으로 찍어 보고 감독이 하나를 고른다. 고른 뒤에는 탐색과 후보 묶음 내내 고정한다. 빛은 PIE 안에서만 바꾸고 맵 에셋은 고치지 않는다(맵에 넣는 것은 사용자가 모양을 고른 뒤).
- 실행 전에 같은 에디터에서 3D 안개 구역이 없는 맵의 칼 휘두르기를 한 번 돌린다(애니메이션 미리 읽기, 엔진 ensure 는 L-editor-98).

## 3. 숫자 (후보를 거르는 데만 쓴다. 통과·실패 판정이 아니다)

밝기 Y 는 1b 와 같다((0.2126 R + 0.7152 G + 0.0722 B) ÷ 255, 저장된 8비트 그대로). 아래 값은 255 를 곱해 적는다.

- 걷기 자국 영역 RW = 화면 세로 [0.72 H, 0.98 H) × 가로 [0.35 W, 0.65 W) (뒤 카메라에서 폰 발 아래부터 카메라 쪽 땅).
- 휘두르기 영역 RS = 세로 [0.60 H, 0.95 H) × 가로 [0.25 W, 0.75 W) 에서 가운데 [0.42 W, 0.58 W) 를 뺀 곳.
- 걷기 자국 대비 Wk(t) = RW 안 |Y(W t초 장) − Y(W 기준 장)| 의 평균. 대표값은 12.1초 장.
- 휘두르기 자국 대비 Sk(t) = RS 안 |Y(S t초 장) − Y(S 기준 장)| 의 평균. 대표값은 2.5초 장.
- 되풀이 잡음 N = 그 영역 안 |기준 장 첫째 − 둘째| 의 평균.
- 다시 차오름 비: Sk(7.0) ÷ Sk(2.5), Wk(17.6) ÷ Wk(12.1).
- 평소 무늬 Tx = S 기준 장의 RS 에서 "Y − 흐리게 한 Y(가우스 σ 20화소)"의 제곱평균제곱근.
- 로그: 끝날 때 요약 줄의 거부 수, Fog3D 경고·오류 줄 수(0 이어야 그 실행을 쓴다).

이 숫자들은 뒤 카메라에서만 계산한다. 옆·비스듬히 위 카메라의 그림은 눈으로만 본다.

## 4. 탐색: 값을 하나씩 바꿔 보기 (조절 표 사본, 다시 빌드 없음)

기본값에서 한 가지만 바꾼 실행을 하나씩 찍는다(뒤 카메라, 고른 빛).

| 묶음 | 바꾸는 값(데이터 필드) | 수준 |
|---|---|---|
| 몸 깎기 | BodyErosionPerSec | 4, 12, 30 |
| 몸 크기 | FootRadiusCm·HandRadiusCm 35 + PelvisRadiusCm 45 (몸 깎기 12 와 함께) | 1벌 |
| 얼룩 | bStainNoiseEnabled 켬 + StainNoiseAmplitude / StainNoiseSpacingCm | 0.3 / 200, 0.6 / 300, 0.6 / 500, 0.9 / 400 |
| 잔무늬 | FineNoiseAmplitude / FineNoiseSpacingCm | 끔, 0.5 / 100, 0.5 / 150, 0.8 / 150 |
| 안개 높이 | BaseThicknessCm (BaseTopBlurCm 는 그 절반) | 60, 130, 170 |
| 안개 짙기 | BaseDensity | 0.4, 1.6 |
| 다시 차오름 | FillRefillPerSec | 0.15, 0.6 |
| 밀린 것 되돌림 | DisplacementRefillHorizontalPerSec / VerticalPerSec | 0.03 / 0.1, 0.3 / 0.9 |
| 바람 | BodyWindStrength·BladeWindStrength 2 / WindRefillPerSec 0.3 | 2벌 |
| 칼 | BladeErosionPerSec 60 / BladeRadiusCm 30 | 2벌 |
| 바람 없는 판 | 콘솔 `TD.Fog3D.Mode 1`(표의 Mode 2 자리에) | 1벌 |
| 엔진 안개 | 콘솔 `r.VolumetricFog.HistoryWeight 0.7` / `r.VolumetricFog.GridPixelSize 8` | 2벌(실행 뒤 원래 값으로 되돌린다) |

값 검사에 걸리는 수준은 건너뛰고 그 사실을 적는다. 기본값 실행은 처음과 끝에 한 번씩(같은 값이 다시 나오는지 본다).

## 5. 후보 세 벌을 만드는 규칙

탐색 표를 보고 감독이 값을 조합해 세 벌을 만들고, 조합한 까닭을 적는다. 목표는 숫자로 미리 정한다.

| 후보 | 걷기 자국 대비 Wk(12.1) | 평소 무늬 Tx | 휘두르기 Sk(2.5) |
|---|---|---|---|
| 약 | 3~5 | 기본값의 1.5배 이상 | 기본값 이상 |
| 중 | 8~12 | 약보다 뚜렷하게 | 기본값 이상 |
| 강 | 16 이상 | 중 이상 | 중 이상 |

- 모든 후보는 Wk(12.1) 가 되풀이 잡음 N 의 3배 이상, Fog3D 경고·오류 0, 계산 거부 0 이어야 한다.
- 후보를 한 번 찍어 위 범위에 드는지 확인한다. 안 들면 값을 한 번만 고쳐 다시 찍는다(고친 내용을 적는다). 그래도 안 들면 든 것만 후보로 내고 사실대로 적는다.
- 안개 높이(무릎 90cm / 허리 130cm 안팎)는 숫자 목표 없이, 탐색에서 본 대로 후보에 섞어 사용자가 견줄 수 있게 한다.

## 6. 사용자에게 보여 줄 묶음

- 기본값과 후보 셋, 장면 둘(휘두르기·걷기), 카메라 둘(뒤, 비스듬히 위)의 시간 순 그림과 움직이는 그림.
- 묻는 것: ① 어느 후보가 좋은가 ② 걷기 자국·휘두르기 자국·평소 무늬를 각각 더 세게 / 약하게 ③ 안개 높이 ④ 거슬리는 것(깜빡임, 네모난 모양, 경계).

## 7. 지킬 것

- 통과 기준(1a·1b)과 그 문서는 건드리지 않는다. 이 회차에는 코드·기본값·에셋을 바꾸지 않는다(조절 표 사본과 PIE 안 설정만). 새 도구와 문서, 그림만 생긴다.
- 숫자 목표에 맞추려고 영역·식을 바꾸지 않는다. 숫자가 눈과 어긋나 보이면 그 사실을 적고 사용자에게 그림으로 보인다.

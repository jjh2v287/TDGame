# 1d 바람 옮기기 방식 교체 — 설계 판정선과 고르는 규칙 (등록본)

등록: 2026-11-14 claude(감독·결정). 정확한 시각은 이 파일의 수정 시각이다. 새 방식의 기준 모의 실험을 돌리기 전에 썼다(앞서 돌린 것은 원인 분석 `Saved/AgentOps/20261114/fog3d/stage1c/ra-asymmetry.md` 뿐이다: 물체 없는 장면에서 지금 방식의 치우침 +0.205, 면마다 따로 옮기는 방식 0.000).

## 0. 왜 바꾸나

지금 방식(명세 v1 의 A1)은 칸의 +면 바람 값을 칸 가운데 바람으로 써서 한 번만 거슬러 올라간다. 그래서 좌우 대칭 입력에도 반응이 세계 −X·−Y 쪽으로 치우치고(+0.205), 걷는 방향에 따라 화면의 자국 세기가 2.7배 다르다(L-editor-103). 사용자가 눈 판정에서 "한쪽 치우침"을 거슬리는 것으로 짚었다.

## 1. 후보 (값싼 순)

| 후보 | 내용 |
|---|---|
| N1 | 한 번만 거슬러 올라가되, 칸 가운데 바람을 양쪽 면 값의 평균으로 잡는다(바람 세 성분과 밀린 거리·채움이 같은 출발점을 쓴다) |
| N2 | 밀린 거리·채움은 N1 처럼, 바람 세 성분은 면마다 그 면 자리의 바람으로 따로 거슬러 올라간다(거슬러 오르기 4번) |

벽 처리(부풀리기, 경로 따라 멈추기, 이어진 칸만 읽기)는 두 후보 모두 지금 규칙을 그대로 지켜야 한다. 면에서 출발하는 경우의 정확한 규칙은 설계 작업자가 정하되, "읽는 칸이 끝 칸과 이어져 있다"는 성질이 정의로 보장돼야 한다.

## 2. 판정선

새 판정선(물체 없는 장면, 128칸, 초당 60번, "중 값"의 대칭 걷기 입력: 두 발 y = ±12cm·골반 y = 0, 600cm 를 초속 520cm 로, 멈춘 뒤 1.3초)
- D-S1 좌우 치우침: 걸어온 선의 왼쪽 띠와 오른쪽 띠(각 폭 100cm)의 기둥 농도 변화(절댓값 평균)로 |왼쪽 − 오른쪽| ÷ (왼쪽 + 오른쪽) ≤ 0.03.
- D-S2 방향 고르기: +X, −X, +Y, −Y 로 걸었을 때 기둥 농도 변화의 전체 크기(절댓값 평균)가 넷의 평균에서 ±5% 안. 그리고 네 방향 모두 D-S1 을 만족.
- D-S3 대각 걷기(+X+Y 방향, 같은 입력을 45도 돌린 것): 좌우 치우침 ≤ 0.05.

기존 판정선(모두 다시 잰다. 기준과 장면은 등록 문서 `prereg-design.md`·`-2`·`-2b`·`-2c`·`-2d`·`-2e` 그대로)
- 높이 구분 D-V2 ≥ 2.0, D-G12c·D-G12d·T5 의 기준, 낮은 상자 넘어감·높은 상자 막힘, 얇은 벽 76경우·어긋나게 쌓은 벽 76경우·막힌 방 3,840경우의 새는 양(모두 지금 기준), 물체 없는 장면의 결정론(같은 입력 두 번이 같은 해시).
- 기존 판정선 가운데 값이 달라지는 것은 지금 값과 나란히 적는다. 기준을 넘지 못하는 것이 하나라도 있으면 그 후보는 탈락이다.

## 3. 고르는 규칙

N1 → N2 차례로, 2절의 판정선을 모두 만족하는 첫 후보를 고른다. 둘 다 탈락이면 고르지 않고 무엇이 걸렸는지 보고한다(감독이 다음 후보를 덧붙임으로 등록한다). 고른 후보의 비용(칸마다 텍스처 읽기 수, 거슬러 오르기 수)을 지금 방식과 견주어 적는다. 비용은 판정선이 아니라 정보다.

## 4. 지킬 것

잠긴 기준 도구(`Tools/FluidFX/fog3d_ref/` 의 fog3d_core.py 등)와 명세·등록 문서는 고치지 않는다. 새 방식은 새 파일로 만든다. 판정선과 규칙은 결과를 본 뒤 바꾸지 않는다.

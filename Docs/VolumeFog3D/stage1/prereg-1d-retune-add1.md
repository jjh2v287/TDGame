# 1d 뒤 화면 확인 — 덧붙임 1 (첫 촬영 뒤, 다음 촬영 전)

등록: 2026-11-14 claude(감독·결정). 정확한 시각은 이 파일의 수정 시각이다. `prereg-1d-retune.md`(05106c39e54fe324)의 첫 촬영 결과를 본 뒤, 다음 촬영 전에 썼다. 결과를 본 뒤에 쓴 문서임을 판정 기록에 함께 적는다.

## 1. 첫 촬영의 기록 (버리지 않는다)

3인칭 프리셋 값, 옆빛(세계에 고정: 해 높이 35도·방향 100), 뒤 카메라를 걷는 방향에 맞춤.
- 걷기 자국 Wk(12.1): +X 8.24 / −X 4.59 / +Y 1.85 (바꾸기 전 10.63 / 3.92 / 4.00). 평균에서 +69% / −6% / −62% → 등록한 조건(±25%) 불만족.
- 좌우 치우침: +0.128 / −0.231 / −0.080 (바꾸기 전 +0.41 / −0.70 / −0.18) → −X 가 0.15 를 넘어 불만족.
- 휘두르기 Sk2(2.5) 12.2(목표 20~32, 바꾸기 전 26.0).
- 등록한 대로 값을 맞추지 않고 멈췄다.

## 2. 조건이 틀렸다고 보는 까닭

GPU 덤프로 잰 계산 자체는 네 방향의 세기 차가 ±0.00004% 이고 좌우 치우침이 0.00003 이다(1d 통과 기준 E3). 그런데 첫 촬영의 조건은 빛을 세계에 고정한 채 카메라만 걷는 방향으로 돌렸다. 그러면 방향마다 카메라에서 본 해의 방향과 그림자 자리가 달라지고, 안개의 밝기는 해와 시선의 각도에 따라 달라진다. 1c 2회차에서도 같은 방향(+X)에서 빛만 반대쪽으로 돌렸을 때 걷기 자국이 10.63 → 8.12 로 24% 달라졌다. 곧 첫 조건은 "계산의 방향 차"와 "빛·시선의 차"를 함께 쟀다. 내 등록 실수다.

## 3. 고친 확인 (빛을 걷는 방향과 함께 돌린다)

- 걷는 방향 +X·−X·+Y 마다 해의 방향을 100 + 걷는 방향(도)으로 돌려, 카메라에서 본 빛의 방향이 세 실행에서 같게 한다. 그 밖은 첫 촬영과 같다.
- 조건: 세 방향의 Wk(12.1) 가 셋의 평균에서 ±15% 안이고, 세 방향의 좌우 치우침이 서로 0.10 안(가장 큰 값 − 가장 작은 값).
- 치우침의 값 자체는 정보로 적는다(폰의 오른손과 칼이 오른쪽에 있어 폰 기준의 치우침은 남을 수 있다. 기준 모의에서 −0.107).
- 이 조건도 벗어나면 값을 맞추지 않고 멈춰서 보고한다.

## 4. 값 다시 맞추기 (사다리를 넓힌다)

- 걷기: 등록본 그대로(평균 M 이 8~14 가 되게 BodyWindStrength 사다리).
- 휘두르기 Sk2(2.5) 가 20 보다 작으면 BladeRadiusCm 35 → 그래도 작으면 BladeWindStrength 1.5 → 2.0 → 2.5 차례로 올려 처음 20~32 에 드는 값을 쓴다. 32 보다 크면 등록본 그대로(BladeRadiusCm 25). 끝까지 들지 않으면 가장 가까운 값을 쓰고 사실대로 적는다.
- 값을 맞춘 뒤에는 등록본 3절 그대로 기본값에 넣는다. 최종 값으로 세 방향(빛을 함께 돌림)을 한 번 더 찍어 3절의 조건을 다시 확인한다.

# 1d 뒤 — 화면에서 치우침 다시 보기와 3인칭 프리셋 값 다시 맞추기 (등록본)

등록: 2026-11-14 claude(감독·결정). 정확한 시각은 이 파일의 수정 시각이다. 새 옮기기 방식의 GPU 구현이 통과한 뒤, 그 코드로 화면을 찍기 전에 썼다. 숫자는 1c 등록본(`prereg-1c.md`·덧붙임)의 시각표·영역·식 그대로다. 빛은 옆빛, 카메라는 뒤(걷는 방향에 맞춤).

## 1. 무엇을 찍나

3인칭 프리셋(`Tools/FluidFX/fog3d_presets/thirdperson_mid.json` 의 값)을 조절 표 사본으로 넣고, +X·−X·+Y 세 방향으로 걷는 실행을 하나씩 찍는다. 방향마다 걷기 자국 Wk(12.1), 좌우 치우침 (Wk_L − Wk_R) ÷ (Wk_L + Wk_R), 휘두르기 자국 Sk2(2.5)(+X 실행에서), 남는 비 Wk(17.6) ÷ Wk(12.1) 을 잰다.

## 2. 볼 것 (화면에서 고쳐졌는가)

- 세 방향의 Wk(12.1) 가 셋의 평균 M 에서 ±25% 안(바꾸기 전에는 10.6 / 3.9 / 4.0 으로 평균에서 ±70%).
- 방향마다 좌우 치우침의 크기 ≤ 0.15(바꾸기 전 +0.41, −0.70, −0.18).
- 둘 가운데 하나라도 벗어나면 값을 맞추지 않고 멈춰서 보고한다(계산은 대칭인데 화면에서 치우친다면 빛·그림자나 입력 쪽을 다시 봐야 한다).

## 3. 값 다시 맞추기 (사용자가 고른 "중"의 세기에 맞춘다)

- 목표: M 이 8~14(1c 에서 "중"으로 정한 범위), 휘두르기 Sk2(2.5) 가 20~32(사용자가 본 "중"은 26.0).
- M 이 8 보다 작으면 BodyWindStrength 를 2.5 → 3.0 → 3.5 차례로 올려 처음 범위에 드는 값을, 14 보다 크면 1.5 → 1.25 → 1.0 차례로 내려 처음 드는 값을 쓴다. Sk2 가 20 보다 작으면 BladeRadiusCm 35, 32 보다 크면 25 를 한 번 써 본다. 그 밖의 값은 건드리지 않는다. 끝까지 범위에 들지 않으면 가장 가까운 값을 쓰고 사실대로 적는다.
- 정해진 값을 프리셋 파일에 적고, 코드 기본값(헤더)·정본 JSON·기본값을 기대하는 시험·시험 무대의 빛(옆빛)에 넣는다. 그 뒤 빌드, 3D 안개 시험(널 RHI·GPU), 회귀, 쿠킹을 다시 돌린다.

## 4. 사용자에게 보일 것

새 기본값으로(조절 사본 없이) 네 방향 걷기와 휘두르기를 0.1초 간격으로 찍은 움직이는 그림, 그리고 바꾸기 전(같은 값·옛 방식의 1c 2회차 그림)과 나란히 놓은 멈춘 그림.

## 1. 공통 조건 (1차와 다른 점)

1차 공통 조건(칸 가로·세로 15.625cm, 평소 곡선 0.8·두께 90cm·흐림 45cm, 차이값 되돌림 초당 0.3, 시간 간격 1/60초, 윗면 열림·바닥 닫힘, 값을 칸의 면에 둔 엇갈린 격자)을 잇고 아래만 바꾼다.

1. 바람 되돌림: 초당 0.75(지금 2D 값), 곱셈은 exp(−0.75 dt). 1차 민감도 표에서 이 값으로 D-V1·D-V2·D-V3 판정이 1.0 과 같음을 봤다 [이미 봄].
2. 층 배치: U8 = 30cm × 8층. S8 = 아래부터 15·15·15·15·20·30·50·80cm(합 240cm). 기준용 U32 = 7.5cm × 32층. 압력 식·몰림·기울기는 층마다 다른 두께를 그대로 넣는다.
3. 창과 이음매
   - 창의 가장 작은 칸 번호는 축마다 16의 배수다. 대상(플레이어) 칸이 창 가운데 칸에서 어느 축으로든 12칸 넘게 벗어나면, 그 축에서 대상을 가운데로 하는 가장 가까운 16의 배수 위치로 옮긴다.
   - 창 가장자리 면(이음매)은 막힌 면이다. 지나는 바람은 0 이고, 압력 풀이에서 양쪽 칸은 이웃이 아니다.
   - 새로 들어온 띠의 바람·차이값·압력은 0 에서 시작한다.
   - 옮기기에서 뒤로 따라간 자리는 "지금 창과 지난 창이 겹치는 칸들의 가운데점이 이루는 상자" 안으로 자른다(창 밖과 새 띠의 값은 읽지 않는다). 높이는 가장 아래·위 층 가운데 사이로 자른다. 평소 곡선에 넣는 높이는 0 이상으로만 자른다.
   - 가장자리 띠 8칸: 띠 안에서 바람과 차이값에 exp(−4 × (1 − fade) × dt)를 곱한다. fade = smoothstep(0, 8, 가장자리에서 칸 가운데까지의 칸 수).
   - 위치 계산은 모두 "창 기준 정수 칸 번호 + 칸 안 위치"로 한다(세계 좌표를 실수 하나로 들지 않는다).
4. 입력의 표준형: 쓸린 구
   - 입력 하나 = 지난 중심 A, 지금 중심 B, 반지름 r, 속도 V, 바람 세기 s(기본 1), 깎기 비율 E(초당, 기본 0).
   - 캡슐 모양(칼날, 1차의 "길이 1m 캡슐", "세로로 선 캡슐")은 축을 따라 간격이 반지름 이하가 되게 놓은 구 여러 개로 나타낸다. 개수 = 올림(축 길이 ÷ 반지름) + 1, 양 끝 포함. 구마다 자기 A·B·V 를 가진다. 멈춰 있는 입력은 A = B 이고 V 는 따로 준다.
   - 가중치 W(칸 높이 범위에서 평균): 재는 자리에서 선분 AB 위 가장 가까운 점까지의 차를 (ox, oy, oz), a = 1 − (ox² + oy²)/r² 라 한다. a ≤ 0 이면 W = 0. 아니면
     W = (r/dz) × [G(u2) − G(u1)], G(u) = a²u − (2/3)a·u³ + u⁵/5, u1 = max((oz − dz/2)/r, −√a), u2 = min((oz + dz/2)/r, √a), u2 ≤ u1 이면 W = 0.
     dz 는 그 자리의 세로 범위다(칸 가운데와 가로 면은 층 두께, 층 경계 면은 위아래 층 가운데 사이). 층이 얇으면 1차의 (1 − (d/r)²)² 와 같아진다.
   - 바람: 입력 순서대로, 바람 성분이 놓인 자리마다 바람 ← 바람 + (V − 바람) × (s × W).
   - 깎기: 머문 양 D = [dt × (r/|AB|) × (G(q2) − G(q1))] × (W ÷ wc). 대괄호는 붓이 지나가는 동안 점 가중치를 시간으로 더한 값이다. 여기서 a 는 칸 가운데에서 직선 AB 까지의 수직 거리 d⊥ 로 a = 1 − d⊥²/r², q 는 직선 위에서 수직점부터 잰 거리 ÷ r 이고 선분 양 끝과 ±√a 로 자른다. wc 는 가장 가까운 점에서의 점 가중치 (1 − (d/r)²)². |AB| < 0.01cm 이면 대괄호 = dt × wc. wc < 1e-6 이면 D = 0.
     전체 농도에 exp(−E × D)를 곱한다. 여러 입력의 D 는 더한다.
5. 한 번 계산의 순서: 창 이동 처리 → 옮기기(+되돌림, 가장자리 띠) → 입력(바람, 깎기) → 막힌 면 바람 0 → 몰림 → 압력(지난 압력에서 이어 풀기) → 기울기 빼기 → 출력.
6. 차이값 옮기기 식(2판). 뒤로 따라간 자리를 x′, 그 높이를 h′, 도착 칸 높이를 h 라 한다.
   - 읽은 전체 농도 ρ̃ = max(0, 보간한 차이값(x′) + B̄(x′)). B̄ 는 평소 곡선을 "x′ 를 끼고 있는 위아래 두 층 가운데에서 계산해 높이로 선형 보간"한 값이다. 차이값도 위아래 두 층을 각각 가로로 보간해 읽은 뒤 같은 높이 비율로 직접 섞는다(두 보간의 비율이 정확히 같아야 빈 곳이 0 으로 남는다).
   - 어긋남 e = B(h′) − B̄(x′). 채움 비율 φ = B̄ > 1e-6 이면 min(1, ρ̃ ÷ B̄), 아니면 0.
   - 새 전체 농도 = max(0, ρ̃ + φ × e). 새 차이값 = (새 전체 농도 − B(h)) × exp(−0.3 dt).
   - 뜻: 안개가 평소만큼 있는 곳에서는 1차 식(평소 곡선을 식 그대로 옮김)과 같고, 빈 곳에서는 "전체 농도를 칸 값으로 옮기기"와 같아 없는 안개가 생기지 않는다. 고르게 일부만 깎인 곳(평소의 f 배)은 정확히 f 배로 옮겨진다. 1차 식(1판)은 비교용으로만 돌린다.
   - 차이값을 −평소 이상으로 자르던 단계는 없앤다(위 식이 0 이상을 지킨다).
7. 그림과 층 배치 비교에서 "그려지는 농도" = 평소 곡선(식, 그 높이에서 바로 계산) + 차이값(층 가운데 사이를 높이로 선형 보간, 양 끝은 끝값). 재질이 그리는 방식과 같다.
8. "정밀 기준 구성" = 옮기기 A3, 막힌 칸 처리 S4, 압력은 매번 R ≤ 0.001 까지 푼 것. 고르기 실험은 고르는 축만 바꾸고 나머지는 정밀 기준으로 둔다.
9. 격자: 고르기 실험은 128×128(창 20m). 최종 확인에서 고른 압력 풀이의 R 은 256×256 으로도 잰다.

## 2. 고르는 규칙

### R2-L 층 배치 (U8 대 S8)

- 장면 4개(정밀 기준 구성): L1 내려찍기(D-V1 입력, 0.5초 시점) / L2 낮게 휘두르기(D-V2 낮음, 0.3초) / L3 높게 휘두르기(D-V2 높음, 0.3초) / L4 낮게 휘두르기 + 깎기 초당 30(0.3초).
- 장면마다 U8·S8·U32 로 계산한다. 비교 영역: 입력 경로 가운데점에서 가로·세로 ±3m, 높이 0~150cm 안의 U32 칸 가운데점들.
- 오차 E = 그 점들에서 [그 배치의 차이값을 1절 7 방식으로 보간한 값 − U32 의 차이값]의 제곱 평균 제곱근.
- 규칙: E(U8) ≥ 1e-4 인 장면만 센다. 센 장면이 3개 이상이고, 그중 3개 이상에서 E(S8) ≤ 0.75 × E(U8) 이며, 센 장면 전부에서 E(S8) ≤ 1.10 × E(U8) 이면 S8. 아니면 U8.
- 추가 조건: S8 의 압력 후보가 R2-P 의 P1~P5 안에서 통과해야 한다. 아니면 U8.
- 4절 최종 확인에서 S8 구성이 "U8 구성은 통과하는 판정선"을 못 넘으면 U8 로 돌아간다.

### R2-S 막힌 칸 처리 (옮기기가 벽 속 값을 읽는 문제)

후보(값싼 순)
- S0 없음
- S1 자르기: 칸 가운데에서 뒤로 따라갈 때, 자기 칸의 막힌 면 쪽으로는 그 축의 이동을 0 으로 한다
- S2 채워 두기: 막힌 칸의 차이값 자리에 "유체인 면 이웃들의 차이값 평균"을 적어 둔다(유체 이웃이 없으면 면 이웃 6칸에 적힌 값의 평균, 창 밖 이웃은 뺀다). 정지 상태에서는 0 이다
- S3 = S1 + S2
- S4 가중치 다시 나누기: 8칸을 따로 읽어 막힌 칸 몫을 빼고 나머지로 나눈다(기준용)

시험 LEAK: 높은 상자(가로·세로 150cm, 높이 180cm). 압력 풀이는 끈다. 바람은 매번 정해 준 값으로 덮어쓴다(모든 열린 면에 같은 벡터, 막힌 면은 0). 매 계산 직전 모든 유체 칸을 비운다(차이값 = −평소). 한 번 계산 뒤 "다시 찬 비율"(= (차이값 + 평소) ÷ 평소)을 잰다. 재는 칸: 바람이 상자에서 멀어지는 쪽 면에서 3칸 이내, 면의 양 끝 2칸 제외, 평소 농도 ≥ 0.1 인 칸. 20~30번째 계산의 평균. 설계값 = 1 − exp(−0.3 dt).
- 경우: 면에 수직인 바람 50·300·1000 cm/s / 면에 45° 인 300 cm/s / 낮은 상자(높이 30cm) 윗면에서 위로 100 cm/s(윗면 위 3칸 이내).
- 규칙: 옮기기 방식 A1·A2·A3 마다, 모든 경우에서 "잰 값 ÷ 설계값 ≤ 1.15" 인 가장 값싼 후보(S0 → S4 순). 최종은 R2-A 가 고른 옮기기 방식의 것.
- [이미 봄: 1판 식, 면 바로 옆 칸만 잰 값으로 S0 은 A3 에서 2.3배, A1 에서 1.13배.]

### R2-A 옮기기 방식

후보(값싼 순)
- A1 한 번 읽기: 자기 텍셀의 면 값 셋을 칸 가운데 바람처럼 써서 뒤로 따라가고, 바람과 차이값을 한 번에 읽는다
- A2 차이값만 제자리: 바람은 A1 처럼 읽고, 차이값은 칸 가운데 바람(마주 보는 두 면의 평균)으로 따로 따라가 읽는다
- A3 성분별: 바람 성분마다 자기 면 자리에서, 차이값은 칸 가운데에서 따라간다

규칙(층 배치마다): 아래를 모두 통과하는 가장 값싼 후보(A1 → A3 순). 나머지 축은 정밀 기준 구성.
- D-V1(조건 3개), D-V2(조건 2개, 시간 간격 1/60초), D-G2, D-G4(1/30·1/60·1/144), D-G6 — 판정선은 1차 문서 그대로, 공통 조건은 이 문서 1절.
- 아무도 D-V2 를 못 넘으면 A3 을 고르고 D-V2 실패로 적는다.
- 정보: D-V2 비율을 1/30·1/144 에서도 잰다. 1초 뒤 바람·차이값 장이 A3 과 얼마나 다른지 적는다.
- [이미 봄: 1차(U8, 1판 식, 16점 입력)에서 A1 은 D-V2 1.65 로 실패, A3 은 2.16 으로 통과. A2 는 본 적 없다.]

### R2-P 압력 풀이

후보(단순한 순)
- P1·P2·P3: 세로 줄 풀기(가로 바둑판 2색으로 번갈아, 제자리 갱신, 가속 계수 ω). 한 번 계산에 전체 훑기 4·8·12번.
- P4: 격자 2단계(가로·세로만 2배 거칠게, 거친 식은 막힘 표시로 다시 만듦), 비용 8 이하.
- P5: 격자 3단계, 비용 8 이하.
- P6: 격자 5단계 V(1,1), 비용 12 이하(1차의 차선).
- (P7: 1차가 고른 갤러킨 방식. P1~P6 이 모두 실패할 때만, U8 에서만.)
- ω 와 P4~P6 의 순환 꼴은 판정에 쓰지 않는 입력 T0(1차와 같음)로 정하고, 판정 실행 전에 고정해 적는다. 비용 단위는 1차와 같다.

통과 조건(모두)
- (a) 처음 풀기 R ≤ 0.25: T1·T2·T3(1차와 같음) + T4(T1 을 서쪽 이음매에서 4칸 안쪽에 두고 이음매 쪽으로 붊) + T5(T2 를 창 모서리에서 두 축 모두 4칸 안쪽에 둠) 중 가장 나쁜 값. 공통 자, 압력 0 에서 시작.
- (b) 모양 충실도: 이 후보로 돌린 계산(이어 풀기 켬)의 아래 값이 정밀 기준 구성의 값과 이만큼 안에 든다.
  - 상대 5%: D-V1 고리 바깥 바람, D-V1 둘레 차이값 합, D-V2 차이값 비율, D-V3 F(자유)
  - 절대 0.02: D-V1 기둥 농도 저하 비율, D-V3 의 F(낮음)÷F(자유), F(높음)÷F(자유), S(높음)÷S(자유)
  - 절대 5cm: D-V2 바람 높이 중심 차
- (c) D-G7(이음매 누수) 통과.
- (d) D-G4(안정성) 통과.

규칙(층 배치마다): P1 → P6 순으로 처음 통과하는 후보. 고른 후보와 그다음 후보 하나는 반드시 재서 적는다. P1~P6 이 모두 실패하면 U8 은 P7, S8 은 R2-L 의 추가 조건에 따라 탈락.
후보마다 적을 것: T1~T5 의 처음 풀기 R, 입력이 초속 3m 로 60번 움직일 때 마지막 10번 평균 R, 움직이다 멈춘 첫 계산의 R, 비용 단위, 한 번 계산의 패스 수.

## 3. 새 결함 판정선

고른 최종 구성으로 잰다. 따로 적지 않으면 128×128, 1/60초.

- **D-G7 이음매 누수**: T1 입력(구 반지름 50cm, 초속 5m)을 서쪽 이음매에서 4칸 안쪽에 두고 이음매 쪽으로 3번 넣은 뒤 1초 더 계산한다. ① 3번째 입력 직후 동쪽 이음매 옆 8칸 띠의 바람 최댓값 ÷ 입력 근처 바람 최댓값 ≤ 1e-4. ② 1초 뒤 같은 띠의 차이값 절댓값 최대 ≤ 1e-6, 바람 최대 ≤ 처음 입력 근처 최댓값의 1e-4. 모서리(두 이음매에서 4칸)에 둔 경우에는 나머지 세 모서리의 8×8칸에서 같은 조건. [이미 봄: 감긴 풀이에서는 ①이 0.20, ②가 0.021 과 2.9 cm/s.]
- **D-G8 깎기가 시간 간격에 무관**: 구 반지름 20cm, 높이 45cm, 바람 세기 0, 되돌림 끔, 깎기 초당 30. (가) 초속 1m 로 1초 (나) 초속 8m 로 0.25초 (다) 제자리 0.5초. 끝난 뒤 없어진 양(−차이값 × 칸 부피의 합)이 1/30초·1/144초에서 각각 1/60초 값의 ±5% 이내.
- **D-G9 달리기 창 이동**: 구 입력(반지름 40cm, 높이 60cm, 바람 세기 1, 깎기 초당 30)이 +x 로 초속 6m 로 5초 달린다. (가) 128×128 창이 1절 3 규칙으로 따라감 (나) 길 전체를 덮는 512×128 고정 창. 끝 시점에 (가)의 마지막 창에서 가장자리 16칸을 뺀 영역에서 ① 차이값 차의 최댓값 ≤ (나) 차이값 절댓값 최대의 5% ② 바람 차의 최댓값 ≤ (나) 바람 최댓값의 5%. ③ (가)의 앞쪽 가장자리 16칸 띠(가장 늦게 들어온 띠)에서 차이값 절댓값 최대 ≤ (가) 전체 차이값 절댓값 최대의 1%(뒤쪽에서 나간 자국이 앞에 다시 나타나지 않는다).
- **D-G10 붓 높이 연속성**(U8·S8 모두): 멈춘 구(반지름 20cm, 가로 초속 3m)를 높이 30cm 부터 200cm 까지 5cm 간격으로 놓고 정지 상태에 한 번 넣는다(압력 끔). 들어간 양 P = Σ(바람 × 그 자리 부피). ① 모든 높이에서 P 가 높이 평균값의 ±10% 이내(높이에 따라 출렁이지 않는다). ② 높이 평균값이 식의 값(V × 32π r³ ÷ 105)의 ±15% 이내(가로는 칸 간격으로 점을 찍으므로 여유를 둔다).
- **D-G11 먼 좌표**: D-V2 낮게 휘두르기를 창 원점을 가로·세로 +100만 칸(약 156km), 그리고 −100만 칸 옮긴 자리에서 계산한다. 입력 위치는 창 기준 값으로 주고 원점 이동은 정수 칸 번호에만 더한다. 0.3초 뒤 상태 해시(창 순서로 편 값)가 원점 0 에서 계산한 것과 같다.
- **D-G12 빈 곳과 평소 곡선** (압력 끔, 정해 준 바람 = 모든 칸에서 위아래 100 × sin(2π t ÷ 0.25초) cm/s, 0.5초 동안)
  - a 빈 곳 유지: 처음에 모든 칸을 비우고(차이값 = −평소) 되돌림을 끈다. 끝난 뒤 전체 농도 최댓값 ≤ 1e-6.
  - c 왕복 뒤 제자리: 정지 상태에서 시작, 되돌림 끔. 한 주기(0.25초)와 두 주기 뒤 차이값 절댓값 최대 ≤ 0.04.
  - b 내려찍기 뒤 빈 곳(압력 켬): 반지름 1m 기둥을 비워 두고(되돌림 켬) D-V1 입력을 기둥 축으로 내려찍는다. 0.5초 시점에 축에서 반지름 50cm 이내·높이 90cm 아래 칸의 전체 농도 합 ÷ 평소 농도 합 ≤ 0.139 × 1.25.
  - 1판 식도 같은 시험으로 재서 정보로 적는다.

## 4. 최종 확인과 올림 규칙

1. 최종 구성 = R2-L 이 고른 층 배치 + 그 배치에서 R2-A·R2-S·R2-P 가 고른 것.
2. 최종 구성으로 1차 판정선 전부(D-G2·D-G3·D-G4·D-G5a·D-G5b·D-G6·D-V1·D-V2·D-V3)와 3절의 새 판정선 전부를 다시 잰다. D-G5 의 "창을 따라가게 한 쪽"은 1절 3 의 창 규칙을 쓴다(1차와 다른 점으로 적는다).
3. D-V3 는 ①(낮은 상자 넘어감)·②(높은 상자 막힘)가 통과해야 한다. ③(돌아 흐름)은 값만 적는다(1차에서 실패. 원인 미확정).
4. 최종 구성이 어떤 판정선을 못 넘는데 정밀 기준 구성은 넘으면, 값싼 축부터 한 칸씩 올려 다시 잰다: 압력 한 단계 → 옮기기 한 단계 → 막힌 칸 처리 한 단계. 최대 3번. 올린 내용을 적는다.
5. 정밀 기준 구성도 못 넘는 판정선은 식의 결함이다. 원인과 함께 적고 감독이 다룬다(판정선은 그대로).

## 5. 정보로만 적는 것 (통과·실패 없음)

- I3 넓은 바람: 높은 상자 앞 1.5m 에 폭 4.5m(상자 폭의 3배)로 세운 바람 입력(초속 4m, 2초). 상자 옆 가운데 면과 뒷면 뒤 2칸 면에서 S(높음) ÷ S(자유). 기대: 바람이 상자보다 넓으면 1.0 이상.

- I5 시간 간격 1/20초와 1/10초에서 D-G4.
- I6 교란 뒤 정지로 돌아가는 시간(바람 최댓값이 0 이 되는 계산 횟수), 16비트 저장을 흉내 냈을 때의 같은 값.

## 1. 깎기 정의 (prereg-design-2.md 1절 4 의 "깎기" 줄을 대신한다)

- 붓이 한 번 계산 동안 A → B 로 움직인다. 붓 중심 c(t) = A + t(B − A), t 는 0~1.
- 칸 가운데의 가로 위치에서 c(t) 까지의 가로 거리가 반지름보다 작은 t 구간을 [t1, t2]라 한다(가로 평면에서 2차식을 풀고 0~1 로 자른다). 가로 이동이 0.01cm 보다 작으면, 가로 거리가 반지름 안일 때 [0, 1], 아니면 구간 없음.
- 머문 양 D = dt × (t2 − t1) × Σ(q=1..3) ω_q × W(c(t_q)). t_q 와 ω_q 는 구간 [t1, t2] 위의 3점 가우스-르장드르 적분점과 무게(무게 합 1). W(c) 는 붓 중심이 c 에 있을 때 그 칸의 "높이 범위에서 평균한 가중치"(prereg-design-2.md 1절 4 의 W 식, 가장 가까운 점 대신 c 를 쓴다).
- A 와 B 가 0.01cm 안이면 D = dt × W(A).
- 전체 농도에 exp(−E × D)를 곱한다. 여러 입력의 E × D 는 더한다. 바람 섞기 뒤에 한 번 한다.
- 뜻: "붓이 그 칸 위에 머문 시간 × 붓이 그 칸 높이와 겹친 정도". 칸 가운데가 붓 밖이어도 높이가 겹치면 깎인다.

## 2. 식 3판: 밀린 거리와 채움 비율 (prereg-design-2.md 1절 6 의 후보)

칸 가운데에 두 가지를 둔다.
- 밀린 거리 d = (dx, dy, dz) cm: 지금 이 자리의 공기가 원래 있던 자리 X = 지금 자리 − d.
- 채움 비율 차 g: 전체 농도 = (1 + g) × 평소 안개(X). 깎으면 g 가 −1 쪽으로 간다.
- 정지 상태는 d = 0, g = 0 이고 계산을 돌려도 정확히 0 으로 남는다.

그려지는 농도(재질과 판정 지표가 쓰는 값): ρ(x) = max(0, 1 + g̃) × B(x − d̃). g̃·d̃ 는 칸 가운데 값을 선형 보간한 것(가로는 칸 사이, 높이는 층 가운데 사이, 양 끝은 끝값). B 에 넣는 높이는 0 이상으로 자른다. 얼룩이 있으면 B 의 가로 위치에도 X 를 넣는다. 계산 쪽은 평소 곡선을 쓰지 않는다.

한 번 계산
- 옮기기: 칸 가운데에서 뒤로 따라가 자른 자리를 x_s 라 하면(자르기와 막힌 칸 처리 S0~S4 는 prereg-design-2.md 그대로, 대상만 d·g 로 바뀐다)
  d_새(x) = [d(x_s) + (x − x_s)] × (가로 성분은 exp(−0.1 dt), 높이 성분은 exp(−0.3 dt)), g_새(x) = g(x_s) × exp(−0.3 dt).
  (위아래로 밀린 것은 초당 0.3 으로 제자리에 돌아오고, 가로로 밀린 것은 초당 0.1 로 천천히 돌아온다. 깎인 것은 초당 0.3 으로 다시 찬다.)
- 옮기기 방식 A1·A2·A3 의 뜻: A1 = d·g 를 바람과 같은 자리(자기 텍셀의 면 값으로 따라간 자리)에서 읽는다 / A2 = d·g 는 칸 가운데 바람으로 따로 따라가 읽는다 / A3 = 바람도 성분별.
- 깎기: g ← (1 + g) × exp(−Σ E × D) − 1.
- 가장자리 띠 감쇠는 d·g 에도 곱한다. 새 띠와 막힌 칸은 d = g = 0(S2 는 읽기용 사본에 이웃 평균을 적는다).
- 바람 없는 판: d 는 0 그대로, g 만 깎고 되돌린다.
- 판정선의 "차이값" = 칸 가운데에서 [그려지는 농도 − 평소 농도] = max(0, 1 + g) × B(칸 가운데 − d) − B(칸 가운데). 1차·2차 판정선의 지표는 이 값으로 그대로 잰다.
- 판정선 문구의 "비운다"(D-G6·D-G12·누수 시험) = g = −1(d 는 0). "되돌림 끔" = d·g 의 되돌림과 가장자리 띠 감쇠를 모두 끔.
- R2-L 의 오차 E: U32 칸 가운데점들에서 [그 층 배치의 d·g 를 위 방식으로 보간해 그린 농도 − U32 가 자기 칸 값으로 그린 농도]의 제곱 평균 제곱근. 2판이 뽑히면 prereg-design-2.md 의 정의 그대로.

- 2판으로 새 깎기 정의의 영향을 받는 것(D-G8, D-G9, D-G13)과 D-G12 d 를 다시 잰다. 나머지는 [이미 봄] 값을 쓴다.
- 3판이 모두 통과하면 3판.
- 3판이 실패한 판정선이 있고 2판이 그 판정선을 통과하면 2판.
- 3판이 실패한 판정선을 2판도 모두 실패하면 3판(둘 다 실패한 판정선은 식의 결함으로 적는다).

## 4. 새 판정선

- **D-G12 d 되돌리는 소용돌이** (압력 끔, 되돌림·가장자리 띠 끔, 정지에서 시작): 정해 준 바람 u = +U × sin(πx/240) × cos(πz/240), w = −U × cos(πx/240) × sin(πz/240) (x 는 창 가운데 기준 가로 cm, z 는 높이 cm, y 방향 바람 0, U = 100 cm/s. 몰림이 0 이고 바닥과 240cm 높이에서 위아래 바람이 0 인 맴돌이다). 앞 0.25초는 이 바람, 뒤 0.25초는 부호를 뒤집은 바람. 끝난 뒤(공기가 제자리로 돌아온 뒤) 차이값 절댓값 최대 ≤ 0.04. 가운데 시점(0.25초)의 차이값 절댓값 최대는 정보로 적는다(0.05 보다 작으면 신호가 약한 것이므로 판정 불가로 적는다).
- **D-G13 깎기의 높이 연속성**(U8·S8): 구 반지름 20cm 를 높이 30cm 부터 200cm 까지 5cm 간격으로 놓고 한 번 계산(1/60초)의 머문 양을 잰다. (가) 멈춘 구 (나) 가로로 초속 8m 로 움직이는 구. Q = Σ(머문 양 × 칸 부피). ① 모든 높이에서 Q 가 높이 평균의 ±10% 이내 ② 높이 평균이 dt × 32π r³ ÷ 105 의 ±15% 이내. (가)·(나) 모두.
- D-G8(깎기가 시간 간격에 무관)은 정의 그대로, 새 깎기 정의로 다시 잰다.

# 1단계 설계 판정선 2차 덧붙임 2 — 얇은 벽과 "길 따라 자르기" (실험 전 등록)

등록: 2026-11-13 claude(감독·결정). 2차 실험 묶음(K2·EA·EB·EE·K3)과 독립 반박(V3·V4)을 읽은 뒤, 이 덧붙임의 실험을 돌리기 전에 썼다. 앞 문서 셋(`prereg-design.md` 84c1f178cad78ebb, `prereg-design-2.md` 3a0ddd47b0f5b729, `prereg-design-2b.md` 25f6ea62b87734de)은 고치지 않는다. 결과를 본 뒤에는 이 문서도 고치지 않는다. 이미 본 숫자는 [이미 봄]으로 적는다.

## 0. 왜 덧붙이나

- 반박(V3)이 찾은 것 [이미 봄]: 규칙 R2-S 가 고른 막힌 칸 처리 S3(자기 칸 자르기 + 채워 두기)은 두꺼운 상자에서만 새지 않는다. "왼쪽 가득·오른쪽 비움, 바람 덮어쓰기"에서 다시 찬 비율 ÷ 설계값이 한 칸 두께 벽은 초속 10m 에서 3.22, 초속 20m 에서 43.1, 두 칸 벽은 초속 20m 에서 9.87 이다. 칸보다 얇은 물체(두께 10cm 판)는 막힌 칸이 0개라 아예 사라진다.
- 원인: S1 은 자기 칸의 닫힌 면만 본다. 한 번에 한 칸 넘게 뒤로 따라가는 칸은 벽 칸(양쪽 이웃 평균이 적혀 있음)이나 벽 너머를 읽는다. 시간 간격이 길면(초당 30번이면 이동이 두 배) 더 샌다.
- 결정: 두께·빠르기·시간 간격에 기대지 않고 구조로 막는다. (1) 얇은 물체는 굽기 전에 한 칸 두께로 부풀린다. (2) 뒤로 따라가는 길을 칸 단위로 따라가며 닫힌 면을 넘지 못하게 한다.
- 규칙 R2-S 의 결과(S3)는 기록으로 남는다. 이 덧붙임은 새 요구(얇은 벽)에 대한 새 후보와 새 판정선이다. 식(3판)·층 배치(U8)·옮기기(A1)·압력(P2)은 바꾸지 않는다.

## 1. 정의

### 1.1 얇은 물체 부풀리기(굽기 규칙)

- 상자: 국소 축 a(단위 벡터)마다 반두께 ← max(원래 반두께, m_a), m_a = 7.9cm + 7.2cm × |a·위|. 가로 축은 7.9cm(반 칸 + 0.0875cm), 세로 축은 15.1cm(U8 반 층 + 0.1cm).
- 구: 반지름 ← max(원래 반지름, 18.7cm)(칸 대각선의 절반).
- 그 뒤는 지금과 같다: 칸 가운데가 (부풀린) 물체 안이면 막힘(열린 부등호). 면 표시도 지금과 같다(막힌 칸에 닿은 면, 이음매, 바닥은 닫힘. 윗면은 열림).
- 기준 모의에 "세로 축 둘레로 돌린 상자"(가운데, 반두께 셋, 도는 각)를 더한다.

### 1.2 길 따라 자르기

칸 c0 의 가운데 x0 에서 이동 δ = −V·dt 로 뒤로 따라갈 때(A1: V 는 자기 텍셀의 면 값 셋)

1. 이동 상한: δ 에 min(1, 125cm/|δx|, 125cm/|δy|, 120cm/|δz|)를 곱한다(방향은 그대로, 가로 8칸·높이 120cm 까지).
2. 지금 있는 자르기를 그대로 적용해 목표 x1 을 얻는다(가로는 지금 창과 지난 창이 겹치는 칸 가운데들의 상자, 높이는 가장 아래·위 층 가운데 사이).
3. 지금 칸 c = c0. 축마다 "묶임 = 아니오", 끝 좌표 e = x1.
4. 되풀이(최대 24번)
   - 묶이지 않은 축 a 가운데 이동 방향(x1_a − x0_a 의 부호, 0 이면 건너뜀)으로 칸 c 의 면이 닫혀 있는 축: e_a 를 "그 방향으로 칸 c 의 가운데를 넘지 않는 값"으로 자르고(x1_a 가 가운데를 넘었으면 가운데, 아니면 x1_a) 그 축을 묶는다.
   - 묶이지 않은 축 가운데, 선분 x0 → x1 이 칸 c 의 다음 경계를 가장 먼저 넘는 축 b 를 찾는다(선분 위 매개변수 t ≤ 1 인 것만. 같으면 x, y, z 순). 없으면 끝낸다.
   - c 를 축 b 방향으로 한 칸 옮긴다.
5. 표본 자리 = e. 바람과 밀린 거리·채움 비율을 이 자리에서 읽는다(지금과 같은 8칸 읽기).

- 뜻: 표본 자리는 닫힌 면에 붙은 칸의 가운데를 그 면 쪽으로 넘지 못한다. 그래서 8칸 읽기에 "면으로 맞닿은 막힌 칸"이 섞이지 않는다. 자기 칸에서는 S1 과 같은 결과다. 벽을 따라 미끄러지는 이동은 남는다.
- 물체가 없는 장면에서는 2번의 자르기가 이미 바닥·이음매 칸의 가운데 안쪽이므로 결과가 S3 과 같아야 한다(3절 1 에서 확인).

### 1.3 후보(값싼 순)

- S5: 길 따라 자르기만(막힌 칸의 값은 0)
- S6: 길 따라 자르기 + 채워 두기(S2: 막힌 칸에 유체 면 이웃 평균, 2단계 포함)
- S7: 길 따라 자르기 + 가중치 다시 나누기(S4, K3 가 고친 판: 8칸이 모두 막혔으면 자기 칸 값)
- (S3: 지금 것. 비교용 정보로만 돌린다)

## 2. 새 판정선 D-G14 얇은 벽

공통: 식 3판·U8·A1, 압력 끔, 128×128, 가장자리 띠 켬. 바람은 매 계산 정해 준 벡터로 덮어쓴다(모든 열린 면에 같은 벡터, 닫힌 면 0). 매 계산 직전에 "바람이 불어오는 쪽" 유체 칸은 정지(d = 0, g = 0), "바람이 가는 쪽" 유체 칸은 비움(d = 0, g = −1)으로 둔다. 한 번 계산한 뒤 재는 칸의 채움(1 + g) 최댓값 ÷ 설계값(1 − exp(−0.3 dt))을 적는다. 창 가장자리에서 16칸 안쪽만 잰다. **기준: 모든 경우에서 ≤ 1.15.**

### 규칙 R3-S

S5 → S6 → S7 순으로, 아래를 모두 통과하는 첫 후보를 최종 막힌 칸 처리로 쓴다.
- (i) R2-S 의 누수 시험 5경우(등록된 정의 그대로, ≤ 1.15)
- (ii) D-G14 가·다·라·마의 모든 경우

아무도 통과하지 못하면 가장 적게 실패한 후보와 실패 내용을 적고 감독이 다룬다(기준은 그대로).

## 3. 최종 확인

고른 후보로 바꾼 최종 구성(3판·U8·A1·고른 후보·P2)에서

1. 물체가 없는 장면의 상태 해시가 같은 코드로 돌린 S3 구성과 같은지 본다: D-V1(0.5초), D-V2 낮음·높음(0.3초), D-G12 d(끝), D-G9 가(끝). 모두 같으면 물체 없는 판정선은 K3 의 값을 그대로 쓴다. 하나라도 다르면 2차 4절 2 의 판정선 전부를 다시 잰다.
2. 물체가 있는 판정선을 다시 잰다: D-G3, D-V3 ①·②(③ 은 값만), R2-S 누수 5경우. 정보로 I3.
3. 못 넘는 판정선이 있으면 올림 없이 적고 감독이 다룬다.

## 4. 정보로만 적는 것

- 가에서 S3 의 값(고치기 전 모습).
- 얇은 벽의 끝(길이 2m 판, 끝에서 3칸 이내)과 한 칸 기둥 뒤의 값. 안개가 돌아 흐르는 자리라 판정하지 않는다.

# 명세 덧붙임 1d — 바람 옮기기 N2

## 1. 3.3 한 번 계산의 순서 — 바뀌는 것

순서(옮기기 → 입력 → 닫힌 면 0 → 압력 → 정리)와 패스 수는 그대로다. 바뀌는 것은 "옮기기" 단계의 내용 하나다: 지금까지는 칸 가운데에서 길 하나를 잡아 바람 세 성분과 d·g 를 같은 표본에서 읽었다. 이제는 길이 칸마다 넷이다(가운데 1 + 면 3).

## 2. 3.6 옮기기와 벽 — 대체하는 줄

- **3.6-1 대체**: 칸 가운데 바람 V_c = (양쪽 x 면 평균, 양쪽 y 면 평균, 위아래 면 평균). 창 아래 끝 면·바닥 면은 0. d·g 의 이동 δ = −V_c × dt.
- **3.6-2~4**: d·g 의 길은 그대로(출발점 칸 가운데).
- **3.6-5 의 "바람 세 성분" 줄 대체**: 바람 성분 a(x, y, z)마다 자기 칸의 +a 면 가운데에서 따로 거슬러 올라간다.
  1. 면 자리 바람 V_f = 면 자리를 겹침 상자(칸 가운데점 상자, 높이 15~225cm)로 자른 점에서의 엇갈린 격자 3선형 보간. 보통 칸에서 자기 성분 = 그 면 값, 다른 두 성분 = 둘레 면 4개 평균. 상자에 잘리는 면(가로 겹침 상한 칸의 +면, 맨 위 층의 윗면)은 자른 자리 값: 맨 위 층 윗면의 w = ½(w₆ + w₇), u·v = 같은 층 두 값의 평균.
  2. 이동 = 3.6-2 의 상한을 곱한 −V_f × dt, 목표 = 3.6-3 의 상자로 자름(원점은 면 가운데).
  3. 시작 칸: 목표의 a 성분 > 0 이면 면 너머 칸, 아니면 자기 칸. 길 따라 멈추기는 3.6-4 그대로(원점 = 면 가운데).
  4. 끝 자리에서 그 성분의 면 격자 8마디를 읽는다. 면 축 기준 마디 상한은 가로 N − 1, 높이 7(칸 격자의 N − 2·6 이 아니다). 면 이어짐: 마디의 두 칸 가운데 표본의 칸 묶음 안에 드는 칸이 면 길의 끝 칸과 3.6-5 ①~④ 로 이어지지 않으면 그 마디는 0. 다시 나누지 않는다. 섞기는 높이 → 세로 → 가로 "a(1−t)+b·t".
- **3.6-5 의 "d·g" 줄**: 그대로(가운데 길의 표본과 끝 칸).
- 3.6 아래 "5 의 이어짐의 뜻" 문단의 "읽는 칸은 늘 끝 칸과 열린 면으로 이어져 있다"는 면 읽기에도 성립한다(면 이어짐 규칙이 정의로 보장한다). 그 규칙이 결과를 바꾸는 경우는 드물지만 있다(`impl-1d-contract.md` 3절의 반례).

## 3. 5절 품질 단계

옮기기 패스의 비용이 커진다(칸마다 길 1 → 4, 정적 텍스처 읽기 약 32 → 101). 5절의 시간 어림은 1d 의 실측(E7)으로 다시 정한다.

## 4. 한계 (두 줄)

- 축 네 방향의 좌우 치우침은 사라지지만(0.205 → 0.00003) 비스듬한 방향(11.25°·22.5°)에 약 5% 치우침이 남고, 대각으로 걸을 때 자국이 네 방향보다 약 35% 약하다(더 줄이려면 옮기기 보간 차수를 올려야 한다).
- 면 이어짐 규칙이 결과를 바꾸는 것은 면 축으로 한 계산에 5칸 넘게 가는 바람과 특정한 막힌 칸 꼴이 겹칠 때뿐이라, 장 차이 판정으로는 보이지 않고 전용 장면의 국소 판정으로만 확인된다.

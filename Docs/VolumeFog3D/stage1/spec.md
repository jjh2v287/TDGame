## 0. 한 장 요약

- 만드는 것: 안개 구역 안에서 플레이어 주변 40m 를 따라다니는 얇은 3D 격자(가로 256 × 세로 256 × 높이 8층)에 "바람 3방향", "공기가 밀린 거리", "깎인 정도"를 계산해 엔진 볼륨 안개에 3D 텍스처로 얹는다.
- 안개 농도는 저장하지 않는다. 평소 안개는 그리는 쪽이 식으로 그린다. 계산은 "이 자리의 공기가 원래 어디 있었나(밀린 거리 d)"와 "얼마나 깎였나(채움 비율 차 g)"만 옮긴다. 건드리지 않은 곳은 값이 정확히 0 이다.
- 사다리 중간 칸(차이만 → 성긴 바람 → 완전판)은 건너뛰고 완전판으로 간다. "바람 없는 판"을 스위치로 남겨 같은 장면에서 비교한다.
- 검증(사용자 지시 2026-10-25): 기능을 먼저 만들고 칸마다 빌드·회귀·결정론·오프스크린만 본다. 화면 판정과 값 보정은 1c 에서 한꺼번에 한다.

## 1. 목표와 범위

목표 장면: 안개 시험 무대의 3D 안개 구역에서 3인칭 카메라로, 플레이어가 걷고 칼을 휘두를 때
1. 높게 휘두르기와 낮게 휘두르기가 다르게 보이고,
2. 내려찍으면 구멍이 뚫리며 둘레로 밀려나고,
3. 낮은 상자는 안개가 넘어가고 높은 상자와 얇은 벽 앞에서는 막히며,
4. 건드린 자리가 몇 초에 걸쳐 다시 차오른다.

미리 적어 두는 기대치(범위를 늘려 고치지 않는다)
- 장면 1: 차이는 처음 0.3초쯤에 가장 뚜렷하다. 1초 뒤에는 높게 휘두른 바람도 내려와 안개 윗면을 약 25cm 누른다.
- 장면 3: 높은 상자 뒤는 고요하다(상자 뒤 흐름 ÷ 상자 없을 때 = 0.04). 낮은 상자는 넘어간다(0.88). 상자를 감아 돌아 뒤로 들어오는 흐름은 약하다(좁은 바람 0.39, 상자보다 넓은 바람 0.85~0.97, 기대 1.0 에 못 미침).

| 1단계에서 하는 것 | 뒤로 미루는 것 |
|---|---|
| 새 3D 계산(바람 3방향, 밀린 거리·채움, 압력 풀이) | 깨어 있는 덩어리만 계산, 작은 값을 0 으로 내려 잠재우기, 바람 16비트 저장(3단계) |
| 입력: 플레이어 몸·칼을 쓸린 구로(최대 16개) | 파편 대량 입력(2단계) |
| 물체: 등록된 상자(세로 축 둘레로 돌린 것까지)를 막힌 칸으로 굽기(최대 32개, 얇으면 한 칸 두께로 부풀림) | 구·기운 상자, 일반 물체 자동 수집, 움직이는 물체, 책상 밑 규칙(2단계) |
| 계산 창이 플레이어를 따라감(16칸 걸음) | 카메라 앞쪽으로 창 치우침(4단계) |
| 평지 구역, 바닥 높이 한 값 | 땅 높이 캡처, 비탈·절벽(2단계) |
| 고정 구역 상자 + 가장자리 흐림 | 구역 없는 넓은 야외, 먼 곳 이음(3·4단계) |
| 엔진 볼륨 안개에 얹기, 잔무늬는 원래 자리에서 읽기 | 자체 그리기, 1인칭(5단계). 소용돌이 보강, 떠오름 힘, 옮기기 고급 방식, 층 16개(4단계) |
| 값은 데이터, 품질 단계 표, 모드 스위치 | 설정 화면 연결, 시간 섞기 자동 걸기(2단계) |

2D 안개(FogMist·FogMistStir·FogTileSim)는 그대로 둔다. 3D 안개는 별도 액터와 전역 데이터 표 하나로 추가한다(안개 종류 열거형에 넣지 않는다).

2D 와 3D 가 겹치지 않게 하는 규칙: 3D 안개는 "구역 액터의 상자" 안에만 있다. 플레이어가 구역 밖이면 계산을 쉬고 평소 안개만 그린다. 1단계 평지 구역은 2D 구역의 깨우기 거리(20m) 밖에 둔다.

## 2. 이어받는 사실과 설계 판정 결과

- 0단계: 엔진 안 3D 한 번 계산(측정용) 256×256×8 에서 압력 반복 1회 0.034 ms, 나머지 0.137 ms. 볼륨 렌더 타깃을 Volume 재질이 읽어 3인칭에서 구분된다. 재질 추가 비용 +0.012 ms(작은 상자). 엔진 안개의 시간 섞기 0.9 는 절반 반응 8.4프레임. 안개 무대 GPU 여유 1.6~2.0 ms(초당 60장).
- 1차 실험: 칸 가운데에 값을 모아 둔 식은 몰림이 29~32% 남는다. 면에 둔 식은 0 까지 간다. 윗면을 열면 압력 영향이 약 1.2m 마다 e 배씩 줄어든다(그래서 단순한 풀이로 충분하다).
- 2차 실험: 차이값을 옮기는 식은 위아래로 흔들면 번져서 제자리로 못 돌아온다(0.042, 기준 0.04). 밀린 거리 식은 돌아온다(0.007). 바람을 넣으면 같은 붓의 모양 변화가 2.7~2.8배 커진다.
- 3차 보완(벽 처리, 세 번에 걸쳐 닫음)
  - 자기 칸만 자르는 처리는 한 칸 두께 벽에서 바람이 초속 10m 이상이면 설계값의 7.7~201배로 샌다(초속 3m 에서는 새지 않는다). 길 따라 자르기 + 막힌 칸 빼고 읽기로 얇은 벽 판정 76경우(와 두 칸 벽 8경우)가 모두 1.000배가 됐다.
  - 그래도 얇은 벽 두 장을 대각 한 칸 어긋나게 쌓으면 39.5배, 벽 사이에 뚜껑을 얹어 막은 방의 모서리에서는 한 번에 6칸 넘게 움직이는 바람(1/20초에 초속 20m 이상)일 때 1.8~11배로 샜다. 8칸 읽기에 "막히지는 않았지만 벽 너머인 유체 칸"이 대각으로 섞였기 때문이다.
  - 읽는 칸을 "끝 칸과 8칸 묶음 안에서 이어진 유체 칸"으로 한정하니 쌓은 벽 76경우와 막힌 방 3,840경우가 모두 1.000배다. 읽은 칸이 끝 칸과 이어져 있지 않은 경우는 0건이다(정의로 보장).
  - 벽 처리를 바꿔도 물체가 없는 장면의 결과는 비트 단위로 같다. 그래서 2차 실험의 판정 값이 그대로 유효하다.

## 3. 계산 모델

### 3.1 격자·좌표·자리 약속

- 가로·세로 칸 h = 15.625cm. 창 N × N 칸, N = 256(40m) 또는 128(20m). 칸 크기는 품질에 따라 바꾸지 않는다.
- 층: 8층, 층 두께 30cm, 전체 240cm. 층 k(0~7)의 아래 30k, 가운데 30k + 15, 위 30k + 30(cm). 높이는 "구역 바닥에서의 높이"다. 층 두께는 데이터 표로 두되 1단계는 고른 30cm 만 지원한다.
- 세계 칸 번호 = floor(세계 좌표 ÷ h)(정수). 창의 가장 작은 칸 번호 o = (ox, oy)는 축마다 16의 배수. 지역 칸 l = 세계 칸 − o(0 ~ N−1). 저장 자리 = 세계 칸을 N 으로 나눈 나머지(음수도 0 ~ N−1 이 되게 비트 곱으로). 창이 움직여도 데이터를 옮기지 않는다.
- 위치 계산은 모두 "창 기준 정수 칸 번호 + 칸 안 위치(cm, 32비트 실수)"로 한다. 세계 좌표를 32비트 실수 하나로 들지 않는다. 게임 쪽은 64비트 좌표에서 창 원점을 빼서 넘긴다.
- 값의 자리(엇갈린 격자). **이 약속이 다르면 결과가 크게 달라진다**(반대로 하면 높이 구분 비가 2.10 → 2.91).
  - 텍셀 (i, j, k)의 u = 칸의 +x 면 값(면 가운데), v = +y 면 값, w = 윗면(+z 면) 값.
  - d(밀린 거리 3성분, cm), g(채움 비율 차), 압력, 몰림 = 칸 가운데.
  - 창 서쪽·남쪽 가장자리 면과 바닥 면은 저장하지 않고 0 이다. 동쪽·북쪽 가장자리 면(지역 번호 N−1 의 u·v)은 저장 자리는 있지만 늘 0 이다.
- 닫힌 면: (가) 막힌 칸에 닿은 면 (나) 창 가장자리 면(이음매) (다) 바닥 면. 윗면(맨 위 층의 +z 면)은 열려 있다(그 위 압력 0).
- 닫힌 면의 바람은 0 을 "골라서" 쓴다(0 을 곱하지 않는다. 음수 × 0 은 −0 이 된다).
- 압력 색: (저장 자리 x + y)가 짝수면 0색, 홀수면 1색. 창 원점이 16의 배수이고 N 이 짝수라 지역 번호로 세어도 같다.

### 3.2 저장하는 것

- 읽기 뷰와 쓰기 뷰를 한 텍스처에 동시에 쓰는 것은 압력(R32F)뿐이다. 다른 텍스처는 "형식 있는 쓰기 뷰 읽기"가 필요 없게 짰다.

### 3.3 한 번 계산의 순서

```
[처음 계산, 다시 시작한 계산, 창이 움직인 계산, 물체 목록이 바뀐 계산에만]
 가. 막힘 굽기(두 패스): 칸 막힘 → 면 표시
 나. 정리: 바람을 다른 장으로 베끼면서 닫힌 면·이음매 면·새 띠를 0 으로 하고, 넷째 채널에 유체 표시를 쓴다
     (이 계산에서는 그 장이 "지금 장"). 같은 패스에서 새 띠의 d·g(이번에 읽을 장)와 압력을 0 으로 쓴다
[매 계산]
 1. 옮기기 패스: 바람·d·g 를 뒤로 따라가 읽기 → 되돌림 → 가장자리 띠 → 새 띠 0 → 입력(바람 섞기, 깎기)
                → 닫힌 면 바람 0 → 막힌 칸은 그리기용 값 채우기 → 바람·상태·출력 텍스처에 쓴다
 2. 몰림 계산
 3. 압력 풀이: 0색, 1색을 번갈아 8번(디스패치 16번)
 4. 압력 기울기 빼기 + 닫힌 면 바람 0
```

- 평소 디스패치 19번. 가·나가 도는 계산은 +3.
- 새 띠 = 지난 창에 없던 칸. 처음 계산과 다시 시작한 계산은 모든 텍스처를 0 으로 지운 뒤 가·나를 돈다.
- d·g 는 1 에서 확정되므로 출력 텍스처도 1 이 함께 쓴다(쓰기 뷰 3개).
- 바람 없는 판(모드 1)은 1 의 줄인 꼴만 돌되, 가·나는 완전판과 같은 조건에서 돈다(3.11).

### 3.4 평소 안개, 밀린 거리, 채움 비율

- 밀린 거리 d: 지금 자리 x 의 공기가 원래 있던 자리 X = x − d. 채움 비율 차 g: 깎이면 −1 쪽으로 간다(−1 = 다 깎임).
- 화면의 안개 농도 = max(0, 1 + g) × 평소 안개(X). 평소 안개(높이 곡선, 잔무늬, 얼룩)는 그리는 쪽(재질)에만 있다. 계산 셰이더는 평소 안개를 알지 못한다.
- 평소 곡선: B(높이) = 기본 농도 × (1 − smoothstep(두께 − 윗면 흐림, 두께, max(높이, 0))). 기본 0.8 / 90cm / 45cm.
- 옮기기: 칸 가운데 x 에서 뒤로 따라가 정한 표본 자리 e(3.6)에서 d·g 를 읽어
  - d ← [d(e) + (x − e)] × (가로 두 성분 exp(−0.1 dt), 높이 성분 exp(−0.3 dt))
  - g ← g(e) × exp(−0.3 dt)
- 바람 되돌림: 바람 ← 읽은 바람 × exp(−0.75 dt).
- 뜻
  - 위아래로 밀린 안개는 초당 0.3 으로 제자리에 돌아온다. 가로로 밀린 무늬는 초당 0.1 로 천천히 돌아온다. 깎인 곳은 초당 0.3 으로 다시 찬다(절반 2.31초).
  - 안개 윗면이 층 사이에 있어도 격자에 뭉개지지 않는다. 빈 곳은 빈 채로 남는다.
  - 평소 안개에 잔무늬가 있으면 바람에 실려 움직인다. 고른 안개(무늬 없음)에서는 가로 바람이 화면에 보이지 않는다. 그래서 잔무늬를 기본으로 켠다(4절).
- 깎기는 "자리"에 남는다: 밀려서 잠깐 비어 있던 자리를 깎아도, 안개가 그 자리로 돌아올 때 깎인 채로 돌아온다(1c 에서 눈으로 본다).
- 정지 상태(바람 0, d 0, g 0)는 계산을 돌려도 모든 값이 0 이다. 뒤 단계의 "잠든 덩어리 건너뛰기"가 기대는 조건이다. 교란 뒤 아주 작은 값이 정확히 0 까지 내려가는 것은 보장하지 않는다. 0 으로 내리는 문턱은 3단계에서 넣는다.

### 3.5 압력 풀이와 경계

- 몰림(칸 가운데): (u[i] − u[i−1]) ÷ h + (v[j] − v[j−1]) ÷ h + (w[k] − w[k−1]) ÷ 30. 저장하지 않는 면은 0. 막힌 칸은 0.
- 식: 대각 × p − Σ 결합 × p_이웃 = −칸 부피 × 몰림. 결합 = 면 넓이 ÷ 중심 거리(열린 면만): 가로 이웃 30(= h × 30 ÷ h), 위아래 이웃 h² ÷ 30. 맨 위 층은 윗면 결합 h² ÷ 30 을 대각에만 더한다(위 압력 0). 대각 = 결합의 합. 막힌 칸과 열린 면이 하나도 없는 칸은 p = 0.
- 풀이: 세로 줄 풀기. 한 색의 기둥마다 "오른쪽 = −부피 × 몰림 + Σ 가로 결합 × 이웃 p"로 8층 삼중 대각 식을 직접 풀어 y 를 얻고 p ← (1 − 1.5) × p + 1.5 × y. 0색 → 1색 순서로 8번 되풀이한다. 지난 계산의 압력에서 시작한다.
- 기울기 빼기(열린 면만): u −= (p[i+1] − p[i]) ÷ h, w[k] −= (p[k+1] − p[k]) ÷ 30, 맨 위 w −= (0 − p) ÷ 30.
- GPU: 색 하나에 디스패치 한 번. 스레드 하나가 기둥 하나(8층)를 레지스터에서 풀고 같은 텍스처에 쓴다. 같은 색 기둥끼리는 서로 읽지 않으므로 결과가 실행 순서와 무관하다. 색 사이의 장벽은 생략하지 않는다.
- 닫힌 면 너머의 압력은 0 을 곱하는 대신 아예 읽지 않는다. 막힌 칸에는 0 을 그대로 쓴다(가속 섞기를 하지 않는다).
- 숫자가 깨지지 않게: 삼중 대각 풀이에서 나눌 값(피벗)의 절댓값이 1e-12 × 그 층의 대각보다 작으면 그 층의 역수를 0 으로 둔다(그 층의 y 와 다음 층으로 넘기는 계수가 모두 0 이 된다). 사방과 위가 막힌 기둥 대비다. 기준 모의에도 같은 보호를 넣는다(1a-0).
- 품질 [실측]: 처음 풀기에서 몰림이 0.11~0.17 로 줄고, 입력이 움직이는 동안은 평균 0.016(이어 풀기 덕), 움직이다 멈춘 첫 계산은 0.23 이다.

### 3.6 옮기기와 벽

칸 (i, j, k) 가운데 x 에서

1. 바람 V = 자기 텍셀의 (u, v, w)를 칸 가운데 바람처럼 쓴다. 이동 δ = −V × dt.
2. 이동 상한: δ 에 min(1, 125 ÷ |δx|, 125 ÷ |δy|, 120 ÷ |δz|)를 곱한다(cm. 성분이 0 인 항은 뺀다. 방향은 그대로).
3. 목표 x1 = x + δ 를 자른다. 가로는 "지금 창과 지난 창이 겹치는 칸들의 가운데점 상자", 높이는 맨 아래 층 가운데(15cm) ~ 맨 위 층 가운데(225cm).
4. 길 따라 자르기: 선분 x → x1 을 칸 단위로 따라간다. 지금 칸 c = 자기 칸, 끝 좌표 e = x1. 축마다 이동 방향 = (x1 − x) 의 부호. 이동이 0 인 축은 처음부터 묶인 것으로 본다.
   되풀이(최대 24번)
   - x, y, z 순으로, 묶이지 않은 축 가운데 이동 방향으로 칸 c 의 면이 닫힌 축: x1 의 그 성분이 칸 c 의 가운데를 이동 방향으로 넘었으면 e 의 그 성분을 가운데로, 아니면 x1 그대로 두고, 그 축을 묶는다.
   - 묶이지 않은 축마다 선분이 칸 c 의 이동 방향 쪽 경계를 넘는 시점 t = (경계 − x) ÷ (x1 − x)를 구해 가장 작은 축을 고른다(엄격히 작을 때만 바꾼다. 같으면 x, y, z 순으로 앞 축). 고를 축이 없거나 t > 1 이면 끝낸다. t 는 자기 칸 가운데를 원점으로 한 칸 안 좌표로 계산한다(가로와 세로 이동이 정확히 같을 때 두 시점이 정확히 같게 나오도록. 기준 모의도 같은 식으로 맞춘다).
   - c 를 그 축 방향으로 한 칸 옮긴다.
5. 표본 자리 e 에서 8칸 읽기: e 를 끼고 있는 칸 가운데 8개를 직접 읽는다. 축마다 가중치 t(0~1, 32비트 실수). 기준 칸 번호는 창 안에서 N−2(층은 6)를 넘지 않게 자르고 그때는 t = 1 로 둔다.
   - 이어짐: 4 가 끝난 칸을 "끝 칸" c 라 한다(늘 유체이고 8칸 가운데 하나다). 8칸의 유체 표시만으로, c 에서 유체 칸을 면 이웃으로 따라가 닿는 칸을 "이어진 칸"으로 정한다(무게와 무관).
     ① c 와 한 축이 다른 세 칸(면 이웃): 유체면 이어짐.
     ② 두 축이 다른 세 칸(모서리 대각): 유체이고, 그 두 축의 면 이웃 가운데 하나라도 이어져 있으면 이어짐.
     ③ 세 축이 다른 칸(몸통 대각): 유체이고, 모서리 대각 세 칸 가운데 하나라도 이어져 있으면 이어짐.
     ④ ② 에서 이어지지 않은 유체 모서리 대각 칸은, 몸통 대각 칸이 이어져 있으면 이어짐.
   - 바람 세 성분: 칸 가운데 값처럼 높이 → 세로(y) → 가로(x) 순으로 "a × (1 − t) + b × t" 꼴로 섞는다(t = 1 에서 정확히 b 가 나오는 꼴이다. a + t × (b − a) 꼴은 쓰지 않는다). 막힌 칸은 그대로 섞고(막힌 칸의 면 값은 0 이다), 이어지지 않은 유체 칸의 값은 0 을 골라 섞는다. 다시 나누지 않는다.
   - d·g: 칸마다 무게 = 세 축 가중치의 곱. 값 = Σ(무게 × 값). 8칸 가운데 막힌 칸이나 이어지지 않은 칸이 하나라도 있으면 그 칸들의 무게를 0 으로 하고 남은 무게의 합으로 나눈다. 8칸이 모두 막힌 칸이면 자기 칸 값을 쓴다(c 가 유체라 생기지 않는다).
6. 3.4 의 식으로 d·g·바람을 갱신한다.

- 4 의 뜻: 표본 자리는 닫힌 면에 붙은 칸의 가운데를 그 면 쪽으로 넘지 못한다. 그래서 길이 벽을 넘지 않고, 벽의 두께·바람 빠르기·시간 간격과 무관하다. 벽을 따라 미끄러지는 이동은 남는다.
- 5 의 "이어짐"의 뜻: 길 옆으로 대각에 놓인 막힌 칸과, 막히지는 않았지만 벽 너머에 있는 유체 칸을 읽지 않는다. 그래서 읽는 칸은 늘 끝 칸과 열린 면으로 이어져 있다. 이미 읽는 8칸의 유체 표시만 쓰므로 읽기 수는 늘지 않는다(비트 연산 네 단계).
- 끝 칸이 8칸 묶음 밖에 놓이는 일은 생기지 않는다(실측 0번). 생기면 이어짐 규칙을 적용하지 않는다.
- 실측: 한 칸 이상 옮겨 가는 칸은 보통 장면(초속 4m 이하)에서 0%, 초속 24m 구 입력에서 0.13%(최대 2번)다. 초속 30m 바람을 창 전체에 덮어쓴 시험에서도 최대 10번이었다. 이동 상한에서 최대 20번이므로 24번 상한에 닿지 않는다.
- 그리기용 값 채우기: 막힌 칸의 d·g 자리(상태와 출력)에는 "유체인 면 이웃들의 지난 값 평균"을 적는다. 유체 면 이웃이 없으면 0. 창 가장자리 너머의 이웃(저장 자리가 감겨 반대편 값이 나오는 칸)과 바닥 아래·윗면 위는 이웃으로 세지 않는다. 재질이 벽 옆에서 보간해 읽을 때 벽 속의 0 이 섞여 안개 띠가 생기지 않게 하는 용도다. 계산은 이 값을 읽지 않는다(5 가 막힌 칸을 뺀다). 기준 모의에는 없으므로 대조·해시는 유체 칸만 본다. 한 칸 두께 벽에서는 양쪽 이웃의 평균이 적히므로, 재질이 벽 속 칸을 보간할 때 양쪽 값이 섞여 보일 수 있다(벽 속이라 보통 보이지 않는다. 1c 에서 눈으로 본다).

### 3.7 입력

- 표준형은 "쓸린 구" 하나다: 지난 중심 A → 지금 중심 B, 반지름 r, 속도 V = (B − A) ÷ (마지막 계산 뒤 실제로 흐른 시간), 바람 세기 s(기본 1), 깎기 비율 E(초당). 속도의 크기는 상한(데이터, 기본 초속 30m)으로 자른다(방향은 그대로).
- 처음 계산과 다시 시작한 계산(3.9)은 모든 입력의 A 를 B 와 같게 둔다(속도 0. 깎기의 머문 양은 아래 "|B − A| < 0.01cm" 경우). 순간이동한 자리까지 긴 줄로 바람이 그어지는 일을 막는다.
- 한 번 계산에 최대 16개. 수집 순서는 칼날(끝 → 손잡이) → 손 → 발 → 골반이고, 16개를 넘으면 뒤에서부터 버린다(한 번 경고).
- 몸: 뼈 위치(기본 pelvis·hand_r·foot_l·foot_r). 칼: 칼날 축을 따라 간격이 반지름 이하가 되게 놓은 구들(개수 = 올림(길이 ÷ 반지름) + 1. 1m·반지름 20cm 면 6개). 반지름은 16cm 이상(데이터 검사).
- 깎기 기본값(데이터): 칼날 초당 30, 몸 0. 서 있는 입력에 깎기를 주면 구멍이 계속 깊어지므로 몸은 0 으로 시작한다(1c 일괄 보정).
- 가중치 W(칸 높이 범위에서 평균): 재는 자리에서 선분 AB 위 가장 가까운 점까지의 차를 (ox, oy, oz), a = 1 − (ox² + oy²) ÷ r². a ≤ 0 이면 0. 아니면 W = (r ÷ 30) × [G(u2) − G(u1)], G(u) = a²u − (2/3)a u³ + u⁵/5, u1 = max((oz − 15) ÷ r, −√a), u2 = min((oz + 15) ÷ r, √a), u2 ≤ u1 이면 0.
- 바람 섞기: 입력 순서대로, 성분이 놓인 자리(u 는 +x 면 가운데, v 는 +y 면 가운데, w 는 윗면 가운데)마다 값 ← 값 + (V 의 그 성분 − 값) × (s × W).
- 깎기(칸 가운데): 선분 위 점 c(t) = A + t(B − A). 칸 가운데와 c(t) 의 가로 거리가 r 보다 작은 t 구간 [t1, t2](0~1 로 자름)에서
  머문 양 D = dt × (t2 − t1) × Σ 무게 × W(붓 중심이 c(t_q) 한 점일 때), t_q = t1 + (t2 − t1) × {0.5 − 0.5√0.6, 0.5, 0.5 + 0.5√0.6}, 무게 {5/18, 8/18, 5/18}.
  - |B − A|(3차원) < 0.01cm 면 D = dt × W(A).
  - 가로 이동이 0.01cm 미만이면(내려찍기) 구간은 "칸 가운데와 A 의 가로 거리 < r 일 때 [0, 1], 아니면 없음"이다.
  - 모든 입력의 E × D 를 더한 X 가 0 보다 큰 칸만 g ← max(0, 1 + g) × exp(−X) − 1.
- 순서: 바람 섞기를 모두 한 뒤 깎기를 한 번 한다. 계산을 건너뛴 프레임이 있으면 A 는 "마지막으로 계산했을 때의 위치"다.
- 비용을 지키려면 입력마다 경계 상자 밖의 칸을 먼저 거른다.
- 식의 정본은 `prereg-design-2.md` 1절 4(가중치)와 `prereg-design-2b.md` 1절(깎기)이다.

### 3.8 물체

- 등록된 물체(지금 2D 가 쓰는 물체 컴포넌트) 가운데 상자를 읽는다. 1단계는 "바로 선 상자"(세로 축 둘레로만 돌린 것)만 받는다. 판정: 상자의 국소 셋째 축과 위 방향의 안쪽 곱 절댓값이 1 − 1e-4 이상이면 바로 선 상자로 보고 돌림 각만 쓴다. 구와 기운 상자는 건너뛰고 한 번 경고한다(2단계).
- 최대 32개. 넘으면 창 가운데에서 가까운 순으로 고른다(같으면 등록 순).
- 부풀리기: 상자의 국소 축 a 마다 반두께 ← max(원래 값, 7.9cm + 7.2cm × |a·위|). 바로 선 상자면 가로 두 축 7.9cm, 세로 축 15.1cm 다. 칸보다 얇은 물체가 사라지지 않고 한 칸 두께 벽이 되게 한다. 값은 데이터이고, 이 값은 칸 15.625cm·층 30cm 에 맞춘 것이다(반 칸 + 0.0875cm, 반 층 + 0.1cm. 칸이나 층이 바뀌면 다시 정한다).
- 굽기: 칸 가운데가 (부풀린) 물체 안이면 막힘(열린 부등호). 막힌 칸에 닿은 면은 닫힘. 첫 패스가 칸 막힘을, 둘째 패스가 이웃 6칸의 막힘을 읽어 면 표시를 만든다. 칸 가운데 위치는 창 기준 정수 칸 번호 + 칸 안 위치로 계산한다(여유가 작아 큰 좌표의 32비트 오차를 견디지 못한다).
- 바닥은 항상 닫힘. 캐릭터는 막힘이 아니라 입력으로만 넣는다. 1단계의 물체는 움직이지 않는 것으로 본다(목록이 바뀌면 다시 굽는다).

### 3.9 창 이동, 가장자리, 다시 시작

- 플레이어 칸이 창 가운데 칸(o + N/2)에서 어느 축으로든 12칸 넘게 벗어나면, 그 축에서 o ← 16 × floor((플레이어 칸 − N/2) ÷ 16 + 0.5). 걷기 기준 약 0.6초에 한 번.
- 새로 들어온 띠: 바람·d·g·압력 0 에서 시작한다("정리" 패스가 읽을 텍스처의 새 띠를 0 으로 쓴다. 저장 자리가 감기므로 지우지 않으면 반대편에서 나간 줄의 묵은 값이 남는다). 들어온 계산의 옮기기 결과도 0 으로 둔다(그 뒤 입력·압력은 적용).
- 가장자리 띠 8칸: fade = smoothstep(0, 8, 창 가장자리에서 칸 가운데까지의 칸 수(가로·세로 중 작은 쪽)). 바람·d·g 에 exp(−4 × (1 − fade) × dt)를 곱한다. 면 값은 그 텍셀의 계수를 쓴다. 재질도 같은 fade 로 d·g 의 무게를 내린다.
- 다시 시작(모든 값을 0 에서): 순간이동(한 번에 창 크기 이상 이동), 구역 재진입, 모드나 품질 단계를 바꿀 때, 꺼져 있던 엔진 볼륨 안개가 다시 켜질 때. 다시 시작한 계산은 입력의 지난 위치도 버린다(3.7).

### 3.10 시간 간격

- 한 번 계산의 dt = 지난 계산 뒤 흐른 시간. 상한 1/20초(넘으면 1/20초로 계산한다. 입력 속도 V 는 실제 흐른 시간으로 나눈다).
- 품질 단계의 "초당 계산 횟수"는 상한이다. 화면이 더 빠르면 계산을 건너뛰고, 더 느리면 프레임마다 한 번 계산한다.
- 결정론 시험은 2D 관례대로 시간 간격을 섞어 돌린다(1/60·1/30·1/45·1/20). 기준 모의와의 대조는 고정 간격으로 한다.

### 3.11 모드 스위치

| 값 | 뜻 |
|---|---|
| 0 | 끔(평소 안개만 그림) |
| 1 | 바람 없는 판: g ← g × exp(−0.3 dt) → 깎기 → 막힌 칸 그리기용 값 채우기만. d 와 바람은 0(출력의 d 도 0). 압력·옮기기·가장자리 띠 없음. 창이 움직이거나 물체 목록이 바뀐 계산에는 완전판과 똑같이 막힘 굽기와 정리(새 띠 g = 0)를 한다 |
| 2 | 완전판(기본) |

데이터 값이고 콘솔 `TD.Fog3D.Mode` 로 덮어쓴다(−1 이면 데이터). 1c 에서 1 과 2 를 같은 장면으로 나란히 찍는다.

### 3.12 시험용 손잡이(GPU 모듈의 시험 입력, 게임에서는 쓰지 않음)

압력 끔 / 되돌림 끔(바람·d·g) / 가장자리 띠 끔 / 정해 준 바람으로 덮어쓰기(고른 벡터, 위아래 흔들기, 되돌리는 소용돌이) / 영역 비우기(g = −1, d = 0) / 영역을 정지로(d = 0, g = 0) / 전체 상태 읽어 오기(덤프). 1a 의 기준 대조 시험이 쓴다.

## 4. 그리기 연결

- 구역 액터가 가진 상자 메시(구역 크기로 고정)에 Volume 재질을 입혀 엔진 볼륨 안개에 얹는다(0단계에서 확인한 길).
- 재질(Custom 노드 하나): 창 기준 위치로 출력 텍스처를 읽어 d·g 를 얻는다. 가로 UV = 창 기준 위치 ÷ (N × h), 높이 W = 바닥에서의 높이 ÷ 240. 필터는 선형, 주소는 고정(clamp).
- 창 기준 위치를 큰 좌표에서도 정밀하게 구하는 법: 그래프에서 (절대 세계 위치 − 구역 액터 위치)를 큰 좌표 빼기로 구하고, 거기서 "창 원점 − 구역 위치"(게임이 64비트로 계산해 32비트로 넘긴 값)를 뺀다. 창 원점 파라미터는 "마지막으로 제출한 계산의 창 원점"이다(계산을 건너뛴 프레임에도 그대로).
- 무게 = 가장자리 띠 fade × "계산 중" 여부 × (1 − smoothstep(210, 240, 높이)). d·g 에 무게를 곱한 뒤
  원래 자리 X = 지금 자리 − d, 농도 = max(0, 1 + g) × B(X 의 높이) × 잔무늬(X 의 가로 위치) × 구역 가장자리 흐림.
- 잔무늬: 0.5m 간격 값 잡음 n 으로 농도 × (1 + 0.2 × (2n − 1)). 기본 켬. 얼룩(두께가 2m 간격 값 잡음으로 ±30% 달라짐): 기본 끔. 둘 다 X 에서 읽으므로 바람에 실려 움직이고, 밀린 것이 돌아오면 제자리로 온다. 잡음 좌표는 구역 기준이다(창 기준이면 창이 움직일 때 무늬가 튄다). 값은 데이터(1c 에서 비교).
- 값 잡음의 정의(기준 모의와 같은 값이 나와야 한다): 격자점 (x, y)의 값은 32비트 부호 없는 정수로 h = x × 374761393 + y × 668265263 + 씨앗 × 2246822519, h = (h ^ (h >> 13)) × 1274126177, h = h ^ (h >> 16), 값 = h ÷ 2³². 격자 칸 안은 smoothstep 가중 양선형. 씨앗은 잔무늬 1, 얼룩은 데이터.
- 구역 가장자리: 상자 면에서 안쪽으로 데이터로 정한 폭(기본 5m)만큼 서서히 0. 구역 크기는 창보다 커도 작아도 된다(창 밖 구역은 평소 안개로 그린다). 구역 한 변은 흐림 폭의 2배 이상이어야 한다(데이터 검사).
- 엔진 볼륨 안개가 꺼진 품질(`r.VolumetricFog=0`)이거나 높이 안개의 볼륨 안개가 꺼져 있으면 계산과 쓰기를 건너뛴다.
- 엔진 안개의 시간 섞기 값은 1단계에서 건드리지 않는다. 1c 에서 콘솔로 0.9·0.8·0.7 을 비교한다.
- 평소 곡선 식은 재질 한 곳에만 있다. 재질 HLSL 은 dxc 컴파일 확인과 "기준 모의의 그리는 식과 같은 값" 시험을 둔다(구역 위치 0, 높이 210cm 아래 칸 가운데에서).

## 5. 품질 단계 — 잠정(1a 에서 실제 시간을 재고 확정)

| 단계 | 창 | 초당 계산 | 한 번 계산 어림 |
|---|---|---|---|
| 낮음 | 128×128(20m) | 30 | 0.15~0.23 ms |
| 보통 | 256×256(40m) | 30 | 0.55~0.85 ms |
| 높음(기본) | 256×256(40m) | 60 | 0.55~0.85 ms |

- 어림의 근거 [추정]: 0단계 실측(옮기기 약 0.07, 몰림·기울기 각 0.034, 압력 훑기 1번 0.034 ms)을 패스 목록과 읽고 쓰는 양에 맞춰 다시 셈. 옮기기(8칸 직접 읽기 2벌 + 입력 16개 + 길 따라가기, 32비트 텍스처) 0.22~0.30, 몰림 0.034~0.05, 압력 디스패치 16번 0.28~0.40, 기울기 0.04~0.06. 가·나가 도는 계산은 +0.05~0.15 ms.
- 창을 256 → 128 로 줄이면 비용이 약 30% 로, 초당 60 → 30 으로 줄이면 평균 50% 로 내려간다. 16층 단계는 1단계에서 두지 않는다.
- 표는 데이터에 두고 콘솔 `TD.Fog3D.Quality` 로 바꾼다(−1 이면 데이터).

## 6. 게임 쪽 구조

| 누구 | 하는 일 |
|---|---|
| `ATDFog3DZoneActor`(무대에 배치) | 구역 상자·바닥 높이 보유. 매 틱(단계 `TG_PostUpdateWork`): 플레이어가 구역 안인지, 엔진 볼륨 안개가 켜졌는지 확인 → 몸·칼에서 쓸린 구 수집 → 물체 목록 → 창 위치 → 계산 제출 → 재질 파라미터. 월드에서 하나만 계산한다(둘째는 경고 후 쉼) |
| `FTDFog3DLayer`(UObject 아님) | 창 칸 맞추기, 계산 박자, 입력·물체를 창 기준으로 포장(부풀리기 포함), 렌더 상태 소유, 렌더 명령 발행. 월드 없이 시험 가능 |
| `FTDFluidGpuFog3DState`(GPU 모듈) | 렌더 스레드만 만지는 상태 텍스처 묶음 |

- 본보기는 물 근접 잔물결 층(창 따라가기, 자체 그래프, 출력 렌더 타깃 직접 쓰기). 엔진 순서상 월드 틱이 화면 그리기보다 먼저이므로 같은 프레임에 계산하고 읽는다(매 프레임 쓰고 읽는 경로는 1b-7 이 처음 확인한다).
- 입력 수집은 새로 짠다(기존 2D 입력 코드는 고치지 않는다).
- 물체는 `UTDFluidLiveSubsystem` 에 읽기 함수 하나를 더해 얻는다(기존 파일 변경은 이것과 프리셋 등록 1줄, 정본 JSON 1항목뿐). 정본 JSON 에는 다른 작업의 커밋 안 된 변경이 있으므로 내 덩어리만 스테이징한다.
- 데이터: 전역 표 `Globals.TDFog3DSettings`(구조체 `FTDFog3DSettings`, `Source/TDGame/FluidFX/TDFog3DTypes.h`). 켜기·모드·창·층 두께 표·평소 곡선·되돌림(바람, 밀린 거리 가로·높이, 채움)·입력(뼈 목록과 반지름, 칼 반지름, 깎기 비율, 속도 상한)·물체(상한, 부풀리기 값)·구역 흐림 폭·잔무늬·얼룩·품질 단계 표.

## 9. 결정 기록 (claude 결정, 사용자가 뒤집을 수 있음. 규칙이 고른 것은 "규칙"으로 표시)

1. 사다리 중간 칸을 건너뛰고 완전판으로 간다. 보완: 바람 없는 판 스위치.
2. 3D 안개는 안개 종류 열거형이 아니라 별도 액터 + 전역 표로 둔다.
3. 3D 안개는 구역 상자 안에만 있다(2D 와 겹치지 않게, 안개 벽 없이). 구역을 나갔다 들어오면 0 에서 시작한다.
4. [규칙 R2-F] 안개 농도 대신 밀린 거리와 채움 비율을 옮긴다. 이 식을 후보에 넣은 것은 감독 결정(덧붙임 2b).
5. [규칙 R2-L·R2-A·R2-P] 층 30cm × 8, 한 번 읽기 옮기기, 세로 줄 풀기 8번.
6. [규칙 R3-S → R4-S → R5-S] 벽 처리는 길 따라 자르기 + 이어진 칸만 읽기. 얇은 물체는 한 칸 두께로 부풀린다. 규칙 R2-S 가 고른 처리(자기 칸만 자르기)가 얇은 벽에서 새는 것을 반박이 찾았고, 그 뒤 두 번 더(어긋나게 쌓은 벽, 막힌 방의 모서리) 등록 밖에서 새는 경우를 찾아 그때마다 덧붙임(2c·2d·2e)을 실험 전에 등록해 닫았다. "여유"나 "한계"로 넘기지 않고 구조로 막는다는 것이 감독 결정이다.
7. 쌓이는 값은 모두 32비트로 저장한다(메모리 약 43MB). 바람을 16비트로 줄이는 것은 3단계 최적화 후보다. 8칸은 직접 읽는다(하드웨어 보간을 쓰면 먼 좌표에서 결과가 달라진다). 막힌 칸 표시는 바람 텍스처의 넷째 채널에 실어 읽기 수를 늘리지 않는다.
8. 붓 가중치는 칸 높이 평균, 깎기는 가로로 지나간 시간 구간의 3점 적분으로 정의한다.
9. 깎기 기본값은 칼날만(초당 30), 몸은 0. 잔무늬는 기본 켬, 얼룩은 기본 끔.
10. 1단계는 평지 구역(바닥 높이 한 값), 물체는 바로 선 상자만. 땅 높이 캡처, 구·기운 상자, 시간 섞기 자동 걸기는 2단계로 미룬다.
11. 품질 단계는 2의 거듭제곱 격자만 둔다. 낮은 단계는 칸을 키우지 않고 창을 줄인다.
12. "높은 상자를 돌아 흐름"(D-V3 ③)은 실패로 기록하고 기대치를 낮춰 적는다.
13. 밀린 것이 돌아오는 빠르기는 높이 초당 0.3, 가로 초당 0.1 로 시작한다(데이터, 1c 일괄 보정).
14. 규칙이 고른 "한 번 읽기 옮기기"를 그대로 쓴다. 반박이 찾은 약점(면 자리 약속에 민감, 좌우 14% 비대칭)은 한계로 적고, 더 정밀한 방식은 4단계 후보로 둔다. 규칙 결과를 뒤집지 않는다.
15. 막힌 칸에는 그리기용으로 유체 이웃 평균을 적는다(벽 옆 안개 띠 방지. 계산은 읽지 않는다).
16. 1a 통과 기준은 1a-0 이 기준 숫자를 뽑은 뒤, GPU 를 재기 전에 잠근다.

## 10. 알려진 한계와 뒤 단계로 넘긴 것

- 바람은 1.5~2.5m 에서 멈춘다(되돌림 값으로 조절). 소용돌이가 생기지 않는다(4단계 후보).
- 고른 안개에서 가로 바람은 잔무늬가 있어야 보인다.
- 높이 구분은 처음 0.3초쯤에 뚜렷하고, 1초 뒤에는 남은 바람이 안개 윗면을 누른다.
- 한 번 읽기 옮기기: 대칭인 내려찍기에서 고리 바람이 동쪽 21.7, 서쪽 24.8 cm/s 로 14% 다르다. 1초 뒤 바람 장은 정밀한 방식과 상대 0.5~0.6 다르고 고리 바람은 1.46배 세다.
- "되돌리면 제자리"는 작은 밀림(약 25cm)·초당 60번 근처에서만 잘 맞는다. 되돌리는 소용돌이의 끝값은 초당 30번에서 0.043(기준 0.04 를 조금 넘음), 초당 10번에서 0.22, 1초씩 길게 밀면 0.63 이다. 크게 밀린 곳은 되돌림(초당 0.3·0.1)이 천천히 되돌린다.
- 걷기에서 가로 밀림이 3m 넘게 쌓여, 끌린 무늬가 10초 넘게 남을 수 있다 [추정].
- 맨 위·맨 아래 층에서는 위아래로 흔든 뒤 밀림이 남는다(맨 위 층 14cm). 재질이 높이 210~240cm 에서 무게를 0 으로 내려 가린다.
- 아주 빠른 입력(초속 30m 가 상자 모서리를 스침)에서 원래 자리 사상이 접히는 칸이 0.02~0.26% 생긴다. 숫자는 깨지지 않는다.
- 층 30cm 는 휘두른 자리의 얇은 구조를 뭉갠다(4배 촘촘한 층과의 차가 신호의 약 40%). 아래가 얇은 층 배치는 네 장면 중 셋에서 낫지만 한 장면에서 2.5배 나빠 규칙이 고르지 않았다.
- 압력: 움직이다 멈춘 첫 계산에서 몰림이 0.23 남는다. 사방과 위가 막힌 빈 칸 묶음은 처리하지 않는다(숫자가 깨지지 않게만 한다).
- 구와 기운 상자는 막지 못한다(건너뜀. 2단계).
- 입력은 벽을 가리지 않는다. 칼이 벽에 붙어 지나가면 붓(반지름 20cm)이 벽 너머 칸에도 닿는다(2단계에서 다룬다).
- 가로와 세로 이동이 정확히 같은 대칭 장면에서는 길 따라가기의 순서 규칙(x 먼저)에 따라 벽 옆 몇 칸의 밀린 거리가 달라질 수 있다(채움은 같다). GPU 와 기준 모의를 맞대어 볼 때 그런 장면은 채움으로 본다.
- 상태 해시는 −0 과 +0 을 다르게 본다. 맞대어 볼 때는 −0 을 +0 으로 바꾼 뒤 해시한다.
- 작은 값이 정확히 0 까지 내려가지 않는다(3단계에서 문턱).
- 평지만 된다. 비탈·절벽, 움직이는 물체, 책상 밑은 2단계.
- 기준 모의와 판정 도구는 지금 `Tools/scratch/fog3d/stage1/r2/`에 있다(커밋 대상 아님). 1a-0 에서 `Tools/FluidFX/`로 올린다.

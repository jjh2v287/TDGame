# 3D 볼륨 안개 2단계(지형·물체) — 구간 계획

작성: 2026-11-15 claude(감독·결정). 근거: 계획 `Docs/VolumeFog3D_Plan.md` 7절의 "2 지형·물체·파편" 줄, 1단계 마무리에서 넘어온 흠 ①~④(`Docs/VolumeFog3D/progress.md` '1단계 마무리 결과와 판정').

## 구간과 순서

| 구간 | 만들 것 | 끝난 모습 | 크기 |
|---|---|---|---|
| 2a 땅 높이 따라가기 | 격자의 세로축을 "땅에서의 높이"로 바꾼다. 비탈·언덕 따라가기, 급한 곳(절벽)은 벽, 창이 움직일 때 땅 높이 갱신, 땅 높이 원본(기존 지형 높이 캡처 방식을 다시 쓸지 검토) | 비탈·절벽 무대에서 안개가 땅을 따라 깔리고, 걷기·휘두르기 반응이 평지와 같은 느낌이며, 절벽 아래와 위가 서로 영향을 주지 않는다. 정지 시험 흐트러짐 0 | 중 |
| 1단계 흠 ⑤ 섞기 식 넘침 | (2a 구현 중 발견, 감독 세션 결정 2026-11-15: 2a 를 닫은 뒤·2b 앞) 바람 섞기 식에 자르기가 없어 세기 3.0 에서 가만히 선 몸 주변 바람이 계속 진동한다. GPU·게임에서 재현 → 후보를 실험 전에 등록(따르는 빠르기와 바람 크기 배율을 나누는 안 포함, 품질 단계별) → 독립 반박 → GPU 는 데이터 스위치로 넣고 기본값은 지금 식 → 1단계·2a 판정선 뒷걸음 확인 → 지금 식 대 고친 식 그림. 2b 의 입력 패스 작업보다 먼저 | 가만히 선 몸 주변 바람이 잦아들고, 사용자가 나란히 놓인 그림으로 식과 세기를 고른다 | 중 |
| 2b 물체 | 구·기운 상자·일반 물체를 충돌 도형에서 자동으로 모아 층별 막힌 칸으로 굽기, 책상 밑 규칙, 칼 입력이 벽 너머에 닿지 않게 하기(흠 ①), 물체 옆 어두운 띠(흠 ②)와 먼 상자 아래 쐐기(흠 ④)의 원인 찾기, 위에서 내려다보는 촬영으로 높은 상자 뒤 막힘 확인(흠 ③), **2a 에서 넘어온 것 둘: ① 위가 덮인 빈 곳(판·다리·처마 밑)에 안개가 차는 성질을 어떻게 할지 ② 오픈월드용 구역 상자 규칙 — 지금은 상자가 그 자리 지형의 높낮이를 모두 덮어야 한다(높낮이 54m 인 곳에서 상자 높이 60m). 창을 따라 자동으로 잡을지 포함**(2026-11-16) | 무대의 물체를 손으로 등록하지 않아도 막히고, 얇은 벽 뒤 안개가 칼에 바뀌지 않는다 | 중~대 |
| 2c 움직이는 물체·파편 | 움직이는 물체(막힘이 바뀔 때 다시 굽기와 그 비용), 파편 입력(구역별 목록), 파편 200·500개 장면 비용 | 파편이 안개를 밀고, 비용 숫자가 나온다 | 중 |
| 2d 마무리 | 엔진 안개 시간 섞기 값 걸기, 2단계 일괄 촬영(비탈·절벽·물체·파편), 전체 비용, 사용자 눈 판정, **기본값 결정의 근거 하나: 기존 1단계 무대 `LV_TDFog3DStage` 에서 땅 따라가기를 켠 것과 끈 것이 같은 그림인지**(2026-11-16 감독 세션 보탬. 오늘 확인된 것은 새 무대의 평지 칸뿐: 안개 보임 23.35 대 23.35, 걷기 자국 5.84 대 5.84) | 2단계 닫음 판정 | 소 |

## 이 순서인 까닭

- 2a 가 먼저: 칸의 "세계 높이"가 바뀌면 물체를 칸에 굽는 식(2b)과 입력을 칸에 넣는 식(2c)이 모두 그 위에 선다. 물체를 먼저 만들면 다시 고쳐야 한다.
- 2b 가 2c 앞: 벽 너머 입력 막기는 파편 수백 개의 입력에도 그대로 쓰인다. 물체를 모으는 길(충돌 도형 → 막힌 칸)도 움직이는 물체가 다시 쓴다.
- 시간 섞기 값은 다른 것과 얽히지 않고 작다. 촬영 조건을 한 번만 맞추려고 마지막 일괄 촬영과 묶는다.
- 흠 ②·④(띠·쐐기)는 2a 뒤에 본다: 원인이 "벽 옆 칸에서 위아래로 밀린 값"이면 2a 의 좌표 변화와 얽힌다.

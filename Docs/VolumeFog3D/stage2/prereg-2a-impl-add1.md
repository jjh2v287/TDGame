# 2a 구현 통과 기준 — 덧붙임 1: R5 덧층의 대조 (등록본)

등록: 2026-11-15 claude(감독·결정). `prereg-2a-impl.md`(잠김)는 고치지 않는다. R5 덧층을 GPU 에 넣기 전에, 곧 R5 의 GPU 덤프가 하나도 없을 때 잠근다. 해시는 `Docs/VolumeFog3D/progress.md` '사전 등록 잠금'에 적는다.

이 문서를 쓸 때 감독이 이미 본 것: R4 본체로 잰 2A-I1(D3D12·D3D11 통과, 가장 큰 장 차이가 한계의 0.8%)·I3(변이 일곱 잡힘)·I2(글자대로는 미충족: 예외 ADD-a), 기준 모의의 덧붙임 2 결과(정보 ⑯·⑰: 부분 기울임이 크게 일어나는 곳은 낮은 턱뿐). R5 의 GPU 결과는 없다(코드가 아직 없다).

## 1. 왜 보태는가

`prereg-2a-impl.md` 4절은 "R5 가 골라지면 기준 덤프를 R5 로 다시 뽑아 I1·I3 을 다시 잰다"고만 적었다. 그런데 재생 장면 12개에는 R5 의 부분 기울임(몫 g 가 0 과 1 사이)이 거의 없다(덧붙임 2 정보 ⑰: 30cm 턱 걷기 98쌍, 비탈 옆 100cm 턱은 건너편이 통째로 g = 0). 그대로 재면 "R5 의 섞기 산술이 GPU 에서 맞는가"를 가리지 못한다.

## 2. 보태는 것

1. **장면 하나**: `s2a_slope_curb60` — 지형 S30CURB60(x < 0 이면 tan(30도) × x, 아니면 60. 덧붙임 2 정보 ⑯의 지형), 2A-G4 (가)의 걷기(걷는 선 x = −20, +y) 70걸음 + 멈춤 78걸음, 이어서 칼 구(반지름 35cm, 바람 세기 2.5, 깎기 초당 30, 그 자리 땅에서 100cm)가 (−120, 0)에서 (60, 0)까지 초속 800cm 로 턱을 넘어가고(끝점에서 자름), 그 뒤 입력 없이 30걸음. 덤프는 걷기 70걸음째·칼이 끝난 걸음·끝. 턱을 넘는 칼을 넣는 까닭: 깎는 양의 섞기가 실제로 쓰이게 하려는 것이다(기존 칼은 턱 40cm 앞에서 멈춘다).
2. **2A-I1(R5)**: 재생 장면 13개(기존 12 + 위 하나)를 후보 R5 의 기준 덤프(`fog3d_replay_s2a.py --candidate R5`)와 대조한다. 기준은 `prereg-2a-impl.md` 2A-I1 그대로다(유체 표시 같음, 묶음별 장 차이 ≤ X, 땅 높이·벽 같음, 기울기 ≤ 1e-6, 입력 틀 ≤ 1e-3cm·1e-5, D3D12 와 D3D11). X 는 같은 식 min(3%, max(0.2%, 3 × 민감도))로 R5 기준 덤프와 그 흔든 덤프에서 다시 계산하고, GPU 를 재기 전에 숫자 파일 `Docs/VolumeFog3D/measurements/stage2a-impl/prereg-2a-impl-numbers-r5.json` 으로 적는다(이 문서의 잠금 뒤, GPU 측정 전. 지문을 진행 기록에 적는다). 대조 보고의 "틀 없음(건너뜀)"이 0 이어야 한다(도구가 없는 틀을 통과로 넘기므로 감독이 직접 본다).
3. **2A-I3(R5)**: 변이 아홉 — `prereg-2a-impl.md` 의 일곱에 둘을 더한다. (아) 몫 g 를 늘 1 로 둠(R5 가 R4 로 돌아감) (자) 깎는 양에만 섞기를 적용하지 않음(바람 무게는 섞음). 아홉 모두 I1(R5)의 대조나 단위 시험으로 잡혀야 한다. 살아남으면 I3 은 실패이고 그것을 잡는 장면이나 시험을 더한 뒤 다시 본다(문턱은 바꾸지 않는다). 변이가 작업 트리에 든 동안에는 빌드 보류(`Saved/AgentOps/build_hold.json`)를 걸고 같은 트리를 쓰는 다른 작업을 나란히 돌리지 않는다.
4. **최종 코드의 뒷걸음(2A-I2 의 내용)**: 결함 수정과 R5 덧층이 들어간 뒤의 코드에서 1단계 대조를 다시 돌린다. 기대(재기 전에 적는다): `fog3d_compare.py` 끝 코드 0, `fog3d_compare_v2.py` 끝 코드 0, `fog3d_compare_add1.py` 는 12검사 가운데 ADD-a 하나만 실패(1d 판정 때 빼기로 한 예외, 끝 코드 1), `GroundOffMatchesStage1` 통과. 이와 다르면 뒷걸음이다.
5. **R4 본체로 잰 값의 자리**: 앞에서 R4 기준 덤프로 잰 2A-I1 은 "R5 덧층을 넣기 전의 본체 확인"으로 남는다. R5 덧층을 넣은 뒤의 GPU 는 R4 기준 덤프와 견주지 않는다(턱 건너편과 30cm 턱에서 달라지는 것이 맞다).

## 3. 떨어졌을 때

`prereg-2a-impl.md` 3절 그대로다. I1(R5)이 떨어지면 구현을 고치고(코드가 덧붙임 2 D절·계약 §4.6 과 다른 곳을 파일:줄로 기록) I1 을 모두 다시 잰다. 코드가 식과 같은데 떨어지면 근거를 적고 덧붙임을 다음 측정 전에 등록한다.

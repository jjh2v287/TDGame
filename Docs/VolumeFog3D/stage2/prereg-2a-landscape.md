## 1. 무대와 하는 법

- 레벨: `/Game/Level/LV_DarkFantasy_OpenWorld`(기존 레벨. **저장하지 않는다**).
- 안개 구역 액터는 **PIE 월드에만** 실행 중에 띄운다(에디터 월드에 두지 않는다). 재질은 2a-3 에서 만든 `/Game/FluidFX/Materials/M_TD_Fog3DVolumeGround`. 정본 설정 JSON 은 바꾸지 않고 실행의 사본에만 땅 따라가기 켬·재질 경로·필요한 구역 값을 넣는다.
- 구역 상자는 그 자리 지형의 높낮이를 모두 덮게 잡는다(바닥 = 사각형 안 가장 낮은 땅보다 아래, 윗면 = 가장 높은 땅 + 안개 두께보다 위). 쓴 값(상자 크기, 캡처 높이 설정)을 적는다.
- 참값: 기둥 가운데에서 수직으로 쏜 선이 랜드스케이프 충돌 면과 만나는 높이(지형 높이 질의 `GetHeightAtLocation` 이 읽는 것과 같은 자료. 새 C++ 을 넣지 않으려고 선 추적으로 읽는다 — 계약 글자와 다른 점). 선이 랜드스케이프가 아닌 것(바위·나무)에 먼저 닿으면 그것을 빼고 다시 쏜다.
- 재는 값: `TD.Fog3D.GroundReadback` 으로 읽은 정본 높이(구역 바닥 기준)를 세계 높이로 바꾼 것.

## 2. 감독이 숫자로 판정하는 것

| ID | 무엇을 | 기준 |
|---|---|---|
| 2A-L0 깨끗한 실행 | PIE 구간 로그(2A-S1 과 같은 규칙)와 끝난 뒤 `git status --short Content` | Fog3D 경고·ensure·RDG 오류가 없다(순간이동 ensure 는 알려진 것으로 따로 센다, L-editor-105). 끝난 뒤 Content 의 상태가 시작 전과 같다: 기존 맵·에셋의 변경 없음, `__ExternalActors__`·`__ExternalObjects__` 에 새 파일 없음 |

성격(미리 적는다): L1 은 '캡처가 그리는 지형'과 '충돌 지형'의 차를 본다. 랜드스케이프의 충돌 해상도가 그림보다 낮게 설정돼 있으면(`CollisionMipLevel` > 0) 참값이 거칠어 2cm 기준으로 가를 수 없다 — 그때 L1 은 '판정 못 함'으로 적고, 캡처의 상세 단계를 가장 촘촘하게 강제한 캡처와의 차를 정보로 잰다. L2 의 0.5cm 는 '같은 세계 격자에 맞춰 다시 찍으면 같은 값이 나온다'는 기대에서 온 것이고, 지형의 상세 단계가 보는 자리에 따라 달라지면 깨진다(그것을 찾으려는 항목이다).

## 3. 정보로 적는 것 (판정선 아님)

1. 랜드스케이프 설정: Nanite 사용 여부, 칸 크기, 충돌 해상도, 캡처에 실제로 그려진 것(랜드스케이프 컴포넌트 종류).
2. 다시 찍는 프레임의 GPU 시간 증가(강제 − 보통, 여덟 쌍 이상의 평균과 표준오차). 도형 무대의 문턱 0.30ms 와 나란히 적는다.
3. 걷기 그림: 경사진 곳에서 땅 따라가기 켬 대 끔(뒤 카메라와 높은 카메라). 그림 묶음에 '실제 지형' 절로 더한다 — 눈 판정은 사용자.
4. 캡처 사각형 가장자리 밖의 안개 바닥 높이가 어떻게 보이는지, 구역 상자를 높게 잡았을 때의 비용 변화(상자 높이 300cm 대 쓴 값, 같은 자리 GPU 시간).
5. 겪은 제약: 구역 상자 높이·캡처 높이 설정이 지형 높낮이를 따라가야 하는지, 월드 파티션 스트리밍과의 관계.

## 4. 떨어졌을 때

- 2A-L0 의 Content 변경: 그 자리에서 멈추고 목록을 적는다. 지우거나 되돌리지 않는다(사용자 몫).
- 2A-L1·L2: 차이의 꼴(폰에서의 거리, 경사, 사각형 가장자리 쪽인지)을 적는다. 진단 하나: PIE 의 캡처 컴포넌트에 상세 단계 강제(`LODDistanceFactor` 등, 코드 변경 없이)를 걸어 한 번 더 재고 달라지는지 적는다(진단이지 통과 판정이 아니다). 고치는 길(캡처 상세 단계 고정, 벽 판정에 이력, CPU 질의로 채우기)은 그 값을 본 뒤 결정으로 적고, 다시 재기 전에 덧붙임을 등록한다. 문턱은 바꾸지 않는다.
- 2A-L3: 보류가 난 프레임과 사유 로그를 적는다.

## 2. 감독이 숫자로 판정하는 것

| ID | 무엇을 | 기준 |
|---|---|---|
| 2A-S1 유효한 실행 | 기본 묶음의 실행마다 PIE 구간 로그(1단계 `fog3d_visible_check.py` 의 로그 규칙 그대로)와 걸은 거리 | Fog3D 경고·ensure·RDG 오류가 없다(내비 없는 무대의 순간이동 ensure 는 알려진 것으로 따로 센다, L-editor-105). 걷기 실행은 걸은 거리가 요청의 90% 이상. 못 채운 실행은 무효이고 판정에 넣지 않는다(까닭을 적고 다시 찍거나 뺀다) |
| 2A-S2 게임 화면 안 캡처의 정렬 | PIE(주 렌더러 안 캡처)에서 `TD.Fog3D.GroundReadback` 으로 높이를 아는 자리 열두 곳 이상(평지, 절벽 위, 계단 단 가운데 셋, 턱 30·60·100 윗면, 착지 평지 둘, 30도 판 가운데 둘)의 정본 높이를 읽는다. 자리마다 모서리에서 두 칸(31cm) 넘게 떨어진 기둥 가운데 | 모든 자리에서 \|읽은 높이 − 무대의 높이\| ≤ 0.5cm |
| 2A-S3 캡처 비용 | `prereg-2a-impl.md` 의 2A-I8 그대로(다시 찍는 프레임의 GPU 시간 증가, 걷는 동안 평균 증가) | ≤ 0.30ms, ≤ 0.05ms |
| 2A-S4 캡처 순서 | `prereg-2a-impl.md` 의 2A-I9 그대로(순서 로그 묶음) | 다시 굽기가 요청 뒤 (지연 설정 + 1) 프레임 안, 16칸 한 번 이동에서 보류된 걸음 0, 첫 진입의 보류는 지연 설정 프레임 이하 |
| 2A-S5 땅 위에 안개가 보임 | 정지 묶음의 "안개 켬 − 끔" 화면 밝기 차(1단계 구역 보임 식 그대로, 같은 영역 비율)를 칸마다 | S30·CL·ST·CB 칸의 값 ÷ 평지 칸(F)의 값이 0.5 이상 2.0 이하. 값이 구해지지 않으면 실패 |
| 2A-S6 걷기 자국이 크게 망가지지 않음 | 걷기 묶음의 자국 대비(1단계 `fog3d_calib_report.py` 의 걷기 자국 식 그대로): W02 30도 오르막, W03 내리막, W04 등고선, W05 20도, W06 40도, W08 절벽 아래, W09 절벽 위, W12·W13 턱 옆, W14 비탈 + 턱, W15 계단 | 걷기마다 값 ÷ 평지 걷기(W01)의 값이 0.5 이상 2.0 이하. 단, 기준 장(계산을 끈 장)이 땅 따라가기 모양을 잃어 대비에 땅 모양 차이가 섞인 걷기는 "잴 수 없음"으로 따로 적는다 — 가르는 법: 보고의 '정지 마지막 장 − 기준 장 평균 밝기 차'가 평지 걷기 값의 3배를 넘으면 잴 수 없음. 잴 수 없는 걷기가 넷을 넘으면 2A-S6 은 "판정 못 함"이고 재는 법을 고쳐 덧붙임으로 다시 등록한다 |

성격(미리 적는다): 2A-S5·S6 은 "크게 망가짐"만 잡는 넓은 띠다. 비탈에서는 카메라와 땅의 각도가 평지와 달라 같은 안개도 화면 값이 달라지므로, 통과가 "평지와 같은 느낌"의 근거는 아니다. 그것은 3절의 눈 판정이 본다. 절벽 위·아래가 서로 영향을 주지 않는 것과 턱 건너편은 계산 대조(2A-I1)가 이미 본 것이고 여기서는 그림으로만 본다.

## 3. 사용자가 눈으로 판정하는 것 (그림을 올린 뒤 답을 기다리지 않고 다음 일을 계속한다)

1. 비탈에서 안개가 땅을 따라 깔려 보이는가(공중에 뜨거나 땅에 묻히지 않는가). 땅 따라가기 켬 대 끔을 나란히.
2. 절벽 위와 아래, 계단, 턱 옆에서 어색한 곳이 있는가.
3. 오르막·내리막·옆으로 걸을 때 자국이 평지와 비슷한 느낌인가. 40도 비탈에서 자국이 어색하게 길쭉한가.
4. 60cm·100cm 턱 옆과 비탈 옆 턱에서 건너편 안개가 지나치게 흔들리는가(알려진 한계: 60cm 에서는 조금 더 닿는다).
5. 땅이 없는 구멍 위의 안개, 창 가장자리 밖(멀리)의 안개 바닥 높이.
6. 달릴 때 끊김이나 튐이 보이는가.
7. 땅 따라가기를 기본값으로 켤 것인가(지금 기본값은 꺼짐. 켜는 결정은 사용자 몫이다).

## 4. 떨어졌을 때

- 2A-S1: 무효 실행은 다시 찍는다. 같은 까닭으로 두 번 무효면 그 장면을 빼고 까닭을 적는다.
- 2A-S2: 어긋남의 꼴(반 텍셀·축·일정한 높이 차)을 적고 구현을 고친 뒤 다시 잰다(문턱 불변).
- 2A-S3·S4: `prereg-2a-impl.md` 3절 그대로.
- 2A-S5·S6: 값과 그림을 함께 적고, 촬영 탓(영역·카메라)인지 계산 탓인지 가른다. 계산 탓이면 고치고 다시 찍는다. 문턱과 식은 바꾸지 않는다.

## 5. 이 등록이 가리지 않는 것

- 가만히 선 몸 주변 바람의 진동(1단계 섞기 식의 성질, `plan.md` 흠 ⑤. 이 촬영의 걷기 뒤 정지 장에도 들어 있다 — 평지와 비탈에 똑같이).
